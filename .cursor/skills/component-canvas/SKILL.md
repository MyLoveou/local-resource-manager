# 组件画布

画布展示组件的真实行为。它包住组件，从不改变组件。用项目现有的框架（Vue 或 React）和库。不要为画布换栈。

这是开发用的探索入口，默认不进产品主导航。若要把它做成给用户的功能，转 `project-spec`。

## 底线

- 不改组件源码、导出、样式、hook 或行为来迁就画布。组件不得 import 画布。
- 不补丁库、浏览器 API、组件渲染出的 DOM 或 portal 根。
- 只展示用户点名的组件。多加组件、装依赖、改组件设计或把画布公开，先问。
- 保留已有访问控制。无关工作不动。拆掉旧画布时，只撤销它对组件的改动。
- 遵守仓库对命令、浏览器、依赖和编辑的限制。

## 动手前

读仓库约定、路由、组件公开 API、设计 token 和测试方式。

只在答案会改变做什么、或会碰到共享代码时才问：哪些组件在范围内、能否加依赖、能否预览真实服务。其余选一个合理默认，写进报告，然后继续。

## 建造顺序

1. 最小路由或入口：一组、一个组件。确认能挂上。
2. 补其余组，带示例数据。
3. 再加变体对比，然后才是手势和持久化。一次一个能力。

画布代码放在一处。移动文件时核对 import 和包导出。跟项目的语言、校验和测试约定。不要新增项目里没有的分层或目录名。

布局和相机与示例数据、组件源码分开。

## 版式

- 铺满视口，纯色背景。
- 项目已支持明暗主题时，用它的主题 API 做一个可访问开关，作用到画布和原生 portal。没有主题就不要开关，也不要发明主题或改组件样式。
- 每组同样的内边距、圆角和细虚线边框，两个主题里都看得见。边框用已有的弱色、大约 25% 不透明度。标题在边框上方 `8px`，用弱文字色、不透明。
- 组要宽，一行里示例槽等宽，放不下就换行。组内组间都留出足够间隙。拉开布局，不要把组件放大。
- 组不能拖。位置不必写死。测量真实边界，含标题、边框和内边距。忽略渲染占位（内容出来前的空盒子）。
- 不要背景点、装饰卡片、页面菜单、说明条、选择工具和块编辑。组件卡片和菜单只作为示例出现。

## 变体

- 在请求范围内展示每个有名字的变体和有用状态。读公开 API：样式、文字和图标尺寸、方向、位置、对齐、模态、折叠。
- 包含有用的内容和组合示例。
- 不要发明变体，也不要生成全部 prop 组合。列出省略了什么、为什么。
- 一次只比一个 prop 或特性。其余保持不变：同一包裹、同一示例数据、同一文字、图标、主题和间距。
- 只有样式对比才改样式变体。尺寸、状态、位置等对比用同一种样式，通常是默认。

例：尺寸对比里每个按钮都写「继续」且 `variant` 为默认，只改 `size`。样式对比只改变体，尺寸和文字不变。

- 保留组件自己的状态样式（禁用透明度、选中色）。示例能响应输入，除非它展示的就是禁用或只读。
- 悬停、焦点、按下靠真实指针和键盘，不要加类名假装。
- portal 示例每次用同一个触发器。不要同时强制打开多个模态。
- 留一份变体清单。项目有类型就用类型约束覆盖。
- 组件表达不了某个响应式或视觉情况时，说明限制。不要改组件去伪造。

## 交互

- 点击、选字、输入、按钮和开关、焦点、内部滚动必须继续可用。
- 画布快捷键（Space、方向键、Escape、原生撤销）只作用于画布壳，不能抢走预览控件的这些键。
- 预览内导航由画布宿主处理。指向画布内组的链接移动相机，而不是滚动页面。离开画布的链接（含 portal 内）要定义行为。不改组件链接或路由内部。
- portal 留在原生根上，按屏幕尺寸摆放。定位和模态焦点交给库。只在需要时用公开的容器选项。在画布变换下核对定位和可点区域。坏了就报告，或提议单独的预览文档。不补丁组件。
- 画布没有撤销、编辑快捷键或历史。

## 预览安全

挂载前就让每个预览安全：

- 用测试数据的 provider、模拟服务或已有回调，挡住真实请求和写入。
- 静态演示资源和本地夹具可以。
- 不用生产凭证或生产数据。
- 隔离不了就省掉这个实时例子并说明原因。单独开一个文档并不能让预览变安全。

## 相机

- 鼠标和触控板：平移，并绕光标缩放。触摸：平移和捏合。
- 普通平移从空白处开始。预览和 portal 内部保留原生手势。
- 不要大范围 `preventDefault`。不要在可交互内容上写 `touch-action: none`。
- 处理指针数量变化、取消、丢失捕获、窗口失焦和隐藏标签。拆除时释放捕获，清掉监听、观察器、定时器和动画帧。
- 手势变换每帧最多写一次。避免交替读写布局。
- 内容变高或视口变化时，组不要重叠。避免布局循环和无谓移动。布局稳定后再适配。适配不重排组。
- 键盘焦点跑出可见区域时，移动相机把它露出来。页面原生滚动不能带动画布。
- 键盘可以操作相机，画布控件有可见焦点。
- 提供「适配全部」和「重置」图标按钮，带可访问名称。视图丢了也要够得到它们。
- 校验相机数值，限制在边界内。

## 持久化

- 只保存相机，带版本号，键按项目或工作区区分。
- 处理损坏或过大的数据、存储不可用和配额错误。
- 已知旧格式要迁移。未知格式用安全默认，丢掉旧的组位置和历史。
- 重置只恢复相机，不清预览状态或草稿。

## 检查

允许的话跑仓库自己的检查。然后在浏览器确认：

- 路由能挂上，import 和导出能解析，控制台无错误。
- 组件源码没变。
- 列出的变体都在，省略有说明，组有虚线边框，非样式对比只用一种样式。
- 键盘相机和可见焦点可用。预览控件保住自己的快捷键和手势。
- 多层缩放和多种视口下，内部滚动、portal 定位、可点区域和模态焦点可用。
- 平移和捏合能扛住指针变化和取消。拆除会释放资源。
- 展开或改变尺寸后组不重叠。适配可用，屏外焦点能被揭开。
- 刷新后相机还在。存储失败能安全回退。重置保留预览草稿。除非用户要求，草稿不必活过刷新。
- 组不能拖。没有撤销。
- 预览用安全测试数据，没有真实的项目或账号写入。

没跑过的检查不能写成通过。跳过了就说明。

## 报告

每次建造或审查都以这些标题结束：

- **改了什么：** 文件及各自改动。注明组件有没有被改（不该有）。
- **跑过的检查：** 每条和结果。
- **不行或没测：** 已知缺口、省掉的变体及原因、未验证项。
- **自行决定的默认：** 没问用户就选定的。

上面的检查没有全部通过时，不要说实现已验证或模板已就绪。
