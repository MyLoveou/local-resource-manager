### 5.2 实现切片（组合式：UI · 功能 · 算法）

模式：**关注点分离 + 能力组合**；**组合根** = 页面或应用门面。

| 切片 | 能力（对外一句话） | 落点模块 `path` | 依赖 | 谁组装 |
|------|--------------------|-----------------|------|--------|
| UI | | | 功能 | 页面 |
| 功能 | | | 算法、模型 | 页面或应用服务 |
| 算法 | | | 无 UI | 功能调用 |

- 依赖：`UI → 功能 → 算法`；算法不依赖 UI
- 本版本组合根：`path`（页面/门面）
- 不拆（理由）：

并行 PR / 短分支可以按上表，**组合切片未验收不算能力完成**。

### 5.3 切片契约（组合式必填）

没有契约就禁止拆。UI 只依赖这些符号，禁止直接调算法内部。

| 调用方 | 提供方 | 名称（函数/事件/命令） | 入参 | 出参 / 错误 | 谁持有状态 |
|--------|--------|------------------------|------|-------------|------------|
| UI | 功能 | | | 成功 / 可展示错误码 | |
| 功能 | 算法 | | | 纯数据，无 UI 类型 | 无（纯函数优先） |

- 错误：功能翻译成 UI 文案；算法只返回码或结果对象
- 未确认的字段标「未确认」
