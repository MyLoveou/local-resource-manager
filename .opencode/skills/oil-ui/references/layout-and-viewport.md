# 布局与视口

## 按参考图还原

先记下参考图对应的视口，以及哪些区域是固定的。图片像素不等于视口，二倍图要除以二。确定不了就写明假设。

先对准栏宽、对齐轴、色板和字号的对比关系，再处理边框和阴影。还原任务不重新发散风格。

长图和草图常常把区块之间的留白压扁了。实现时不要逐像素描纵向坐标。留白跟项目已有的间距刻度；没有刻度时让区块能呼吸，而不是把稿上的紧密度原样搬来。去掉稿里的窗口装饰框。文案保持原有层级，写成规范的产品语言，清掉伪字和「标题」「描述」这类占位。对照真实视口看构图，不做像素网格差分。

## 看哪些视口

任务明确只有一端时，只验那一端。否则先在主视口把主要路径走到结果，再在另一端的代表宽度看主要状态，确认主动作可见可点。两端都要完成同一流程时才各走一遍。

再补一个最容易破坏阅读或主操作的状态：最长内容、空内容、错误与恢复里选一个。已经包含在代表状态里就不再重复。

项目要求的宽度照项目来。下面的风险出现了才加对应检查，通过就停：

- **手势或画布**：实际拖或点一次。画面非空，坐标跟手，页面不会被手势锁住。
- **复杂多栏**：窄屏上重排后的阅读和操作顺序仍然清楚，各栏还能滚。
- **弹窗或键盘**：手机上聚焦输入，看焦点、关闭方式和主操作。键盘和固定栏不能挡住主操作。安全区要算上。
- **多屏**：沿主导航至少走两屏再返回。当前位置和主操作还在。
- **壳内滚动**：页面滚和内部容器滚要落在该滚的地方，不要双滚动条。
- **特殊视口**：只有用户指定的尺寸、横竖屏、缩放或动态高度会影响结果时才补。放大之后阅读顺序仍然清楚。

文字重叠、被裁切，或靠大量小字才装下，回到内容和布局修。截图保存成功不等于已经看过。
