# 说服型页面首屏骨架

落地页、品牌页、发布页、展览页使用。整体流程见 [design-direction.md](design-direction.md)。

模型最顽固的习惯是左右分栏：还没写文案，就摆好标题、一段说明、一个按钮。骨架要在写文案之前决定。

每个方向从下表选一个骨架，再用 3 到 5 个方框画出首屏：每块是什么、占多大、阅读从哪里开始。

| 骨架 | 首屏长什么样 |
|------|----------------|
| 满版图像压字 | 一张图占满首屏，标题和动作压在安全区里 |
| 居中单一物件 | 一个物件或一句话居中，四周是大面积空白 |
| 画面即界面 | 首屏就是产品界面或一件实物，标题和动作长在它上面 |
| 满版文字 | 文字本身就是画面，字大到占满或被裁切 |
| 通栏上下堆叠 | 通栏大标题横跨宽度，下面紧接内容 |
| 网格拼贴 | 多块内容按网格同时出现 |
| 纵排或斜向 | 文字竖排、斜切或旋转，打破从左到右 |
| 左右分栏 | 文字一侧，画面一侧。这是默认习惯，一轮最多一个方向使用，并写明为什么适合。另一侧要有撑得住的主角，不要一张缩得很小、没有重点的整页截图 |

规则：

- 同一轮的多个方向，骨架互不相同。
- 「大标题九栏、说明三栏」同样算左右分栏。
- 骨架定好再写文案。文案去适应骨架。
- 安静的产品也可以用居中一句或满版界面。调性决定音量，骨架决定结构。不要因为想安静，就退回左右分栏。
