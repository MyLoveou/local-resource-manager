# 02 · 数据模型

> 状态：**草案**（L3 数据模型）
> 关联：`docs/requirements/features/local-resource-manager.md`（已定稿）

## 1. 设计决策（默认执行，可改）

| # | 决策 | 结论 |
|---|------|------|
| 1 | 元数据落法 | 核心字段内嵌 `resources`；站点特有字段用 `extra` JSON 兜底，不拆独立 metadata 表 |
| 2 | 哈希 | `sha256` 唯一索引为主；预留快速哈希（xxHash 索引 + SHA-256 确认）双轨优化空间 |
| 3 | 类型契约 | Pydantic snake_case 字段 ↔ JSON **camelCase**（`ApiModel` 统一），前端 TS 用 camelCase；后续以 OpenAPI 为单一事实源（openapi-typescript 生成） |
| 4 | 存储 | SQLite 单库 `library.db`，WAL + busy_timeout，单写者优先（scrape 写资源类表、download 写任务表） |
| 5 | 回收站 | `resources.status=trashed` 软删 + `deleted_at`，不建独立表 |
| 6 | 常量与值对象 | 协议/引擎/适配器 key 收口 `app/shared/constants.py`（前端 `domain/constants.ts` 对齐）；`Rating`/`Dimension`/`Progress` 值对象在 `app/shared/value_objects.py` |
| 7 | 库类型与落盘 | CHECK 含 audio/novel/game/model/comic；`storage_kind` owned=库内副本，indexed=源路径登记（游戏默认）。0009 已落地。 |

## 2. ER 关系

```
resources ──1:N── files
    │ 1:1 ── categories（可空）
    │ 1:N
    ├── seasons ──1:N── episodes（episodes.file_id → files；集不是 Resource）
    ├── extras（特典，file_id → files）
    ├── resource_todos
    ├── scrape_jobs ──1:N── candidates
    ├── resource_tags ──N:1── tags
    └── download_tasks（target_resource_id 关联，完成入库）
settings（KV） / adapters（适配器配置） —— 独立
```

## 3. 表定义（SQLite DDL）

```sql
PRAGMA journal_mode = WAL;
PRAGMA foreign_keys = ON;

CREATE TABLE resources (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  type          TEXT NOT NULL CHECK (type IN ('image','video','anime','av','audio','novel','game','model','comic')),
  storage_kind  TEXT NOT NULL DEFAULT 'owned' CHECK (storage_kind IN ('owned','indexed')),
  title         TEXT NOT NULL DEFAULT '',
  description   TEXT,
  author        TEXT,
  rating        REAL CHECK (rating BETWEEN 0 AND 10),
  cover_path    TEXT,               -- 封面本地缓存路径
  status        TEXT NOT NULL DEFAULT 'active'
                CHECK (status IN ('active','trashed','lost')),
  deleted_at    TEXT,               -- 回收站时间
  last_scraped_at TEXT,
  scraped_source TEXT,              -- 抓取来源（审计）
  extra         TEXT NOT NULL DEFAULT '{}',   -- JSON 兜底
  category_id   INTEGER REFERENCES categories(id) ON DELETE SET NULL,
  created_at    TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at    TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_resources_type   ON resources(type);
CREATE INDEX idx_resources_status ON resources(status);
CREATE INDEX idx_resources_category ON resources(category_id);

CREATE TABLE categories (
  id   INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE
);

CREATE TABLE files (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  path        TEXT NOT NULL,
  sha256      TEXT,                 -- 图片元数据匹配键
  size        INTEGER,
  format      TEXT,                 -- 扩展名/格式
  duration    REAL,                 -- 视频时长（秒）
  width       INTEGER, height INTEGER,
  codec       TEXT,                 -- 视频编码
  fps         REAL,                 -- 帧率
  bitrate     INTEGER,              -- 比特/秒
  exif_taken_at TEXT,               -- 图片拍摄时间
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  UNIQUE (path),
  UNIQUE (sha256)
);
CREATE INDEX idx_files_resource ON files(resource_id);

CREATE TABLE seasons (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  resource_id   INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  season_number INTEGER NOT NULL,
  title         TEXT,
  sort_index    INTEGER NOT NULL DEFAULT 0,
  UNIQUE (resource_id, season_number)
);
CREATE TABLE episodes (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  season_id       INTEGER NOT NULL REFERENCES seasons(id) ON DELETE CASCADE,
  file_id         INTEGER NOT NULL REFERENCES files(id) ON DELETE CASCADE,
  episode_number  INTEGER NOT NULL,
  title           TEXT,
  sort_index      INTEGER NOT NULL DEFAULT 0,
  status          TEXT NOT NULL DEFAULT 'active'
                  CHECK (status IN ('active','trashed')),
  UNIQUE (season_id, episode_number)
);
CREATE TABLE extras (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  file_id     INTEGER NOT NULL REFERENCES files(id) ON DELETE CASCADE,
  title       TEXT NOT NULL DEFAULT '',
  sort_index  INTEGER NOT NULL DEFAULT 0,
  status      TEXT NOT NULL DEFAULT 'active'
              CHECK (status IN ('active','trashed'))
);

CREATE TABLE resource_todos (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  content     TEXT NOT NULL,
  done        INTEGER NOT NULL DEFAULT 0,
  sort        INTEGER NOT NULL DEFAULT 0,
  created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_todos_resource ON resource_todos(resource_id);

CREATE TABLE tags (
  id   INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE
);

CREATE TABLE resource_tags (
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  tag_id      INTEGER NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (resource_id, tag_id)
);

CREATE TABLE scrape_jobs (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  status      TEXT NOT NULL DEFAULT 'queued'
              CHECK (status IN ('queued','running','done','failed')),
  started_at  TEXT, finished_at TEXT,
  error       TEXT,
  match_count INTEGER NOT NULL DEFAULT 0,
  query       TEXT                  -- 手填 BV/链接，可空
);

CREATE TABLE candidates (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  job_id        INTEGER NOT NULL REFERENCES scrape_jobs(id) ON DELETE CASCADE,
  title         TEXT NOT NULL,
  url           TEXT NOT NULL,
  thumbnail_url TEXT,
  source        TEXT NOT NULL,      -- 适配器/站点标识
  relevance     REAL,               -- 0-1
  selected      INTEGER NOT NULL DEFAULT 0,
  created_at    TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE download_tasks (
  id                INTEGER PRIMARY KEY AUTOINCREMENT,
  url               TEXT NOT NULL,
  protocol          TEXT NOT NULL,  -- http/ftp/magnet/torrent
  engine            TEXT NOT NULL,  -- httpx/aria2/rqbit/yt-dlp
  status            TEXT NOT NULL DEFAULT 'queued'
                    CHECK (status IN ('queued','running','paused','done','failed')),
  save_path         TEXT,
  filename          TEXT,
  downloaded_bytes  INTEGER NOT NULL DEFAULT 0,
  total_bytes       INTEGER,
  speed             INTEGER NOT NULL DEFAULT 0,
  error             TEXT,
  target_resource_id INTEGER REFERENCES resources(id) ON DELETE SET NULL,
  created_at        TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at        TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_tasks_status ON download_tasks(status);

CREATE TABLE settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL DEFAULT '{}'
);

CREATE TABLE adapters (
  id      INTEGER PRIMARY KEY AUTOINCREMENT,
  key     TEXT NOT NULL UNIQUE,     -- og/tmdb/bangumi/pixiv/douban
  enabled INTEGER NOT NULL DEFAULT 1,
  config  TEXT NOT NULL DEFAULT '{}'
);
```

## 4. 类型映射（Python ↔ TS）

| 实体 | 后端 Pydantic | 前端 TS |
|------|---------------|---------|
| 资源 | `app/shared/models.py::Resource` | `domain/resource.ts::Resource` |
| 文件 | `ResourceFile` | `ResourceFile` |
| 标签 | `Tag` | `Tag` |
| 设置 | `Settings` | `domain/settings.ts::SettingsEntry` |
| 适配器 | `SiteAdapter` | `SiteAdapter` |
| 抓取任务 | `app/scrape/domain/models.py::ScrapeJob` | `domain/scrape.ts::ScrapeJob` |
| 抓取候选 | `Candidate` | `Candidate` |
| 下载任务 | `app/download/domain/models.py::DownloadTask` | `domain/download.ts::DownloadTask` |

- JSON 序列化 camelCase：`cover_path` ↔ `coverPath`、`exif_taken_at` ↔ `exifTakenAt` 等
- 资源包 `files.role`：`primary` / `cover` / `subtitle` / `thumbnail` / `episode` / `extra`。番剧与 AV 的 **Resource 是作品**；集在 `episodes`，特典在 `extras`。
- 类型 `image` \| `video` \| `anime` \| `av`（`0008_series.sql` 放宽 CHECK）。

### 回收站 HTTP（`library-trash`）

| 方法 | 路径 | 含义 |
|------|------|------|
| DELETE | `/library/resources/{id}` | 软删 `trashed` |
| POST | `/library/resources/{id}/restore` | 仅 trashed → active；非 trashed 409 |
| POST | `/library/resources/{id}/purge` | 删库内包后 DROP 行 |
| POST | `/library/resources/batch` | `{ action: trash\|restore\|purge, ids }`，ids 1–200；响应 `{ ok, failed }` |
| GET | `/library/resources?status=trashed` | 混排回收站（可省略 type） |

彻底删除不碰用户导入源文件。无新表。

### 图片消费（`image-consume`）

无新 REST。原图 `GET /library/resources/{id}/content`。打开磁盘走 Electron `shell:showItemInFolder` / `openPath` / `openWith`，路径取 `files.role=primary` 的库内绝对路径。
