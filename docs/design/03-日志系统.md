# 03 · 日志系统设计

> 状态：已落地（2026-09-01）  
> 关联：架构全景 [经验总结/01](../经验总结/01-架构全景.md)、后端子进程编排 [经验总结/02](../经验总结/02-Electron后端子进程编排.md)  
> 学习向（为什么/怎么用/踩坑）：[经验总结/20-日志系统.md](../经验总结/20-日志系统.md)

## 1. 目标与原则

| 原则 | 说明 |
|------|------|
| 文件为权威 | 排障以落盘文件为准；终端仅作开发预览 |
| 格式统一 | 前后端同一文本模板，便于对照 |
| 目录统一 | 同一 `LOG_DIR`，主进程决定，后端继承 |
| 进程各记各的 | 主进程 / 渲染 / 后端各自写文件；不做远程汇聚 |
| 敏感信息 | 禁止记录 `BACKEND_TOKEN` 等密钥 |

**明确不做（当前）**：远程 ELK/Sentry、业务审计入运行日志、渲染进程直写磁盘。

## 2. 总览

```
渲染进程  logger (electron-log/renderer)
    │  IPC（preload: electron-log/preload）
    ▼
主进程    electron-log/main  ──►  {LOG_DIR}/main.log
    │
    ├─ initMainLog() 写入 process.env.LOG_DIR
    ├─ spawn uvicorn（继承 LOG_DIR，--no-access-log）
    │       │
    │       ▼
    │   后端 LoggingApp  ──►  {LOG_DIR}/backend.log
    │                    ──►  {LOG_DIR}/backend.error.log
    │       │ stdout/stderr (pipe)
    └───────┴─► 开发期转发到当前终端（预览，非权威副本）
```

## 3. 统一约定

### 3.1 文本格式

```text
YYYY-MM-DD HH:mm:ss - [scope] - LEVEL - message
```

| scope | 来源 |
|-------|------|
| `main` | Electron 主进程 |
| `renderer` | 渲染进程（经 IPC 落盘时由主进程格式化；`browser` 映射为 `main`） |
| `backend` | FastAPI / uvicorn 业务与访问日志 |

示例：

```text
2026-09-01 23:50:00 - [main] - INFO - log dir D:\Project\资源管理器\apps\logs
2026-09-01 23:50:01 - [backend] - INFO - Request: GET http://127.0.0.1:60306/library/overview
2026-09-01 23:50:01 - [renderer] - WARN - [http] GET /library/overview -> 500
```

### 3.2 目录（`LOG_DIR`）

| 优先级 | 规则 |
|--------|------|
| 1 | 环境变量 `LOG_DIR` |
| 2 | 开发（存在 `ELECTRON_RENDERER_URL`）：`{repo}/apps/logs` |
| 3 | 生产：`{app.getPath('userData')}/logs` |
| 后端单独启动且无 `LOG_DIR` | 回退 `{APPS_DIR}/logs`（即 `apps/logs`） |

目录内文件：

| 文件 | 写入方 | 说明 |
|------|--------|------|
| `main.log` | electron-log | 主进程 + 经 IPC 的渲染日志 |
| `backend.log` | Python RotatingFileHandler | 全量（默认 INFO） |
| `backend.error.log` | Python RotatingFileHandler | 仅 ERROR 及以上 |

轮转：桌面 / 后端均为约 **10MB**；后端另有 `backupCount=5`。

## 4. 桌面端（Electron）

### 4.1 模块落点

| 路径 | 职责 |
|------|------|
| `apps/desktop/src/main/log/index.ts` | `getLogDir` / `initMainLog` / 导出 `log` |
| `apps/desktop/src/main/index.ts` | **最先**调用 `initMainLog()` |
| `apps/desktop/src/preload/index.ts` | `import 'electron-log/preload'`（contextIsolation 桥） |
| `apps/desktop/src/renderer/src/infrastructure/logging/logger.ts` | 渲染薄封装 |
| `apps/desktop/src/renderer/src/infrastructure/http/client.ts` | 响应失败 `logger.warn('[http] …')` |

### 4.2 初始化时序

1. `initMainLog()`：算目录 → `mkdir` → `process.env.LOG_DIR = …` → `log.initialize()` → 配置 file/console format  
2. `startServices()` → `spawn` 后端（继承 `LOG_DIR`）  
3. `createWindow()`（preload 已能桥接 `__electronLog`）

### 4.3 使用方式

```ts
// 主进程
import { log } from './log'
log.info('[main] backend ready', url)

// 渲染进程
import { logger } from '@/infrastructure/logging/logger'
logger.warn('[http] GET /x -> 500')
```

### 4.4 与后端子进程 stdout

- uvicorn 使用 `--no-access-log`，避免与中间件访问日志重复  
- 子进程 `stdio: pipe`；主进程转发到终端供开发查看  
- **权威后端日志仍是 `backend.log`**，不以终端转发为准

## 5. 后端（FastAPI）

### 5.1 模块落点

| 路径 | 职责 |
|------|------|
| `app/shared/config.py` | `resolve_log_dir` / `LoggingConfig` |
| `app/shared/log.py` | `LoggingApp`（幂等配置）+ 模块级 `logger` |
| `app/shared/middleware/logging.py` | HTTP 请求/响应访问日志 |
| `app/main.py` | 注册 middleware；业务用 `logger` |

### 5.2 LoggingApp 行为

- 进程内只配置一次（锁 + `_configured`）  
- Handler：控制台 + `backend.log` + `backend.error.log`  
- `propagate = False`，避免根 logger 重复  
- Formatter 使用与桌面一致的模板（scope 固定 `[backend]`）

### 5.3 使用方式

```python
from app.shared.log import logger

logger.info("正在初始化数据库")
logger.error("初始化数据库失败: %s", e)
```

访问日志由 middleware 记录 `Request` / `Response`（可后续合并为含耗时的单行）。

## 6. 级别策略

| 环境 | 主进程 console | 主进程 file | 后端 |
|------|----------------|-------------|------|
| 开发 | debug | info | INFO |
| 生产 | info | info | INFO |

未捕获异常：主进程 `log.errorHandler.startCatching()`。

## 7. 排障速查

| 现象 | 排查 |
|------|------|
| 终端看不到后端输出 | 是否保留 pipe 转发；后端是否在子进程中（非当前 shell 直跑） |
| 访问日志打两遍 | 是否未加 `--no-access-log`，与 middleware 叠加 |
| 后端文件不在预期目录 | 子进程环境是否带上 `LOG_DIR`；是否在 `initMainLog` 之后才 spawn |
| 渲染日志未进 `main.log` | 是否调用了 `log.initialize()`；preload 是否 `import 'electron-log/preload'` |
| 格式不一致 | 主进程是否使用 `unifiedFormat`；后端是否为当前 `LoggingConfig.log_file_format` |

启动成功后主进程会打一行：`[main] log dir <绝对路径>`。
