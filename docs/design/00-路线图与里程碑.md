## 2. 横切约定（每个里程碑都遵守）

- 用户可感知结果一律走 `notify`（见 [04](04-全局提示系统.md)），禁止 `alert` / 散落 `useMessage`。
- HTTP 拦截器只打日志；UI 层 `catch` 后 `notify.fromError`。
- 新 API 保持 snake_case 字段 ↔ JSON camelCase（`ApiModel`）。
- 新表走 `migrations/NNNN_*.sql`，同步 [02-数据模型](02-数据模型.md)。
- 质量门禁：桌面 `pnpm lint && pnpm typecheck`；后端至少能启动并 `GET /library/health`。
- 主进程改动后必须重启 `pnpm -F desktop dev`。
