## 1. 里程碑总览

```
MS0 地基收口 ──► MS1 可入库 ──► MS2 可浏览 ──► MS3 可抓取
                                              │
                    MS4 可检索 + 设置完整 ◄────┘
                                              │
                    MS4.1 词表治理（统计/删除）──┘  （MS4 打标之后；需求未定稿不编码）

                    【WCH 定稿门禁】──► MS5 工作台 MVP（M7+M8）
                                              │
                    MS6 工作概览 + 模型占位（M9+M10）
                                              │
                    MS7 下载平台（M5，可与 MS4 后并行）
```

| 里程碑 | 用户能做什么 | 对应模块 | 建议顺序 | 规模 |
|--------|--------------|----------|----------|------|
| **MS0** | 启动稳定、操作有反馈、空态/占位正确 | M0 收口 + Notify | 立刻 | S |
| **MS1** | 添加目录 → 扫进图片/视频 → 库里有数据 | M1 + M6 目录子集 | MS0 后 | L |

| **MS4** | 搜索/标签/排序；设置适配器与备份 | M4 + M6 其余 | MS3 后（搜索可与 MS3 部分重叠） | M |
| **MS4.1** | 标签/分类词表统计与删除（治理膨胀） | M4 增量 | **MS4 打标可用之后**；需求见 [tag-category-hygiene](../requirements/features/tag-category-hygiene.md)（草案） | S–M |
| **MS5** | 工作目录 + 待办/备注 + 按类型打开 | M7 + M8 | **WCH 定稿后** | L |

| **MS7** | 粘贴链接下载、进度、完成后入库 | M5 | MS4 后可并行，不挡 MS5 | L |

| 版本标签 | 包含 | 定位 |
|----------|------|------|

| v1.0 获取闭环 | + MS7 | 下载 → 入库 → 消费 |

## 2. 横切约定（每个里程碑都遵守）

- 用户可感知结果一律走 `notify`（见 [04](04-全局提示系统.md)），禁止 `alert` / 散落 `useMessage`。
- HTTP 拦截器只打日志；UI 层 `catch` 后 `notify.fromError`。
- 新 API 保持 snake_case 字段 ↔ JSON camelCase（`ApiModel`）。
- 新表走 `migrations/NNNN_*.sql`，同步 [02-数据模型](02-数据模型.md)。
- 质量门禁：桌面 `pnpm lint && pnpm typecheck`；后端至少能启动并 `GET /library/health`。
- 主进程改动后必须重启 `pnpm -F desktop dev`。

## 4. MS1 · 可入库（媒体库最小闭环的数据端）

**目标**：用户指定本地目录，扫描出图片/视频并写入 SQLite。  
**不交付**：漂亮网格、播放器、抓取。可用临时列表验证数据。

### 任务

| ID | 任务 | 落点 | 验收 |
|----|------|------|------|
| T-1.1 | 资源目录配置 | `settings` KV：`library.roots[]`；设置页「资源目录」增删 | 路径持久化，重启仍在 |
| T-1.2 | 选目录 IPC | 主进程 `dialog.showOpenDialog`；preload 暴露 | 渲染进程能拿到绝对路径，不直接碰 Node fs |
| T-1.3 | 扫描任务模型 | 后端 scan job：queued/running/paused/done/failed；进度（已扫/发现/去重/跳过） | 可查询当前扫描状态 |
| T-1.4 | 文件识别 | 扩展名白名单对齐 lrm-modules M1 | jpg/png/webp/gif/bmp/heic/avif + mp4/mkv/avi/mov/webm/flv/ts/m4v |
| T-1.5 | 元数据抽取 | 图片宽高/大小/EXIF；视频时长/分辨率/编码/大小 | 入库 `files` 字段非空（格式允许的前提下） |
| T-1.6 | 哈希去重 | sha256 唯一；重复不建新 resource | 扫描报告含去重数量 |
| T-1.7 | 丢失检测 | 再扫时路径不存在 → `status=lost`；哈希匹配可重定位 | 移动文件后重扫能挂回 |
| T-1.8 | 权限/占用跳过 | 读失败记日志 + 计入 skip | 不中断整次扫描 |
| T-1.9 | 手动触发入口 | 工具栏「添加目录」「立即扫描」；启动时可选扫一次 | 无常驻文件监视 |
| T-1.10 | 扫描 UI | LoadingBar + 设置页进度；可暂停/继续（至少可取消） | UI 不卡死；取消后已入库数据保留 |
| T-1.11 | 列表 API 给前端 | 已有 `GET /resources` 接到 Image/Video 页临时列表 | 扫完刷新能看到标题/类型/路径 |

**完成定义**：选一个含图+视频的文件夹，扫完后两个类型页都能列出记录。
