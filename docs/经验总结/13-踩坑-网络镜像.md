# 13 · 踩坑：GitHub / pip / Electron 网络受限

## 现象

- `git clone github.com` → `Recv failure: Connection was reset`
- `pip install` → pypi.org 超时
- Electron 二进制下载卡死

## 解决方案

### git clone GitHub（镜像代理）

```bash
git clone https://gh-proxy.com/https://github.com/<org>/<repo>.git
```

曾试 ghproxy.com（reset）、gitclone.com（504）、kkgithub（502/证书过期）——**gh-proxy.com 可用**。kkgithub 需 `-c http.sslVerify=false` 但 502。

### pip（阿里云镜像）

```bash
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

清华镜像偶发拿不到版本（`from versions: none`），**阿里云稳定**。

### Electron 二进制（npmmirror）

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
node node_modules/electron/install.js
```

## 教训

1. 网络问题按"镜像链"逐个试，记下哪个可用（本项目实测：**gh-proxy.com / 阿里云 pypi / npmmirror**）。
2. 镜像失效快，试错顺序：官方 → 国内大厂镜像 → 代理类。
3. Electron 二进制走 GitHub release，务必设 `ELECTRON_MIRROR`。
