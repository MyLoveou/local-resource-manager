# 19 · 命令速查

> 以仓库根 `D:\Project\资源管理器` 为工作目录。
> 平台：Windows PowerShell 5.1；Python 在 `apps/backend/.venv`。

## 1. 启动

```powershell
pnpm dev                  # 桌面端，自动拉起后端
pnpm backend:install      # 首次：创建 venv + 安装运行依赖
pnpm backend:start        # 单独起后端 :8000（无 token 校验）
```

只启动后端时，数据默认在：

```text
apps/backend/data/library.db
```

## 2. 前端检查

```powershell
pnpm --filter desktop typecheck
pnpm --filter desktop lint
pnpm --filter desktop build
```

不要用根目录 `pnpm typecheck`（根 package 没有这个脚本）。

自动修复 lint：

```powershell
pnpm --filter desktop lint:fix
```

## 3. 后端测试

首次安装测试依赖：

```powershell
apps/backend/.venv/Scripts/pip install -r apps/backend/requirements-dev.txt
```

全量：

```powershell
apps/backend/.venv/Scripts/python -m pytest -q apps/backend/tests
```

单文件：

```powershell
apps/backend/.venv/Scripts/python -m pytest -q apps/backend/tests/test_batch_tag_export.py
```

单个测试：

```powershell
apps/backend/.venv/Scripts/python -m pytest -q `
  apps/backend/tests/test_batch_tag_export.py::BatchTagExportTests::test_export_missing_collection_404
```

## 4. 发布

```powershell
pnpm release:win          # 类型检查 + lint + 测试 + 构建 + 打包 + verify
pnpm release:verify       # 只校验已有 release/ 产物
```

产物：

```text
release/local-resource-manager-<version>-win-x64-setup.exe
release/local-resource-manager-<version>-win-x64-setup.exe.blockmap
release/local-resource-manager-<version>-win-x64.zip
release/latest.yml
release/SHA256SUMS.txt
```

打 tag 触发 CI：

```powershell
git tag v0.1.3
git push origin v0.1.3
```

强制重打（只用于未正式发布的版本）：

```powershell
git tag -f v0.1.3 HEAD
git push -f origin v0.1.3
```

## 5. 冻结后端 / 调试

只冻结后端：

```powershell
pnpm backend:freeze
```

产物：

```text
apps/backend/dist/source-manager-backend/
```

启动冻结后端：

```powershell
apps/backend/dist/source-manager-backend/source-manager-backend.exe `
  --host 127.0.0.1 --port 8123 --no-access-log
```

健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8123/health
```

## 6. 日志与数据

开发日志：

```text
apps/logs/main.log
apps/logs/backend.log
apps/logs/backend.error.log
```

安装版日志：

```text
%APPDATA%\local-resource-manager\logs\
```

安装版数据库：

```text
%APPDATA%\local-resource-manager\library.db
```

查看 SQLite 表：

```powershell
apps/backend/.venv/Scripts/python -c "import sqlite3; c=sqlite3.connect(r'%APPDATA%\local-resource-manager\library.db'); print(c.execute(\"select name from sqlite_master where type='table' order by name\").fetchall())"
```

> PowerShell 里的 `%APPDATA%` 不会自动展开到 Python 字符串；正式排查建议用绝对路径或 `os.path.expandvars`。

## 7. OpenSpec

```powershell
pnpm exec openspec list
pnpm exec openspec status --change "<name>"
pnpm openspec list
```

本项目 CLI 装在仓库根 devDependency，不要假设全局有。

## 8. 网络镜像

pip：

```powershell
apps/backend/.venv/Scripts/pip install -r apps/backend/requirements.txt `
  -i https://mirrors.aliyun.com/pypi/simple/
```

Electron 二进制：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
node apps/desktop/node_modules/electron/install.js
```

GitHub clone 代理属于临时手段；不要把不可信代理用于更新包/可执行文件。

## 9. 更新联调

自定义 generic feed：

```powershell
$env:UPDATE_FEED_URL="https://your-mirror.example.com/lrm/"
pnpm dev
```

注意：开发态默认 `unsupported`，设置 `UPDATE_FEED_URL` 才会走更新流程。镜像目录至少需要：

```text
latest.yml
local-resource-manager-<version>-win-x64-setup.exe
local-resource-manager-<version>-win-x64-setup.exe.blockmap
```

## 10. Git / 发布检查

```powershell
git status
git diff --check
git log --oneline -10
git ls-remote --tags origin "v*"
```

发布前确认：

- 版本号与 tag 一致；
- 远端 tag 指向预期提交；
- Release 是否已存在；
- 仓库是否 public；
- 默认分支是否为 `master`。

## 11. 常见命令组合

```powershell
# 提交前
pnpm --filter desktop typecheck
pnpm --filter desktop lint
apps/backend/.venv/Scripts/python -m pytest -q apps/backend/tests

# 发布前
pnpm release:win

# 只查文档/文件
git status
git diff --check
```
