# 38 · 技术：发布组命名的清洗规则与置信度

> 来源：`smart_import/title_clean.py`。把 `[VCB-Studio] Sousou no Frieren [01][Ma10p_1080p][x265_flac]` 收成可读标题。

## 处理顺序

1. **切方括号段**：`[...]` `(...)` `（...）` `【...】`
2. **逐段判噪音**：把段内按非字母数字切 token，全部命中噪音词表就算噪音
3. **首个短且无中文的段**视为发布组（`[VCB-Studio]`、`[Lilith-Raws]`）
4. **中文字幕组标记**：含 `字幕组/字幕/压制/搬运/生肉/熟肉/汉化/翻译` 也算噪音
5. **季节/集标记**（仅系列作品标题）：`S01` `S01E02` `Season 2` `第2季` `EP05` `Episode 5`
6. **尾部集号**：`- 01` / ` 01` / `第05话` / `第3集`，保留时归一成两位
7. **收尾**：压空白、去掉两端 `-–—_·.`

噪音 token 表分七类：分辨率、编码/位深、音轨、来源、语言/字幕、容器、站点。分开列的理由是它们会以任意组合出现（`[AVC AAC]`、`[WEB-DL 1080p]`）。

## 置信度

```python
confidence = min(0.95, 0.55 + 0.1 * len(removed))
```

- 剥掉 3 段 → 0.85，正好过「默认勾选」线
- 剥掉 1 段（只去了个集号）→ 0.65，落在中间档，需要用户自己勾
- **什么都没有可剥 → 0.0 → 不产生建议**（避免把干净标题也列出来）
- 全被剥空 → 回退原名称，置信度 0.1

## 一个必须按类型分的决定

| 类型 | 集号处理 | 理由 |
|------|----------|------|
| 番剧 / AV | **移除** | 集号在季/集树里，作品标题不该带 |
| 单文件视频 / 图片 | **保留** | 每个文件就是一条资源，编号是唯一区分依据 |

不加这个区分会出事故：一次导入多集，全部被改成同名 `夏日海边`，再也分不出第几集。所以 `clean_release_name(raw, keep_episode=...)` 的默认值是 `True`（不丢信息），只在系列作品标题里传 `False`。

## 目录名优先

番剧目录通常比单集文件名干净，所以先清洗目录名；**只有置信度 ≥ 0.5 时**才压过文件名结果，否则回退。避免目录名是 `273` 这种纯编号时把好标题覆盖掉。

## 教训

1. 规则清洗的关键不是"聪明"，是**可解释**：每一段被去掉的东西都要能说出来。
2. 置信度不要凭感觉，用"剥掉了几段"这种可数指标，天然分档。
3. 「无内容可清洗」不产生建议，和「清洗失败回退原名」是两条不同的分支，别合并。
4. 集号该不该留，取决于**资源粒度**，不是取决于文件类型名称。
