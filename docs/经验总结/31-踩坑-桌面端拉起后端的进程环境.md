# 31 · 踩坑：桌面端拉起后端的进程环境

> 来源：`pnpm dev` 起不来；番剧/TMDB 刮削全部 `ConnectError` 而 B 站正常。

## 现象一：`electron.app` 是 undefined

```
TypeError: Cannot read properties of undefined (reading 'getVersion')
    at Object.<anonymous> (apps/desktop/out/main/index.js:523:31)
    at node:electron/js2c/node_init:2:18159
```

栈里明明是 Electron 在跑，`electron.app` 却不存在。

### 根因

环境变量 **`ELECTRON_RUN_AS_NODE=1`** 被继承了。本机的编辑器/终端宿主本身就是 Electron 应用（DSH 也是），它拉起的子进程会带着这个变量。Electron 看到它就以**纯 Node 模式**启动，`electron.app` 自然没有。

### 修法

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
pnpm dev
```

## 现象二：境外站点全部 ConnectError，国内站点正常

```
直连：bilibili 200 / baidu 200 / api.bgm.tv 000 / api.themoviedb.org 000
```

系统代理是开着的（`ProxyEnable=1`, `127.0.0.1:7890`），但**后端进程不继承 Windows 的"系统代理"设置**——那是浏览器/系统级配置，httpx 只读 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量。

### 修法

后端启动时读一次注册表，注入到进程环境：

```python
# app/shared/proxy.py
def apply_system_proxy() -> str | None:
    # 已显式配置 HTTPS_PROXY 则尊重现值，不覆盖
    # 读 HKCU\...\Internet Settings 的 ProxyEnable / ProxyServer
    # 写入 HTTP_PROXY / HTTPS_PROXY，并把 127.0.0.1,localhost 加进 NO_PROXY
```

在 `lifespan` 最前面调用，保证早于任何出站请求。`NO_PROXY` 必须包含本机地址，否则后端调自己的 `/health`、调 Ollama 都会被绕进代理。

## 教训

1. **sidecar 进程不继承宿主应用的"系统级"配置**：代理、证书、编码、locale 都要显式传。
2. 排查网络问题先分层：**进程有没有配代理 → 代理端口通不通 → 代理能不能出站 → 目标站点通不通**。本次是「进程没配代理」+「代理节点本身不通」两层叠加，只修一层仍然全红。
3. `CONNECT ... 200` 只说明本地代理接受了隧道，隧道里收不到 TLS 响应说明**上游节点不可用**，与本应用无关。
4. 被 Electron 应用拉起的终端，先查 `ELECTRON_*` 变量再怀疑构建产物。
