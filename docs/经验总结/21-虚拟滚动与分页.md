# 21 · 虚拟滚动与分页

> 正式学习向设计见 [design/06-虚拟滚动与分页.md](../design/06-虚拟滚动与分页.md)。  
> 实现前契约草案：[design/05](../design/05-资源分页与无限滚动.md)。  
> 本文只收口：**原则 + 代码入口 + 踩坑**。

## 原则（背下来）

1. **虚拟滚动管 DOM，分页管内存/磁盘。** 只做一层不够。
2. 下一页看 **已加载 `items.length`**，不要用全库 `total` 当虚拟列表 `count`。
3. 网格 **不发 HTTP**；`useResourcePage` 管 `hasMore` / 单飞 / 过期响应。
4. 列数、行高是 **Card 布局契约**，TanStack 算不了，换库也消不掉。
5. 滚动必须发生在 **固定高度** 的 `overflow: auto` 容器上。

## 三层规模

```
SQLite 全库  --limit/offset-->  items[]  --TanStack-->  DOM 几十张卡
```

## 踩坑（我们真实遇到的）

| 现象 | 原因 | 处理 |
|------|------|------|
| 启动失败 sentinel column | `Mapped[int \| None]` 主键 | `Mapped[int]` + autoincrement |
| `created_at` NOT NULL | ORM 插入显式 NULL | 仓储写时间戳 + server_default |
| 封面极慢 / 空白 | picsum 远程 + CSP | 本地 SVG data URI |
| 每次启动都「初始化库」 | 日志/seed 语义不对 | 有库则连接；无库才创建+seed |
| 改后端不生效 | Python 无 HMR | 重启 `pnpm run dev` |

## 验收一眼看

Network：首屏一页；再滚才第二页。  
Elements：卡片节点数约一屏，不是 200。
