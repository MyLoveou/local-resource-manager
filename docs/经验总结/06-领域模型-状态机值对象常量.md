# 06 · 领域模型：状态机 + 值对象 + 常量

## 实体 vs 值对象（DDD 落地）

| 归类 | 本项目的类 | 依据 |
|------|-----------|------|
| **实体** | Resource / ResourceFile / ScrapeJob / Candidate / DownloadTask / Tag / SiteAdapter | 有 id、生命周期、可变状态 |
| **值对象** | `Rating`（0-10 约束）、`Dimension`（宽高比）、`Progress`（进度） | 不可变、按值语义、内聚行为 |
| **常量枚举** | `Protocol` / `DownloadEngine` / `AdapterKey` / 各状态枚举 | 防散落裸字符串 |

## 状态机方法（核心价值：非法迁移在领域层拦截）

`app/shared/errors.py`：

```python
class DomainError(Exception): ...
class InvalidStateError(DomainError): ...   # 状态机边界抛这个
```

`app/download/domain/models.py`：

```python
class DownloadTask(ApiModel):
    """状态机：queued → running ⇄ paused → done / failed"""
    def _transition(self, target, *allowed):
        if self.status not in allowed:
            raise InvalidStateError(f"cannot go {self.status} → {target}")
        self.status = target
        self.updated_at = datetime.now()

    def start(self):      self._transition(RUNNING, QUEUED, PAUSED)
    def pause(self):      self._transition(PAUSED, RUNNING)
    def resume(self):     self._transition(RUNNING, PAUSED)
    def mark_done(self):  self._transition(DONE, RUNNING, QUEUED)
    def mark_failed(self, error): self._transition(FAILED, QUEUED, RUNNING, PAUSED); self.error = error
```

同理：`Resource.to_trash/restore/mark_lost`、`ScrapeJob.start/finish/fail`。

**红线**：方法里只放领域规则/状态迁移/计算属性，**绝不写 SQL/HTTP/IO**（那是 infrastructure 的活）。

## 值对象（不可变，实体暴露"只读视图"）

```python
@dataclass(frozen=True)
class Progress:
    downloaded: int
    total: int | None
    speed: int = 0
    @property
    def percent(self) -> float | None:
        if self.total and self.total > 0:
            return min(100.0, self.downloaded / self.total * 100)
        return None
```

实体保留原始列（适配 DB/API），值对象作为"行为透镜"：

```python
@property
def progress(self) -> Progress:
    return Progress(self.downloaded_bytes, self.total_bytes, self.speed)
```

## 常量收口（避免硬编码）

`app/shared/constants.py`：

```python
class Protocol(str, Enum):
    HTTP = "http"; FTP = "ftp"; MAGNET = "magnet"; TORRENT = "torrent"

class DownloadEngine(str, Enum):
    ARIA2 = "aria2"; RQBIT = "rqbit"; YTDLP = "yt-dlp"

PROTOCOL_TO_ENGINE: dict[Protocol, DownloadEngine] = {
    Protocol.HTTP: DownloadEngine.ARIA2,
    Protocol.MAGNET: DownloadEngine.RQBIT, ...
}
```

模型字段用枚举：`protocol: Protocol = Protocol.HTTP`。前端对应 `domain/constants.ts`（const 对象 + 联合类型）。

## 契约：snake_case ↔ camelCase

`app/shared/models.py` 统一基类，**数据库 snake_case、API JSON camelCase、前端 TS camelCase**：

```python
class ApiModel(BaseModel):
    model_config = ConfigDict(alias_generator=to_camel, populate_by_name=True)
# 后端写 cover_path，序列化输出 coverPath，前端读 coverPath —— 三层一致
```

**单一事实源**：后续用 openapi-typescript 从 FastAPI 自动生成前端类型，杜绝手工双维护。

## 平衡原则

- 只在此处有**行为/校验/不变式**时才抽值对象；路径/URL 这类裸字符串不抽。
- 前端 `domain/` 保持 interface（API 契约 DTO），行为放 hooks/store；纯逻辑才用 class。
