# v0.2.0 · 本地 AI 搜图与检索解释

本次版本把 AI 搜图从“能搜”推进到“能看图、能解释、能继续找相似”。所有图片、向量和查询都在本机处理，不上传云端。

## 新增

### AI 中心

- 新增独立的 AI 中心，集中管理模型、索引、任务和搜索。
- 新增中文 CLIP + YOLOv8n 本地索引，支持用中文描述搜索图片，并提取人数、横竖方向、场景/动作/颜色/物体等特征。
- 顶栏增加 AI 状态和入口；侧栏改为“浏览 / 视图 / 组织 / 工具”分组。

### 以图搜图与图文融合

- 支持库内图片找相似：综合、语义、近似重复三种模式。
- 支持外部图片：文件选择、拖放、剪贴板粘贴。
- 支持图文融合：以查询图为基础，再叠加“红帽子 / 室内 / 两个人”等文字条件，使用 RRF 合并结果。
- 近似重复使用 dHash，相似使用 CLIP 视觉向量；查询图不会出现在结果中。

### 本地 VLM 文案与标签

- 可选接入本地 Ollama VLM，推荐 `qwen2.5vl:3b`，不随安装包捆绑。
- 支持分析图片文案、短标题、标签、场景、动作、颜色、服饰和 OCR 文本。
- 支持在 AI 中心下载/切换 Ollama 视觉模型；模型可放在 D 盘。
- 新增 D 盘安装脚本：`scripts/setup-ollama.ps1`。

### 检索解释

- 文搜图显示原始查询、交给 CLIP 的语义文本、人数/方向/标签硬条件和检索路径。
- 图搜图显示查询图的图片文案、CLIP 标签、VLM 标签、YOLO 人数和方向。
- 每张结果卡片显示匹配依据：CLIP 相似度、命中的硬条件，或 dHash 近似重复差异。
- 解释展示的是可观察的检索信号，不伪装成模型内部思维链。

## 改进

- 索引重建期间禁止搜索和相似检索，避免返回半成品结果。
- 搜索和找相似显示 `已索引 / 匹配 / 返回` 数量，以及当前过滤条件。
- 图片查看器、Inspector 和 AI 中心都可以进入找相似。
- 修复窄窗口筛选栏换行、设置页更新入口同步等问题。
- 修复部分 AI 和人物编辑错误提示的编码问题。

## 升级说明

- 数据库会自动迁移到 schema 28，新增 AI 向量、属性、hash、文案/标签表；原有图库数据不删除。
- 中文 CLIP 和 VLM 模型不随安装包提供，首次使用需在 AI 中心下载或按脚本安装。
- VLM 文案需要主动分析；未分析图片仍可参与 CLIP 文搜图和图搜图，解释中会明确说明。
- 当前文案尚未接入文本检索排序；学习型重排器（LTR）只有设计文档和后续计划，本版本未实现。
