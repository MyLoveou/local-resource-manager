# v0.3.0 · 提示词工作台

新增「提示词」模块：在应用内选标签、拼提示词、存成可检索的存档，并把 PromptForge 的能力原生化。
同时接入 Danbooru 标签数据，安装包不再内置提示词库，改为按需导入。

## 新功能

- **提示词工作台**：模型切换（Anima / MOSS，前缀自动跟随）、正负双编辑、权重 0.1 步进、复制正面/负面。
- **内置标签库**：25 个分类、2956 个标签，中/英/全拼/首字母搜索。
- **Danbooru 数据**：10,833 条，分五类——热门、画师（自动加 `@`）、角色、作品、元信息，带使用量并按热度排序。
- **存档**：保存、载入、删除、收藏字段、风格预览图（384px JPEG）；载入时自动剥离模型前缀、还原权重、去重。
- **导入导出**：存档与内置库各有一对导出/导入；导入兼容 PromptForge 的导出 JSON，按正向内容去重。
- **成人向开关**：默认关闭，关闭时隐藏 NSFW 分类与被标记的 Danbooru 标签；状态存在数据库。
- **安装包瘦身**：内置提示词库不再打进安装包（约省 1.9 MB），首次使用通过「导入内置库」补齐。

## 修复

- 保存提示词返回 422：模型参数是文案字符串，而接口要求对象。现在两者都接受。
- 模型前缀以逗号结尾导致 `safe,, petite` 双重逗号。
- 保存弹窗样式失效（naive-ui 把弹窗 teleport 到 body，scoped 样式不生效），原生文件控件外露。
- 侧栏缺少「提示词」入口（路由没有归入任何菜单分组）。
- 提示词图标与 AI 中心重复。

## 升级说明

- 数据库 schema 32 → 39，旧库启动时自动迁移。
- 本项目当前版本已清空媒体库数据，首次启动会重建空库。
- 提示词库需手动导入：`导入导出 → 导出内置库`（开发环境）或使用随包分发的 `prompt-library-*.json`。
