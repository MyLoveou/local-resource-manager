# v0.2.6 · 重建 0.2.5 的发布

v0.2.5 的 tag 已推送，但构建在测试阶段失败，没有产出安装包。本版本修复导致失败的测试环境依赖并重新发布，功能内容与 v0.2.5 相同。

## 修复

- `test_auth` 自带临时数据库并执行迁移。此前它依赖本机已有的开发库，CI 上会报 `no such table: files`；这个问题在本地被开发库掩盖了很久。
- `test_ai_search` 在用例内固定 `is_installed()` 为真。这些用例本来就用假向量验证检索逻辑，不该因为 CI 没下载 CLIP 模型而失败。

## 与 v0.2.5 相同的功能内容

- 播放进度与续播：首页「继续观看」、按集记录、播到 95% 视为看完。
- 智能导入（S1）：名称清洗、源名称保留、建议分组审阅与批量采纳。
- AI 建议闭集化：标签只取自词表、分类由同标签资源投票并支持 CLIP 近邻兜底、AI 新词单独展示并尝试映射近义标签。
- 番剧分区开启。
- 修复：番剧选集无法播放、首页番剧封面空白、蜜柑把数字 id 当标题、Open Graph 属性顺序导致标题/封面丢失、刮削渠道互相挤占、后端不走系统代理、AI 建议长标题溢出、源码中文被写成问号。

## 升级说明

- 数据库 schema 30 → 32，旧库启动时自动迁移。
- 若你已安装 v0.2.5（未产出安装包，实际不可用），直接安装本版本即可，数据无损。

## 测试

- typecheck、lint、electron-vite build、文件规模检查通过。
- 本版本额外确保：无本机开发库、无 CLIP 模型的环境下同样通过。
