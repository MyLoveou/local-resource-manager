# v0.2.7 · 重建 0.2.5 的发布（第二次修正）

v0.2.5 与 v0.2.6 的构建都在测试阶段失败，均未产出安装包。本版本修正遗留的测试环境依赖，功能内容与 v0.2.5 相同。

## 本次修复

- `test_ai_search` 漏掉了第二个模块的绑定。`service.py` 与 `search.py` 各自执行了 `from ...model_store import is_installed`，只 patch 前者时，检索路径（similer / fusion / text search / feedback / 人数过滤）仍然走真实检查，在没下载模型的 CI 上抛「请先安装 AI 模型」。现在两处都固定为真。

## 前一次修复（v0.2.6 已包含）

- `test_auth` 自带临时数据库并执行迁移，不再依赖本机存在开发库；CI 上曾因此报 `no such table: files`。
- `TemporaryDirectory` 使用 `ignore_cleanup_errors`，避免引擎持有文件导致清理失败。

## 功能内容（与 v0.2.5 相同）

- 播放进度与续播：首页「继续观看」、按集记录、播到 95% 视为看完。
- 智能导入（S1）：名称清洗、源名称保留、建议分组审阅与批量采纳。
- AI 建议闭集化：标签只取自词表、分类由同标签资源投票并支持 CLIP 近邻兜底、AI 新词单独展示并尝试映射近义标签。
- 番剧分区开启。
- 修复：番剧选集无法播放、首页番剧封面空白、蜜柑把数字 id 当标题、Open Graph 属性顺序导致标题/封面丢失、刮削渠道互相挤占、后端不走系统代理、AI 建议长标题溢出、源码中文被写成问号。

## 升级说明

- 数据库 schema 30 → 32，旧库启动时自动迁移。
- v0.2.5 / v0.2.6 未产出安装包，直接安装本版本即可，数据无损。
