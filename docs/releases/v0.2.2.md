# v0.2.2 · AI 文案稳定性修复

本版本修复长批次文案分析被截断、Ollama 偶发错误和旧任务记录干扰的问题。

## 修复

- VLM 输出被截断时，恢复已经完整的文案、短标题和标签，不再因为末尾 JSON 不完整而丢弃整张结果。
- 降低单次 VLM 上下文和输出上限，减少长批次分析时的显存和上下文压力。
- Ollama 返回临时 5xx 或网络错误时自动重试；仍失败才记录该图片。
- 文案分析继续只处理未分析图片；失败图片不会让整个任务静默停止。
- 任务历史支持手动清空，方便清理修复前留下的旧失败记录。

## 说明

- 之前产生的失败任务仍会保留在历史中，这是历史记录，不代表当前任务状态；可点「清空历史」删除。
- 文案分析和中文 CLIP 建索引仍然是两个独立操作。
- 模型不随安装包提供，Ollama 和视觉模型需要单独安装或下载。
