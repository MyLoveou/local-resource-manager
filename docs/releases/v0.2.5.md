# v0.2.5 · 续播、智能导入与 AI 闭集建议

本版本打通了「看了一半」这件事，把导入从「复制进库」升级为「先给建议再决定」，并让 AI 建议只对齐你已有的词表。

## 新增

- 播放进度与续播：记录每个文件看到哪，首页出现「继续观看」，再次打开自动续播；播到 95% 视为看完并归零。按「集」记录，一部番剧每一集各自独立。
- 智能导入（S1）：导入时清洗名称，剥掉发布组、分辨率、编码、音轨、语言、容器、CRC 和字幕组标记；系列作品的集号进季集树，单文件视频保留集号。原始文件名写入 `source_name`，改名后仍可追溯。
- 建议审阅：导入完成后可就地审阅，也可稍后从右下角「待审阅」进入；按建议值分组，≥85% 默认勾选，采纳后写回标题。
- AI 建议闭集化：标签只从你已有的词表里挑；分类建议由「同标签资源的分类」投票得出，没有标签时用 CLIP 近邻兜底；AI 造的新词单独一处展示，能匹配到近义标签时只建议你已有的那个。
- 番剧分区开启。

## 修复

- 番剧/AV 选集点击后无反应：系列播放器原本是空实现，现在复用视频播放器；未选集时给出明确提示。
- 首页概览里番剧封面空白。
- 蜜柑详情页解析失败时把番剧数字 id 当作标题写入（资源曾被改名成 `273`），且空标题不再覆盖已有标题。
- 蜜柑页面的 Open Graph 标签在 `content` 写在 `property` 之前时解析不到，导致标题与封面丢失。
- 刮削多个渠道共用一个结果上限，先返回的渠道会挤掉后面的结果；现改为各渠道独立。
- 后端进程不继承 Windows 系统代理，导致 Bangumi / 蜜柑 / TMDB 全部连接失败；启动时读取系统代理并排除本机地址。
- AI 建议里超长标题撑破布局。
- 源码中 30 处中文被写成问号（含用户可见的错误文案）。

## 升级说明

- 数据库 schema 由 30 升到 32：`0031` 增加播放进度表与音轨列，`0032` 增加源名称与导入建议表。旧库在启动时自动迁移，无需手工操作。
- 新增的 api 端点：`/library/resources/{id}/progress`、`/library/progress/resume`、`/library/import-suggestions`。
- 媒体流仍使用带签名的 URL，本版本修正了 AI 建议里缩略图未签名导致 401 的问题。

## 测试

- 后端 292 个测试通过（含 2 个子测试）。
- typecheck、lint、electron-vite build、文件规模检查通过。

## 未包含

- 每集封面与每集字幕（需要数据模型与播放器字幕轨，另行立项）。
- 系列作品的独立详情页。
- 已作为独立视频导入的特典，暂不支持事后归并为作品特典。
- 训练型 LTR、向量分类的预计算近邻表。
