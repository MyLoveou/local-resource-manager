## 3. 容易混在一起的三对

1. **画廊 vs 消费-看图 vs 图片网格**  
   网格是库视图；消费是打开一张；画廊往往是沉浸连看。A 可以先网格+单击详情，画廊后做。

2. **主题系统 vs 设计系统管理**  
   主题 = 本应用换皮肤。设计系统 = 用户的设计资产（token、规范、参考实现），可导出。不要做成同一个设置页除非你明确要合并。

3. **加密资源 vs 加密空间**  
   前者像给单条/单合集上锁；后者像第二个加密码的库。需要以后二选一或做成「空间含资源」。

## 4. 与「先 A」不冲突的读法

A 最小闭环建议只动这些模块的**子集**：

- 导入（图片/视频目录）
- 库列表 + 详情
- 回收站
- 消费：图预览 + 视频播放
- （可选很薄的）分类标签

合集、系列、音乐、小说阅读、加密、画廊沉浸、主题、下载器、抓取，都进路线图，但**不挡**「能扫能看能删」。
