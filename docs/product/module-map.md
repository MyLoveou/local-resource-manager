## 2. 两层：最低消费 vs 高级

**A-min（先做完再插队高级）** — 每种库类型：

| 库类型 | 导入 | 最低消费 |
|--------|------|----------|
| 图片 | 文件/目录复制 | 内置看图 |
| 视频 | 文件/目录复制 | 内置播放 |
| 番剧 / AV | 目录（或散文件）进作品 | 信息栏点一集/一条即播 |
| 音频 | 文件复制 | Howler 内置播 |
| 小说 | 文件复制 | 系统打开（阅读器另立项） |
| 游戏 | 默认扫描登记；可选复制 | 系统打开 launch |
| 模型 | 文件复制 | 内置 3D 预览（gltf/glb） |
| 漫画 | 目录复制一作（或 cbz 文件） | 系统打开（阅读器另立项） |

共用：列表、详情信息栏手填通用字段、回收站、打开所在位置（系统资源管理器定位文件）。

**A-plus（所有类型都能进能用之后）**：合集、词表治理、画廊沉浸、系列整理与规范命名、字幕组/女优等专用档案、自定义布局仍后置；其中**合集、词表治理、主题令牌的需求已于 2026-09-27 定稿**（`D-20260927-02/03/04`），待 L2/L3。搜排 LIKE、刮削第一刀（视频+番剧）、下载 HTTP 第一刀、壳层换肤已提前编码（待手验）。主题不等于设计系统资产。

**B / 远期**：工作目录；设计系统；提示词/Skill；加密；导出内容另定。

番剧/AV 的**结构**（作品≠每集一张卡）A-min 已落地。特典完善、双列表、批量重命名、字幕组、女优表仍为 **该类型 A-plus**。九类型最低消费见 `library-type-platform`（已合入）。

| 加密 / 设计系统 / 提示词 / Skill / 导出 | 见 facts | **远期** |

## 4. 容易混的三对

1. **最低看图 vs 画廊**：先能打开一张；沉浸连看后做。  
2. **主题 vs 设计系统管理**：皮肤 ≠ 用户的设计资产。  
3. **加密资源 vs 加密空间**：未定，保持远期。
