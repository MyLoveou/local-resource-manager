## 1. 总览

```
  获取                库内核                 消费
  ----                ------                 ----
  导入（A-min）       资源记录               按类型最低打开（A-min）
  下载器（A-plus）    系列（min→plus）       画廊沉浸（A-plus）
  元数据抓取（plus）  合集（A-plus）         阅读/播放的增强（plus）
                      分类 + 标签（plus）
                      回收站（A-min）
                      加密 / 导出（远期）

  壳与资产（可后做）
  ------------------
  主题 · 设计系统 · 提示词/Skill · 工作目录（B）
```

## 2. 两层：最低消费 vs 高级

**A-min（先做完再插队高级）** — 每种库类型：

| 库类型 | 导入 | 最低消费 |
|--------|------|----------|
| 图片 | 文件/目录复制 | 内置看图 |
| 视频 | 文件/目录复制 | 内置播放 |
| 番剧 / AV | 目录（或散文件）进作品 | 信息栏点一集/一条即播 |
| 音频 | 文件/目录复制 | 内置或系统播放 |
| 小说 | 文件/目录复制 | 内置阅读或系统打开 |
| 游戏 | 目录/启动文件复制或登记包 | 启动（可先系统打开/启动器最小集） |
| 模型 | 文件复制 | 预览或系统打开 |

共用：列表、详情信息栏手填通用字段、回收站。

**A-plus（所有类型都能进能用之后）**：抓取、下载、合集、搜索/词表治理、画廊沉浸、系列整理与规范命名、字幕组/女优等专用档案、主题、自定义布局。

**B / 远期**：工作目录；设计系统；提示词/Skill；加密；导出内容另定。

番剧/AV 的**结构**（作品≠每集一张卡）在 A-min 就要成立，否则无法「点一集播放」。特典分组、双封面列表、批量重命名、字幕组、女优表算 **该类型 A-plus**，可在其它类型最低消费之后再补（`anime-av-types` 实现时可切两刀）。

## 3. 模块表

| 模块 | 一句话 | 阶段 |
|------|--------|------|
| 导入 | 选一次，复制进库；按类型挂策略 | **A-min** 覆盖上表全部类型 |
| 回收站 | 软删/恢复/彻底删 | **A-min** |
| 最低消费 | 按类型打开/读/播/启动 | **A-min** |
| 系列（结构） | 作品一卡、能选集播放 | **A-min**（`anime-av-types` 第一刀） |
| 系列（整理与档案） | 规范名、增删集、字幕组、女优、双列表 | **A-plus**（同 change 第二刀或后续） |
| 分类和标签 | 检索与词表治理 | **A-plus**（M4） |
| 合集 | 用户自建一组资源 | **A-plus** |
| 画廊 | 图片沉浸连看 | **A-plus**（与最低看图分开） |
| 下载器 | 链接→任务→文件 | **A-plus**（M5） |
| 元数据抓取 | 站点回填 | **A-plus**（M3） |
| 主题系统 | 应用换肤 | 壳层，A-plus 或更晚 |
| 工作目录 | 不完整工作台 | **B** |
| 加密 / 设计系统 / 提示词 / Skill / 导出 | 见 facts | **远期** |

## 4. 容易混的三对

1. **最低看图 vs 画廊**：先能打开一张；沉浸连看后做。  
2. **主题 vs 设计系统管理**：皮肤 ≠ 用户的设计资产。  
3. **加密资源 vs 加密空间**：未定，保持远期。

## 5. 未决

- 漫画是否单独库类型，还是并入图片/小说。  
- 游戏 A-min 是「系统打开可执行文件」还是最小启动器。  
- 模型 A-min 是系统打开还是内置预览。
