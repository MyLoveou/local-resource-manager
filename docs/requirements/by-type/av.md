# AV（av） · 需求

> 类型配置：`series` 目录导入、`owned` 存储、系列播放器；结构同番剧，但元数据/演员维度独立。
> 默认分区可见；可在 `domain/visibility.ts` 隐藏。

## 1. 已实现

- 目录导入为作品，季/集/花絮结构可承载多文件作品。
- 内置播放器、合集/详情打开、封面与标签/分类。
- 通用合集、批量、回收站、搜索；作品卡可按集数排序。
- 元数据字段可手动编辑；抓取能力复用现有候选确认框架（是否启用取决于适配器）。

## 2. 部分实现 / 未实现

| 能力 | 状态 | 说明 |
|------|------|------|
| 专属站点刮削 | 未实现 | 没有 AV 专属适配器；SearXNG/反查图仍为后续 |
| 女优/男优/角色/作品维度 | 未实现 | R3 的演员/角色模型未做 |
| 多演员/双列表 | 未实现 | 当前用标签/描述过渡 |
| 自动识别番号/标题 | 部分 | 依赖手动 query/站点适配，未做完整番号解析 |
| 封面/剧照批量管理 | 部分 | 通用封面能力可用，AV 专属剧照流程未做 |

## 3. 候选

- AV 专属适配器与番号解析。
- 演员/女优/男优结构化字段与筛选。
- 双列表、演员页、作品关联。
- 与 R3 角色模型的关系：AV 的“演员”是现实人物，不应和虚构角色混表。

## 4. 明确不做

- 在线播放/分享。
- 自动抓取未确认的站点内容并写入。
- 把 AV 合并进 anime 类型。

## 5. 入口

- `features/anime-av-types/`（系列结构）
- `features/photo-management-next/`（R3/R4 角色/人脸方向）
- `features/metadata-scrape/`（通用抓取框架）
