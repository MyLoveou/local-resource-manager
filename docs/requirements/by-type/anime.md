# 番剧（anime） · 需求

> 类型配置：`series` 目录导入、`owned` 存储、系列播放器；一个 Resource 可包含季/集/花絮。
> AV 是另一个类型，不要混用；共用组织/播放见跨类型文档。

## 1. 已实现

- 目录导入为系列作品；季、集、花絮（extras）结构；按集播放。
- 目录级增量挂集、系列导入解释（`series-import-explain`）。
- TMDB / Bangumi / B站抓取，候选确认后回填标题、简介、封面、标签/目录。
- 封面：站点封面、抽帧、用户封面等通用能力。
- 分类、标签、合集、回收站、搜索；作品卡展示集数。
- 播放器统一由 `openResource` 分发；合集/主页/详情行为一致。

## 2. 部分实现 / 未实现

| 能力 | 状态 | 说明 |
|------|------|------|
| 角色/作品/扮演者维度 | 已实现 | `0023` 角色/作品、`0024` 扮演者（D-20261022-01）；番剧本身还未接入角色筛选 |
| 演员/角色筛选 | 部分 | 资源库/时间线/地图可按角色与扮演者筛选；番剧类型页未接入 |
| 自动选集/播放列表 | 部分 | 有系列选集；自动下一集/播放进度未确认 |
| 字幕批量匹配 | 未实现 | 以外挂字幕手动添加为主 |
| 多站点字段合并 | 部分 | 以候选确认为准；字段冲突未做自动合并 |
| 下载/自动追番 | OUT | 下载不自建，统一委托第三方 |

## 3. 候选

- 角色 CRUD、角色页、角色/扮演者多对多（R3）。
- 人脸识别落到扮演者（R4，需单独模型/性能设计）。
- 剧集级标签、片头/片尾跳过、观看进度。
- 番剧专属时间线/追番列表（当前可用合集/时间线规则过渡）。

## 4. 明确不做

- 内置 BT/HTTP 下载器。
- 自动识别未确认的站点资源并直接入库。
- 把 AV 的演员维度硬塞进 anime 标签。
