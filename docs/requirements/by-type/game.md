# 游戏（game） · 需求

> 类型配置：`package` 目录导入、默认 `indexed`（只登记路径，可选手动复制）、系统启动。
> 游戏不是“下载器”，也不默认托管大体积文件。

## 1. 已实现

- 目录登记、启动项/可执行文件识别（exe/bat/cmd/lnk）。
- 启动/打开；合集/详情统一消费入口。
- 封面：exe 图标、lnk、用户封面等通用能力。
- 分类、标签、合集、批量、回收站、搜索。
- 存储可选 `indexed`/`owned`；默认只登记，避免复制整个游戏。

## 2. 未实现 / 待确认

| 能力 | 状态 | 说明 |
|------|------|------|
| 启动参数/工作目录配置 | 部分 | 消费渠道支持命令模板；游戏专属参数 UI 未做 |
| 存档管理/备份 | 未实现 | 无存档路径模型 |
| 游戏时长/最近游玩 | 部分 | 消费事件有记录；游戏专用统计未做 |
| 多启动项选择 | 部分 | 包内 launch 文件/用户打开方式 |
| 游戏元数据刮削 | 未实现 | 无站点/本地扫描器 |
| 安装/卸载管理 | OUT | 只登记与启动，不接管安装 |

## 3. 候选

- 游戏库视图（封面墙、最近游玩）。
- 启动参数、工作目录、兼容层（Proton/Wine）配置。
- 存档路径与备份。
- 与工作目录/待办结合。

## 4. 明确不做

- 内置游戏下载/安装器。
- 游戏内覆盖层/修改器。
- 默认复制整个游戏目录。
