# 工作目录（work_directory） · 需求

> 类型配置：`directory` 登记、`indexed` 存储、系统打开；没有复制/导入扩展名。
> 定位是“工作上下文容器”，不是媒体库的重复副本。

## 1. 已实现

- 目录登记（只保存路径，不复制内容）。
- 工作台页面 `/work`；打开目录/文件。
- 备注/待办（work note/todo）与消费事件。
- 合集、分类/标签按通用资源模型可用（具体入口以页面为准）。
- 回收站、搜索等通用能力。

## 2. 未实现 / 待确认

| 能力 | 状态 | 说明 |
|------|------|------|
| 工作区文件树/编辑器 | 未实现 | 当前以系统打开/工作台为主 |
| 工作项/需求/状态管理 | 未实现 | 有备注/待办，不是完整项目系统 |
| 最近打开/工作上下文恢复 | 部分 | 有消费事件；没有工作区快照 |
| 批量移动/整理 | 未实现 | `indexed` 目录不应被默认移动 |
| 监视目录关联 | 部分 | 监视目录是独立设置，未与工作目录强绑定 |

## 3. 候选

- 工作区文件树、最近文件、快速打开。
- 工作项目/里程碑/任务（与个人知识系统连接）。
- 工作目录的软链接/路径修复。
- 安全边界：为 indexed 目录提供只读/可写策略。

## 4. 明确不做

- 复制整个工作目录入库。
- 内置 IDE/版本控制客户端。
- 把工作目录的任意文件都当媒体资源导入。

## 5. 入口

- `apps/desktop/src/renderer/src/views/Home`（工作区入口）
- `apps/backend/app/library/application/workbench.py`
- `features/work-consumption-hub/`
