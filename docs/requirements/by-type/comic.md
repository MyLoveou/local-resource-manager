# 漫画（comic） · 需求

> 类型配置：`package` 目录导入、`owned` 存储、系统打开；扩展名包含图片与 `cbz/cbr`。
> 当前是“漫画包登记 + 封面”，不是内置漫画阅读器。

## 1. 已实现

- 目录/图片包导入；`cbz/cbr` 及图片文件可形成漫画 Resource。
- 系统默认程序打开；合集/详情统一消费入口。
- 封面：cbz/图片页/用户封面等通用能力；按 `pageCount` 排序。
- 分类、标签、合集、批量、回收站、搜索。

## 2. 未实现 / 待确认

| 能力 | 状态 | 说明 |
|------|------|------|
| 内置漫画阅读器 | 未实现 | 当前 shell 打开 |
| 页顺序/双页/连续阅读 | 未实现 | 无阅读器交互 |
| 阅读进度/书签 | 未实现 | 无 |
| 漫画元数据刮削 | 未实现 | 无站点适配器 |
| CBR 支持 | 部分 | 封面/打开依赖系统/解压能力，未单独验收 |

## 3. 候选

- 内置阅读器（单页/双页/纵向连续、进度）。
- 目录当一本漫画的包模型（与 `image` 的边界需明确）。
- 漫画章节/卷结构化。
- 封面批量重选。

## 4. 明确不做

- 在线漫画源。
- 图片编辑器/嵌字/翻译。
- 把多张图片目录直接混入 image 类型当漫画。

## 5. 入口

- `features/library-covers-complete/`
- `features/library-type-platform/`
- `apps/backend/app/library/application/packages/`
