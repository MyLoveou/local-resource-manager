# B 站片源 Provider · 需求

> 状态：**已编码，待手验**（D-20260922-03；L2/L3 已写）  
> Feature ID：`bilibili-scrape`  
> 拍板：**D-20260922-03**

## 1. 问题

B 站下载件文件名对不上 TMDB。用户也需要在标题里没有 BV 时，**自己填 BV 号**去取稿件元数据。

## 2. 已确认收口

1. 现有 `/scrape` 确认闭环；不新服务、不新主流程骨架。  
2. 只给 **`video`**。`anime` 仍 Bangumi + 蜜柑。不登录、不下载原片。  
3. 视频渠道 = TMDB + B 站。能解析到 BV/av 时 B 站候选在前。  
4. 自动查询 = `title` + 主文件名。  
5. **手动查询：** 信息栏可填 BV / av / 视频页或 b23 短链；非空则必须能解析出稿件 ID，否则直接失败、不拿标题去糊搜。手填时 **force 新 job**，不复用旧候选。  
6. 无手填时：ID 来自标题/文件名则直取；否则关键词尽力，风控当空。  
7. 回填与第一刀相同；`scraped_source=bilibili:<bvid>`；`author` 空则写 UP。  
8. 无 TMDB Key 但 B 站有候选 → job 成功。  
9. 批量条不提供手填 BV（仍只按标题/文件名）。

## 3. 范围

### IN

- `BilibiliProvider`；键 `bilibili:BV…`。  
- `POST /scrape/jobs` 可选 `query`（手填串）。  
- job 持久化查询hint，worker 能读到。  
- 信息栏（仅视频）输入框 + 获取元数据带上 query。确认队列内可改 BV 再搜。  
- 封面精确白名单加 B 站图床。  
- 单测：解析 BV/链接；手填无效 400；search 不写库；select 改标题。

### OUT

- 登录 Cookie；下载成片；分 P 拆集；anime/AV。  
- 批量手填每个 BV。  
- 用 B 站反查 TMDB；WBI 必达；设置页。

## 4. 用户故事

- **US-B.1** 文件名含 BV → 获取 → 第一项为该稿 → 确认后标题/简介/封面（非 user）。  
- **US-B.2** 无 ID 且关键词失败 → 不写库；可读原因。  
- **US-B.3** TMDB 与 B 站同时出现，可选 B 站。  
- **US-B.4** 未确认不改标题。  
- **US-B.5** 导入预搜不手填、不挡导入。  
- **US-B.6** 标题无 BV：在框里粘贴 `BV1…` 或视频 URL → 获取 → 该稿为候选并可确认。  
- **US-B.7** 框里填名称（无 BV）→ 按该名称搜 TMDB 与 B 站，不 400。

## 5. 验收

- [ ] US-B.1 / US-B.6 mock 或夹具。  
- [ ] 无登录、无 Cookie。  
- [ ] user 封面规则不变。  
- [ ] 番剧候选无 bilibili。  
- [ ] 手填非法串：400 或 job.failed，标题不变。

## 6. 复杂度

须 L2（已定稿）+ L3。
