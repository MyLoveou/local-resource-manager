# 封面治理 · 需求

> 状态：**已定稿**（D-20260919-03；L3 见 `实现方案.md`）  
> Feature ID：`library-covers`  
> OpenSpec：`openspec/changes/library-covers/`  
> **禁止编码**，等「可以按此实现」。

## 1. 问题

网格和信息栏靠 `thumbnailPath`（包内 `thumbs/grid.webp`）展示。没有缩略图就显示「无封面」，**禁止**用原图/海报 URL 撑列表。

| 类型 | 导入时封面从哪来 | 用户更换（现状） | 结果 |
|------|------------------|------------------|------|
| 图片 | 主文件即图 | 否 | 一般有卡面 |
| 视频 | 不抽帧 | 仅视频可换 | 未手选则无封面 |
| 番剧/AV | 视频当图失败 | 不能换 | 常无封面 |
| 音频 / 小说 / 模型 | 无自动 | 不能换 | 常无封面 |
| 漫画 | 第一页可回退 | 不能换 | 目录图一般有 |
| 游戏 | 仅目录 `cover/folder/poster` | 不能换 | 多数安装版无封面 |

## 2. 要解决的问题

1. 新导入的非图片资源尽量有作品级封面（未刮削）。  
2. 除图片外都能手指定本机图，并刷新网格缩略图。  
3. 游戏：手指定 > 目录海报 > exe 图标（含解析 `.lnk` 到 exe）。  
4. 手指定之后自动源**永远不再覆盖**。  
5. 旧库不回填。

## 3. 范围

### IN

- 更换封面：除图片外全部类型；`POST .../cover`；indexed 只写入包内小封面。  
- 导入自动封面（失败不挡导入）：  
  - 目录海报 `cover` / `folder` / `poster`（各 package/series/game 目录根）。  
  - 视频、番剧/AV：无海报则 **ffmpeg 抽一帧**（番剧/AV 用第一集）。  
  - 游戏：无海报则从 launch **exe 图标**；`.lnk` 解析到目标 exe 再抽。  
  - 漫画：仍可用第一页。  
- `extra` 记录封面来源；手指定后锁定。  
- TypeProfile 标明是否允许手换封面（图片否）。

### OUT

- 刮削；修图；模型渲染截图；监视目录。  
- **音频内嵌图、EPUB 封面**（进 `todo.md` 后续，不本刀）。  
- 旧资源批量补封面。  
- 每集封面（系列 A-plus）。  
- 改搜索/播放器；本刀不把 ffmpeg 打进安装包（与探测一致：没有则跳过）。

## 4. 游戏优先级（已锁）

手指定 > 目录海报 > launch exe 图标 > 无。  
exe / 解析后的 lnk 目标在**导入时**抽一次写入包内。`.bat`/抽失败：无自动封面。

## 5. 按类型

| 类型 | 本刀自动 | 手指定 |
|------|----------|--------|
| 图片 | 主文件 | 否 |
| 视频 | 抽一帧 | 是 |
| 番剧/AV | 目录海报，否则第一集抽一帧 | 是（作品级） |
| 音频 | 无（后续 todo） | 是 |
| 小说 | 无（EPUB 后续 todo） | 是 |
| 漫画 | 第一页 | 是 |
| 模型 | 无 | 是 |
| 游戏 | 海报否则 exe 图标 | 是 |

## 6. 用户故事

- **US-K.1** 新导入视频/番剧/AV：无海报也能因抽帧在网格见到图（本机有 ffmpeg）。  
- **US-K.2** 非图片 → 更换封面 → 网格与信息栏更新；之后导入逻辑或重抽不得改掉。  
- **US-K.3** 游戏无 poster：从 exe（或 lnk 指向的 exe）抽出图标。  
- **US-K.4** 无 ffmpeg / 抽图标失败 → 导入成功，「无封面」。  
- **US-K.5** 图片不能换无关封面。  
- **US-K.6** 旧库保持原样，不跑补抽。

## 7. 验收

- [ ] 非图片均可更换封面。  
- [ ] 新视频无海报：有 ffmpeg 则有缩略图。  
- [ ] 新番剧/AV：有海报用海报，否则第一集抽帧。  
- [ ] 新游戏：海报优先，否则 exe/lnk→exe 图标。  
- [ ] 手指定后任何自动路径不覆盖。  
- [ ] indexed 彻底删除不删源盘。  
- [ ] 列表只用 `thumbnailPath`。  
- [ ] 自动失败不挡导入；无旧库回填任务。

## 8. 契约草案

- 沿用 `POST /library/resources/{id}/cover`。  
- 不新增封面表。`resources.extra.coverOrigin`：`user` \| `folder` \| `frame` \| `exe` \| `page`。  
- 无新 REST 前缀。
