# 设计 · library-covers（L2）

> 状态：**已定稿**（D-20260919-03）  
> 施工图：`实现方案.md`。禁止编码直至「可以按此实现」。

## 0. 复杂度

跨导入、包内 cover/thumbnail、信息栏、TypeProfile、ffmpeg 抽帧、Win 快捷方式与 exe 图标。不可跳过 L2。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 列表只吃缩略图 | 卡面 = `thumbs/grid.webp` | 用 exe/视频流当 `<img>` |
| 封面是包内小文件 | 自动/手选都 `role=cover`（图片/漫画页回退除外） | 渲染进程读盘、抽图标 |
| 手指定锁定 | `coverOrigin=user` 后自动源永不覆盖 | 换 launch 默默换图标盖掉用户海报 |
| 新导入才自动 | 只在 ingest 成功路径抽 | 旧库扫描任务 |
| 失败不挡导入 | 无 ffmpeg / 坏 exe 则占位 | 因封面失败整单回滚 |
| 目录化 | 「可否手换封面」在 TypeProfile | `canChangeCover = isVideo` |

## 2. 模型

沿用 `Resource` + `files.role=cover|thumbnail` + `cover_path` HTTP。

新增（`resources.extra` JSON，不新建表）：

```text
coverOrigin: user | folder | frame | exe | page
```

不变量：

- **图片**：无 `cover` 角色；主文件即展示源；不允许 `POST cover`。  
- **手指定**：`replace_cover` 成功后 `coverOrigin=user`。此后 ingest 补图、任何「自动抽」入口若已是 `user` 则 **no-op**。  
- **自动写入**仅当尚无 cover 文件，或 `coverOrigin` 为空/非 `user`（新导入总是空）。本刀无改 launch UI，故锁定主要防：重复导入钩子、日后卫生脚本。  
- **优先级（游戏）**：已是 user → 停；否则目录海报 → 否则 exe 图标。  
- **优先级（视频）**：目录无海报概念（单文件）→ 抽帧。  
- **优先级（番剧/AV）**：作品目录海报 → 否则第一集（季号、集号最小的 episode 文件）抽帧。  
- 抽帧/抽图标产出先成静态图，再 `put_cover` + `put_thumbnail`。  
- indexed 游戏：封面与缩略图仍落在 `{store}/game/{id}/`，源盘 exe 只读。彻底删除只删该包。

不抽：音频内嵌、EPUB（后续 todo）。

## 3. 交互

### 手指定

非图片：信息栏「更多」与编辑弹窗「更换封面」（与现视频相同选文件 → `POST cover`）。  
成功：封面+缩略图更新，`library.bump`，`coverOrigin=user`。  
图片：入口不出现。

### 导入（用户无感知步骤）

复制/登记完成后、现有 thumbnail 流程前：跑「解析封面源」。失败打日志，资源仍 active。

无封面：网格「无封面」。

### 空态 / 失败

- 无 ffmpeg：视频/系列无海报 → 无封面，导入成功（与无 ffprobe 探测一致）。  
- exe 无图标 / lnk 目标不是现存 exe：游戏无自动封面。  
- `.bat`/`.cmd`：不抽图标。

## 4. 模块划分

| 模块 | 边界 | 不进入 | 依赖 |
|------|------|--------|------|
| TypeProfile | `allows_user_cover`（图片 false，其余 true） | 抽帧实现 | 前后端同名字段 |
| ingest 封面解析 | 选源、调用抽帧/抽图标、写 cover 行 | HTTP、UI | FileOps、ResourcePackage |
| 抽帧 | 后端调 PATH 上 `ffmpeg` 输出一张图 | 播放器、转码整片 | 与 `media_probe` 同超时风格 |
| 抽图标 | 后端读 exe 资源；lnk 先解析目标 | 主进程 ExtractIcon 每帧列表 | 仅导入线程 |
| replace_cover | 已有用例；补写 `coverOrigin=user` | 改 primary | 刷新 thumbnail |
| InfoPanel | `allowsUserCover` 替代 `isVideo` | 读 exe | 已有 pick 文件 IPC |

依赖方向：UI → REST cover；导入 → 领域解析 → 包布局。禁止渲染进程解析 PE/lnk。

## 5. 功能拆分（仍一刀交付，实现时按此顺序）

| 切片 | 可感知结果 |
|------|------------|
| A | 非图片可更换封面 + origin=user |
| B | 目录海报推广到 series/game（game 已有） |
| C | 视频/第一集抽一帧 |
| D | 游戏 exe 图标；lnk→exe |
| E | 锁定：user 不被自动覆盖（测试钉死） |

## 6. 抽象

**抽**：`resolve_cover_source(type, paths) -> (image_path, origin) | None`，再统一 `put_cover`。  
**不抽**：按类型各写一套 HTTP；为封面新建微服务；前端按类型复制换封面按钮。

抽帧约定（实现方案可改时间点，设计锁定语义）：取**约第 1 秒**；时长不足 1 秒则 0 秒；要关键帧以免黑屏可在 L3 用 `ffmpeg` 默认关键帧行为。只出一张 JPEG/PNG，再走现有 WebP 缩略图。

lnk：Windows 解析快捷方式目标；目标存在且为 `.exe` 才抽；否则无自动封面。非 Windows：不解析 lnk。
