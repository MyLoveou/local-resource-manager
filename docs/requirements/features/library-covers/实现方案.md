# 封面治理 · 实现方案（L3）

> 状态：**已落地**（代码已写；Electron 手测 T1–T10 待重启应用）  
> 拍板：**D-20260919-03**。L2：`设计.md`。

沿用现有 library 分层与包布局，不新开封面服务、不新建表。跳过 L2 的理由：无（已写设计）。

## 1. 对齐与约束

- API → `LibraryQueryService` → `ImportService` / `ResourcePackage` / `FileOps`；桌面 `TypeProfile.allowsUserCover` → InfoPanel。
- 渲染进程不读 exe/lnk、不调 ffmpeg。
- 列表仍只展示 `thumbnailPath`（`resolveCardImageUrl` 不回退 `coverPath`）。
- 失败不挡导入；无 ffmpeg 与无 ffprobe 同等降级。
- 不把 ffmpeg 打进安装包；旧库不回填；不抽音频内嵌/EPUB。

## 2. 本设计锁定

| 项 | 锁定 |
|----|------|
| 来源字段 | `resources.extra.coverOrigin`：`user` \| `folder` \| `frame` \| `exe` \| `page`。与已有 `importSourcePath` **合并**，禁止整表覆盖 extra |
| 手指定 | `POST /cover` 成功后 `coverOrigin=user`。图片 **422** `cover not allowed` |
| 自动写入 | 仅新导入；若已是 `user` 则跳过（单测钉死：先 user 再调自动函数不变文件） |
| 目录海报 | 作品/游戏**源目录根**（系列=导入文件夹；游戏=所选文件夹）：stem ∈ `{cover,folder,poster}` 且图片扩展名。沿用 `find_folder_cover` |
| 抽帧 | PATH 上 `ffmpeg`；超时 **30s**。`-ss`：探测时长 `<1` 则 `0`，否则 `1`。`-frames:v 1` 输出临时 jpg，再 `put_cover` + 现有 WebP 缩略图。无 ffmpeg / 非 0 退出 / 超时：无封面 |
| 番剧/AV | 先海报；否则 **季号、集号最小** 的 episode 文件抽帧（特典不参与） |
| 游戏图标 | 仅 `.exe`。`.lnk`：仅 **Windows** 解析本机目标，目标存在且后缀 `.exe` 再抽。`.bat`/`.cmd` 不抽。抽最大较合适的图标栅格，Pillow 转 png 再 put_cover |
| 图标库 | 新增后端依赖 **`pefile`**（读 PE 资源）；lnk 用 **stdlib 解析** Shell Link，不引入 pywin32 |
| 漫画 | 自动 `coverOrigin=page`（第一页）；可手换变 `user` |
| 图片 | 不写 cover 角色；不允许 POST cover |
| 音频/小说/模型 | 本刀无自动；仅手指定 |
| 系列 `cover_path` | 有 cover 文件时改为 `/library/resources/{id}/files/{coverFileId}/content`，**不再**把作品 `/content`（视频流）当封面 URL |

## 3. 领域 API（应用层）

新建 `app/library/application/covers/`（或单文件 `cover_ingest.py`，apply 时二选一，推荐包）：

```text
COVER_ORIGIN_USER = "user"
...

def merge_cover_origin(extra: dict | None, origin: str) -> dict

def is_user_locked(resource) -> bool
    extra.coverOrigin == user

async def attach_cover_image(...)  # put_cover、写 files、cover_path、origin、刷新 thumbnail
    若 is_user_locked → return

def extract_video_frame(video: Path, dest_jpg: Path) -> bool
def extract_exe_icon(exe: Path, dest_png: Path) -> bool
def resolve_lnk_target(lnk: Path) -> Path | None   # 非 Win 或失败 None
```

`ImportService` 各 `_ingest_*` 在现有 `_try_register_thumbnail` **之前或之内**调用统一 `apply_ingest_cover(...)`：

| ingest | 策略 |
|--------|------|
| file 图片 | 不 attach cover；thumbnail 仍 primary |
| file 视频 | `extract_video_frame(primary)` → origin=frame |
| file 音频/小说/模型 | 不自动 |
| series | `find_folder_cover(root)` → folder；否则第一集 dest → frame |
| comic | 现有第一页 fallback → origin=page（可只打 origin，缩略图仍走 cover_fallback） |
| game | folder cover（已有）→ folder；否则 launch 路径：exe 直接抽 / lnk 则 resolve 再抽 → exe |

临时抽帧/图标文件用完删除，失败不留半截 `cover.jpg`（先写 tmp 再 replace，与 thumbnail 一致）。

## 4. replace_cover

现有用例补：

1. `profile.allows_user_cover` 为 false（图片）→ `ValueError`，API **422**。  
2. 成功路径 `extra = merge_cover_origin(..., user)` 再 `update`。  
3. 仍刷新 thumbnail。

## 5. TypeProfile

后端 + 前端同名：

```text
allows_user_cover: bool   # 图片 False，其余 True
```

前端 InfoPanel：`canChangeCover = profileFor(type).allowsUserCover`（替代 `isVideo`）。  
「更多」里更换封面与弹窗 `allow-cover` 同一开关。

## 6. 数据流

### 导入自动

1. 向导选路径 → `ImportService` copy/probe 写 files。  
2. `apply_ingest_cover` 选源 → 静态图 → `put_cover` → `files.role=cover` → `cover_path` → `extra.coverOrigin`。  
3. `put_thumbnail(cover或回退图)`。  
4. 任一步异常 catch 日志，commit 已成功的资源行（封面步骤在 commit 之后则单独 commit 封面，失败只缺图）。

锁定顺序（避免无封面却已 commit）：**先抽到 tmp 成功，再写库封面行**；抽失败则跳过封面，资源已 commit 亦可。

### 手指定

1. 主进程选图片路径。  
2. `POST /cover`。  
3. 422 图片；400 非法扩展名（现有）；200 则 bump 列表。

## 8. 决策

| 决策 | 选择 | 不选 |
|------|------|------|
| 图标抽取 | 导入时后端 pefile + Pillow | 列表主进程 ExtractIcon |
| lnk | stdlib 解析 | pywin32 / PowerShell |
| 抽帧时刻 | 约 1s | 片中点（黑场仍可能，1s 足够本刀） |
| origin 存储 | extra JSON | 新列（免迁移） |

## 10. 风险

| 风险 | 缓解 |
|------|------|
| ffmpeg 抽到黑帧 | 本刀接受；不重试多时间点 |
| 部分 exe 无图标 | 占位无封面 |
| lnk 格式变种 | 解析失败当无自动 |
| extra 被其它 PATCH 丢掉 | PATCH 合并 extra，coverOrigin 键保留（若本刀触及 PATCH extra 则测） |

## 11. 明确不做

- 旧库回填
