> 主需求见 [local-resource-manager.md](local-resource-manager.md)。

## 2. M0 · 应用骨架与基础设施（P0）

**用户故事**
- US-0.1 用户启动应用 → 主界面打开，后端 FastAPI 服务由主进程自动拉起，失败时给出提示
- US-0.2 用户退出应用 → 后端服务随之退出，不留孤儿进程
- US-0.3 后端端口被占用 → 自动换端口或明确报错

**验收标准**
- [ ] 冷启动到主界面可见 ≤ 5s（不含首次装依赖）
- [ ] 应用退出后无残留后台进程
- [ ] SQLite 首次启动自动建库/迁移，失败可恢复
- [ ] 桌面端↔后端通信链路可配置（本机端口），默认不暴露外网

## 3. M1 · 资源扫描与入库（P0）

**用户故事**
- US-1.1 用户添加资源目录 → 扫描识别图片/视频文件，生成文件清单入库
- US-1.2 重复文件（相同哈希）→ 不重复入库，报告去重数量
- US-1.3 文件被移动/删除 → 库记录标记「文件丢失」，可一键重新定位或移除
- US-1.4 扫描大量文件 → 后台执行，可暂停/继续，UI 不阻塞并显示进度（**手动触发**：添加目录/启动时/手动按钮；常驻监视见 D-20260927-01）

**验收标准**
- [ ] 支持图片格式：jpg/png/webp/gif/bmp/heic/avif
- [ ] 支持视频格式：mp4/mkv/avi/mov/webm/flv/ts/m4v
- [ ] 视频抽取：时长/分辨率/编码/大小；图片抽取：宽高/大小/EXIF（拍摄时间）
- [ ] 十万级文件扫描不卡 UI，可中断且已扫描结果不丢失
- [ ] 扫描方式为**手动触发**（添加目录 / 启动时 / 手动按钮）；常驻监视仅限用户显式添加的源目录（D-20260927-01）
- [ ] 文件缺失/移动通过哈希重新关联（重定位）
- [ ] 权限不足/占用文件跳过并记录日志

## 4. M2 · 资源库管理与展示（P0）

**用户故事**
- US-2.1 打开图片库 → 网格视图缩略图展示，点击可预览大图
- US-2.2 打开视频库 → 卡片展示封面/时长/分辨率，支持本地播放（内嵌播放器 + 唤起系统播放器两种方式）
- US-2.3 点开详情页 → 展示完整元数据（标题/标签/简介/文件信息），可编辑
- US-2.4 目录树视图 → 与本地目录结构一致浏览

**验收标准**
- [ ] 图片网格缩略图懒加载，滚动流畅（万级）（缺口见 [grid-media-performance](grid-media-performance/需求.md)）
- [ ] 视频详情支持**内嵌播放器**与**唤起系统播放器**两种方式
- [ ] 元数据编辑可保存并持久化
- [ ] 删除/移动后的失效文件有明确视觉标记

## 5. M3 · 元数据服务（P0）

**用户故事**
- US-3.1 对资源执行「获取元数据」→ 后端按适配器搜索候选，返回候选列表（标题/封面/来源）；图片类以**文件哈希**为匹配键（无首选站点）
- US-3.2 选择候选 → 抓取详情并回填标题/封面/标签/简介，入库前可预览
- US-3.3 未匹配或抓取失败 → 提示原因，允许手动填写兜底
- US-3.4 批量选取资源 → 批量获取，逐个确认或跳过

**验收标准**
- [ ] 站点适配器接口化（插件式），新增站点不侵入核心流程
- [ ] 抓取具备超时/限速/失败重试，操作幂等可重复执行
- [ ] 图片类元数据匹配键 = **文件哈希**；**双路匹配**（反查图优先 + 哈希→搜索词兜底）
- [ ] 候选来源：SearXNG 自托管为主，商业 API 可插拔；图片来源走 OG 抓取器 / 图片专项适配器
- [ ] 封面等图片本地缓存，库内不依赖外部 URL 存活
- [ ] 无匹配时元数据可全手动填写
- [ ] 抓取来源与时间记录在库，支持审计

## 6. M4 · 检索与过滤（P1）

**用户故事**
- US-4.1 输入关键词 → 跨标题/标签/简介全文检索
- US-4.2 组合过滤（类型/标签/拍摄时间/时长/分辨率）→ 结果即时更新
- US-4.3 标签系统 → 打标、批量打标、按标签浏览
- US-4.4（**P1 增量，MS4.1**）词表治理 → 标签（及定稿后的分类）引用统计、删除无用词条；需求草案 [tag-category-hygiene](tag-category-hygiene.md)

**验收标准**
- [ ] 万级库搜索响应 ≤ 500ms
- [ ] 过滤条件可叠加、可重置
- [ ] 搜索结果支持排序（名称/时间/大小/评分）
- [ ] US-4.4 不纳入 MS4 完成定义；开放问题关闭且方案定稿前不实现

## 7. M5 · 下载管理（P1）

**用户故事**
- US-5.1 粘贴链接（HTTP/磁力）→ 创建下载任务
- US-5.2 任务列表 → 显示进度/速度/剩余时间，支持暂停/恢复/取消
- US-5.3 下载完成 → 自动触发扫描入库
- US-5.4 下载失败 → 自动重试（可配置次数），记录错误

**验收标准**
- [ ] 支持协议：HTTP/HTTPS、FTP/SFTP、BT/磁力、yt-dlp 站点兜底（HLS/DASH/m3u8）
- [ ] 支持并发任务数与带宽限制配置
- [ ] 断点续传（HTTP）
- [ ] 任务状态权威存于编排层 SQLite，重启可恢复
- [ ] 完成后文件自动进入资源库（可配置是否自动入库）

## 8. M6 · 设置与系统（P0）

**用户故事**
- US-6.1 管理资源目录（增删改、扫描）
- US-6.2 配置站点适配器（开关、参数）
- US-6.3 查看日志、导出/备份数据库

**验收标准**
- [ ] 设置修改即时生效或重启生效有明确说明
- [ ] 支持数据库导出/备份（SQLite 文件复制）

## 9. 边界与异常（跨模块）

- **空数据**：首次使用无资源目录、无搜索结果、空下载列表均有友好空态
- **权限**：扫描/读写被系统拒绝时，明确错误提示而非静默失败
- **并发**：扫描、抓取、下载可并行，互不阻塞 UI；写库串行化防锁冲突
- **网络**：抓取/下载断网时任务挂起或标记失败，恢复后可按配置续跑
- **错误提示**：所有用户可感知操作均有结果反馈（成功/失败/原因）
