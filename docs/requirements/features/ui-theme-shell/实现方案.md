# 壳层 UI 模块化与主题 · 实现方案（详细设计）

> 状态：**实现中**（用户已授权「可以按此实现」）

> 拍板：**D-20260918-01**。

## 1. 对齐与约束

- 只动桌面壳：`apps/desktop`。**不**改 FastAPI、SQLite、导入/播放契约。
- 分层：`ui/` 令牌与布局槽；`application/stores` 主题会话与批量壳状态；`main` + `preload` 读盘；`domain` 不出现色值。
- CSP 保持 `style-src 'self' 'unsafe-inline'`。外置主题用 **`<style>` 注入文本**，不用 `file://` 链 css（`default-src 'self'` 拦本地文件）。
- 用户 css **禁止当脚本执行**。不扫描主题目录、不叠多文件、不拉远程 URL。
- 与 `library-type-platform` **分 change / 分 PR**。本刀布局对所有 type 同一套槽。
- 三栏、信息栏默认不折叠（L1）不变。
- 软删 / 恢复 / 彻底删除 / 保存 / 导入语义与文案不改，只搬家或分区。

## 2. 本设计锁定

| 项 | 锁定 | 理由 |
|----|------|------|
| 外置 css | 任意本机路径、一次一份、仅 `.css` | 需求默认；不做主题目录扫描 |
| 内置 | `default` + `dark` 两份 css | 第二套验证令牌，不做第三套品牌 |
| 入口 | 顶栏「主题」菜单 | 设置页 M6 未做 |
| 批量条 | **ToolBar 右侧** | 网格首行腾给卡片 |
| 信息栏 | 身份 / 技术 / 编辑 + **底栏已有 footer 保留并令牌化** | 不改横向双栏 |
| 持久化 | Pinia persist → **renderer localStorage** | 不写 settings KV、不加表 |
| 读盘 | 主进程 `theme:readCss`，上限 **256 KiB** | 渲染进程无 Node fs |
| naive-ui | `NConfigProvider` + `themeOverrides` 映射 `--sm-*` | 不 fork 组件库 |
| overlay | 只吃全局令牌，本刀不精修 | 需求 OUT |

失败策略：读失败 / 空文件 / 超限 / 非 `.css` → `n-message` 提示，**保持上一套已成功主题**；启动时自定义路径失败 → 回退 `default` 并提示一次。

## 3. 领域模型（壳层，非后端聚合）

```text
ThemePack
  kind        'builtin' | 'file'
  id          'default' | 'dark' | 'custom'
  builtinId   'default' | 'dark'          // kind=builtin
  filePath    string                      // kind=file，绝对路径

TokenSheet    文档化的 --sm-* （§4）
ThemeSession  当前 Pack + 已注入 css 文本
ShellBatch    批量模式 + 当前页 browse|trash|none + 由 ResourceBrowser 绑定的动作
```

不变量：

- 同时只有一套 ThemePack 生效。切内置时卸掉 `#sm-user-theme`。
- `ShellBatch` 在 ResourceBrowser 卸载时 `unbind`，顶栏批量按钮消失，避免回收站动作打到已销毁页。
- 换肤不读写 `resources`。

## 4. 令牌契约

新增 `apps/desktop/src/renderer/src/ui/styles/tokens.css`（始终 import）。内置主题与用户 css **只覆盖这些变量**（可另写 `body` 背景，不另发明业务 class）。

| 变量 | 用途 | default | dark |
|------|------|---------|------|
| `--sm-color-bg-page` | 页面底 | `#f9fafb` | `#111827` |
| `--sm-color-bg-surface` | 顶栏 / 侧栏 / 信息栏 | `#ffffff` | `#1f2937` |
| `--sm-color-text` | 主文字 | `#1f2937` | `#f9fafb` |
| `--sm-color-text-muted` | 次要文字 / 空态 | `#6b7280` | `#9ca3af` |
| `--sm-color-border` | 分割线 | `#e5e7eb` | `#374151` |
| `--sm-color-primary` | 主按钮 / 强调 | `#4f46e5` | `#818cf8` |
| `--sm-radius-control` | 控件圆角 | `6px` | `6px` |
| `--sm-space-1` | 4px | `4px` | 同 |
| `--sm-space-2` | 8px | `8px` | 同 |
| `--sm-space-3` | 12px | `12px` | 同 |

`global.css`：`body` 用 `var(--sm-color-text)` / `var(--sm-color-bg-page)`。`variables.less` **本刀起不再作为换肤来源**；遗留 `@primary` 若仍被引用则改为 less 读 css 变量或删引用（只改本刀触及的壳文件，不扫全仓 overlay）。

本刀必须改成令牌的硬编码：`ToolBar` `#fff`/`#e0e0e0`；`InfoPanel` 边框/`#fff` footer；`MenuBar` 若有死色一并改。`ResourceBrowser` 去掉整条 `__batch` 后，残留 hint 用 muted 令牌。

### naive-ui 映射

`App.vue` 用 `NConfigProvider` 包现有 `NMessageProvider`。`themeOverrides` 在主题 apply 后从 `getComputedStyle(document.documentElement)` 读：

```text
common.primaryColor           ← --sm-color-primary
common.primaryColorHover      ← 同主色（本刀不另做 hover 令牌）
common.textColorBase          ← --sm-color-text
common.bodyColor              ← --sm-color-bg-page
common.cardColor / popover    ← --sm-color-bg-surface
common.borderColor            ← --sm-color-border
common.borderRadius           ← --sm-radius-control 的数字 px
```

暗色：内置 `dark.css` 把 `--sm-*` 改成深色；naive 用 **同一套 overrides**，不引入 `darkTheme` 对象双轨（避免两套真相）。若对比度不够，只改 `dark.css` 令牌，不改映射表。

用户 css 缺变量：未覆盖的保持 `tokens.css` 默认（级联）。不必校验「是否声明了全部变量」。

## 5. 主题加载与 IPC

### 5.1 主进程

`apps/desktop/src/main/infrastructure/themeCss.ts`（或并列 `themeIpc.ts`）：

- `ipcMain.handle('theme:readCss', path)`  
  - 必须是绝对路径；扩展名 `.css`（忽略大小写）  
  - `stat` 存在且为文件；`size <= 262144`  
  - `readFile` utf-8  
  - 去 BOM 后 trim 为空 → `{ ok: false, message: '…' }`  
  - 成功 `{ ok: true, css: string }`  
- 复用 `dialog:selectFiles`，filter `{ name: 'CSS', extensions: ['css'] }`，**单选**（`multiSelections` 对主题关掉：新增 `dialog:selectThemeCss` 返回 `string | null`，避免改坏导入多选）。

不解析 CSSOM、不跟随 `@import` 再读盘。远程 `@import` 受 CSP `default-src 'self'` 约束，预期失败即可，不在主进程拦。

### 5.2 preload

```text
selectThemeCss(): Promise<string | null>
readThemeCss(path: string): Promise<{ ok: true; css: string } | { ok: false; message: string }>
```

### 5.3 渲染

`ui/theme/applyTheme.ts`：

- 内置：`import defaultCss from '../themes/default.css?raw'`（及 dark）；写入 `<style id="sm-builtin-theme">`（或切换 class `data-theme=default|dark` 且两份 css 用 `:root[data-theme=…]`）。**锁定实现：`document.documentElement.dataset.theme = builtinId`，内置文件用选择器覆盖；自定义文件写入 `<style id="sm-user-theme">` 且同时 `dataset.theme=custom`。**
- 切自定义前记下上一成功 pack；失败不改 DOM。
- 切内置：移除 `#sm-user-theme`。

`application/stores/theme.ts`：

```text
pack: ThemePack
applyBuiltin(id)
pickFile()     // selectThemeCss + readThemeCss + persist
hydrate()      // 启动：file 则再读路径
```

persist 只存 `{ kind, builtinId?, filePath? }`，**不存 css 正文**（文件可能被用户改，每次启动重读）。

`main.ts`：`createPinia()` + `piniaPluginPersistedstate`（已有依赖未挂）。`hydrate` 在 `app.mount` 前 `await`（自定义主题避免先闪 default）。

菜单（ToolBar）：默认、暗色、从文件选择…、恢复默认。

## 6. 批量条迁顶栏

### 6.1 store

`application/stores/shellBatch.ts`（不 persist）：

```text
bound: boolean
context: 'browse' | 'trash'
total: number
busy: boolean
message: string
batchMode: boolean
enter / exit
emptyTrash / runBatch('trash'|'restore'|'purge')   // 由浏览器绑定
```

`selectedCount` 读现有 `selection.selectedIds.length`，不重复存。

### 6.2 ResourceBrowser

- **删除** `.resource-browser__batch` 整块。
- `onMounted` / `watch`：把当前页的 `isTrash`、`total`、以及现有 `enterBatchMode` / `exitBatchMode` / `emptyTrash` / `runBatch` 绑到 store。
- `onUnmounted`：`unbind` + `exitBatchMode`（与现逻辑一致，避免路由后顶栏仍显示批量）。
- 网格选中逻辑不变：仅 `batchMode` 时 toggle。
- `batchMessage` 可仍显示在网格上方一行 hint（非按钮条），或改到顶栏旁；**锁定：hint 仍留主区顶一行文字，不占按钮行。**

### 6.3 ToolBar

```text
[导入] ………… [批量簇] [主题 ▾]
```

批量簇规则与现网格条相同：无绑定或 `total===0 && !batchMode` 则不渲染按钮。文案/popconfirm 从 ResourceBrowser **原样剪切**，禁止改确认句（含「不删除你电脑上的原文件」）。

## 7. InfoPanel 分区

结构（同一组件，不拆路由）：

```text
aside.info-panel
  .info-panel-content
    .info-panel-body          // overflow auto
      section 身份    封面、标题、类型、indexed 源路径
      section 技术    季集树 或 格式/大小/创建/删除时间/分辨率等只读
      section 编辑    描述、作者、待办、评分、分类、标签
    .info-panel-footer        // 已存在：保存/打开/编辑/更多/回收站…
  .info-panel-empty           // 未选中
```

section 用小标题（「技术信息」「编辑」即可；身份区可不加标题以免重复标题）。颜色改令牌。`padding` 用 `--sm-space-3`。不改字段绑定、不改保存/删除函数。

封面仍在顶部；不改横向双栏。
