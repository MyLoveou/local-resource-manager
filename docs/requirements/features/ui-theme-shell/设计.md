# 设计 · ui-theme-shell（L2）

> 状态：**已定稿**（D-20260918-01；用户口令：按此设计写实现方案）  
> 与 `docs/requirements/features/ui-theme-shell/需求.md` 同范围。  
> 视觉方向：令牌换肤 + 布局分区，不是重做品牌插画。  
> **禁止编码**；施工图见同目录 `实现方案.md`。

## 0. 复杂度

命中：新抽象（令牌/主题包）、跨 ui/application/main IPC、主交互（换肤/批量条）、多文件。不可跳过 L2。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 令牌唯一着色 | 壳层色只来自 CSS 变量；naive-ui 从同一套变量映射 | 为换肤 fork naive-ui；业务页写死 `#fff` |
| 外置即文本 | 主进程读 css 文本，渲染进程注入 `<style>` | `file://` 链 css（CSP 拦）；远程 URL 皮肤 |
| 一份生效 | 同时只有一套主题 | 层叠多文件、扫描主题目录 |
| 布局槽不按 type | 批量条、信息栏分区对所有库类型相同 | 为游戏/漫画各做一套壳 |
| 三栏不折叠 | 信息栏默认展开 | 本刀做可关信息栏 |
| 行为不变 | 软删/保存/导入语义不动 | 改 API、改表 |

## 2. 模型

```text
ThemePack
  kind        builtin | file
  id          default | dark | custom
  label       中文
  source      内置模块 URL 或用户绝对路径

TokenSheet    :root 上的 --sm-* 变量（单一契约）
ThemeSession  当前 pack + 注入的 css 文本（失败回滚上一成功包）
ShellSlots    chrome（顶栏/侧栏/主区/信息栏）+ batch（顶栏右）+ panel sections
```

不变量：

- 换肤不改 `resources` / 导入 / overlay 打开逻辑
- 自定义 css 只应设置 `--sm-*`（以及可选 `body` 背景）；不执行脚本
- 文件体积上限（实现方案锁定，如 256KiB）；超限当失败
- 批量模式状态属于壳，不属于某个 type 页

持久化（拍板）：**Pinia persist（electron 渲染 localStorage）**，不写后端 settings 表（API 未做设置页）。存 `{ kind, builtinId?, filePath? }`。启动时若 file 读失败 → 回退 `default` 并记一次提示。

## 3. 交互

### 换肤

1. 顶栏「主题」菜单：默认、暗色、从文件选择、恢复默认  
2. 选文件：主进程单选 `.css` → 读文本 → 渲染注入  
3. 失败：naive 提示，保持上一套  
4. 重启：按 persist 再加载

### 批量

1. 网格内「批量删除」只切换 `shellBatch.batchMode`（回收站页同理「批量选择」）  
2. 真正的删除/恢复/清空按钮在 **ToolBar 右侧**  
3. 退出批量或路由离开类型页：关批量模式（已有 ResourceBrowser onUnmounted 可接到 store）

### 信息栏

- 上：身份（封面、标题、类型、源路径）  
- 中滚：系列树或技术只读；再编辑区（描述/作者/待办/评分/分类/标签）  
- 底固定：保存、编辑、更多、回收站/恢复/彻底删除、错误文案  

空选中：中部「未选择」仍占信息栏宽度。

## 4. 模块划分

| 模块 | 边界 | 不进入 | 依赖 |
|------|------|--------|------|
| `ui/styles` + `ui/themes` | 令牌契约与内置 css | 业务请求 | 无 |
| `application/stores/theme` | 当前包、apply/rollback | 读盘 | ipc `theme:readCss` |
| `main` theme IPC | 读本地 css、大小/扩展名校验 | 解析 CSSOM | fs |
| `ui/layouts/ToolBar` | 导入 + 主题菜单 + 批量按钮槽 | 调删除 API 细节可委托 handle | shellBatch / theme |
| `application/stores/shellBatch` | batchMode、页上下文（trash/browse） | 网格虚拟列表 | selection、library |
| `InfoPanel` | 分区 DOM | 换肤解析 | 令牌 class |
| naive `NConfigProvider` | 控件色映射 | 自定义皮肤引擎 | `--sm-color-primary` 等 |

依赖方向：layouts → application stores → infrastructure ipc。不反向。

## 5. 功能拆分

| 切片 | 可感知结果 | 本版本 |
|------|------------|--------|
| A 令牌 + 内置 default/dark + ConfigProvider | 菜单切换两套内置 | 是 |
| B 主进程读 css + 注入 + persist | 选文件换肤、重启保持 | 是 |
| C 批量条迁顶栏 | 网格顶不再放删除按钮组 | 是 |
| D InfoPanel 分区 + 底栏 | 滚动时操作仍在 | 是 |

顺序：A → B → C → D。A 不过不要做 B。

## 6. 抽象

**抽**：TokenSheet、ThemePack、ShellBatch 状态、InfoPanel 四个 section。

**不抽**：通用「插件主题市场」；CSS 预处理器主题编译；把 InfoPanel 拆成四个路由组件。
