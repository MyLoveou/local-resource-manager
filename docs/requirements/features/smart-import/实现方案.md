## 2. 数据模型

迁移 `apps/backend/app/shared/db/migrations/0032_smart_import.sql`：

```sql
-- 0032 · 智能导入：源名称 + 建议

-- 采纳改名后仍需可查原始名称（Q1）
ALTER TABLE resources ADD COLUMN source_name TEXT;

CREATE TABLE IF NOT EXISTS import_suggestions (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  job_id      TEXT,                                  -- 导入任务，用于向导内就地审阅
  field       TEXT NOT NULL
              CHECK (field IN ('title','category','season','episode','aiAnalysis')),
  value       TEXT,                                  -- JSON 编码的建议值
  confidence  REAL NOT NULL DEFAULT 0,
  source      TEXT NOT NULL
              CHECK (source IN ('rule','scrape','ai','history')),
  reason      TEXT NOT NULL DEFAULT '',               -- 必填语义：没有理由不展示
  status      TEXT NOT NULL DEFAULT 'pending'
              CHECK (status IN ('pending','accepted','rejected')),
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  decided_at  TEXT
);
CREATE INDEX IF NOT EXISTS idx_suggestions_job
  ON import_suggestions(job_id, status);
CREATE INDEX IF NOT EXISTS idx_suggestions_resource
  ON import_suggestions(resource_id, status);
```

要点：

- 建议**持久化**而不是内存态——「两处都要」（Q3）要求向导关闭后仍能继续审阅；
- `job_id` 让向导能只取本批次的建议；
- `reason` 非空才展示（L1 §8）；
- `value` 用 JSON 存，`category` 存 `{"id": 12, "name": "动漫截图"}`，`title` 存 `{"text": "..."}`。

## 3. 动作模型

```
library/application/smart_import/
├── __init__.py
├── base.py          # Suggestion / ActionContext / ImportAction 协议 / 注册表
├── title_clean.py   # 清洗引擎（纯函数，可单测）
├── pipeline.py      # 跑动作 + 落库
└── actions/
    ├── __init__.py
    └── title.py     # clean-title 动作
```

`base.py` 关键类型：

```python
@dataclass(frozen=True)
class ActionContext:
    resource_id: int
    type: ResourceType
    dir_name: str | None          # 番剧/AV 的目录名
    file_stem: str                # 主文件名（无扩展名）
    existing_categories: list[str]

@dataclass(frozen=True)
class Suggestion:
    field: str
    value: dict | None
    confidence: float
    reason: str
    source: str = "rule"

class ImportAction(Protocol):
    field: str
    applies_to: frozenset[ResourceType]
    def evaluate(self, ctx: ActionContext) -> list[Suggestion]: ...
```

注册表按 `type → [action]` 展开；新增类型只加一个模块并在 `__init__.py` 注册，**不改导入主流程**（L1 §3.1）。

## 4. 清洗引擎

`title_clean.py` 是纯函数，不碰 DB，便于单测与复用：

```python
@dataclass(frozen=True)
class CleanResult:
    title: str
    removed: tuple[str, ...]
    confidence: float

def clean_release_name(raw: str, *, prefer_ep: bool = False) -> CleanResult
```

规则顺序：

1. 切出方括号/圆括号段 `[...]` `(...)`，逐段判定是否为噪音
2. 噪音词表：发布组、分辨率（`1080p` `720p` `2160p` `4K`）、编码（`x265` `x264` `HEVC` `AVC` `H.264`）、音轨（`AAC` `FLAC` `AC3` `DTS` `mp4a`）、来源（`WEB-DL` `BDRip` `BluRay` `HDTV` `WEBRip`）、语言（`CHS` `CHT` `GB` `BIG5` `JPN`）、CRC（`[0-9A-F]{8}`）、站点水印
3. 去掉尾部集号 `- 01` / ` 01`（`prefer_ep=True` 时保留，供 `titleWithEp` 复用）
4. 归一空白与全角标点

**置信度**：命中噪音段数 `n`，`confidence = min(0.95, 0.55 + 0.1n)`；结果为空 → 回退原名，`confidence = 0.1`（L1 V4）；未命中任何噪音且结果等于原名 → **不产生建议**（避免噪音，L1 V12）。

**目录名优先（Q5）**：`actions/title.py` 先清洗目录名，若其 `confidence ≥ 0.5` 且非空则采用；否则回退文件名清洗结果。

## 5. 契约

### 5.1 拉取建议（分组）

```
GET /library/import-suggestions?jobId=&status=pending&limit=200&offset=0
→ data: {
    groups: [{
      field: "title" | "category" | ...,
      value: {...},            // 分组键
      source: "rule",
      confidence: 0.85,        // 组内最小值
      count: 128,
      reasons: ["去掉了 [VCB-Studio] 与 [Ma10p_1080p]"],
      suggestionIds: [1,2,3],
      sampleResourceIds: [533, 534]
    }],
    total: 128,
    appliedResourceCount: 0
  }
```

按 `(field, value)` 聚合，`confidence` 取组内**最小值**（保守：组里有一条拿不准就不算高置信）。

### 5.2 采纳

```
POST /library/import-suggestions/apply
body: { ids?: number[], groups?: [{field, value}], minConfidence?: number }
→ data: { accepted: 120, skipped: 3, updatedResources: 118 }
```

- `ids` 与 `groups` 二选一；`minConfidence` 与 `groups` 合用可做「只采纳 ≥0.85」
- 采纳即写 `resources.title` / 关联分类，并把建议置 `accepted`
- 分类值若已不存在 → 跳过并计入 `skipped`（不新建分类，L1 OUT）
- 采纳 `title` 时若 `source_name` 为空，先回填为当时的 `title`（保证 V11）

### 5.3 忽略

```
POST /library/import-suggestions/reject
body: { ids?: number[], groups?: [{field, value}], all?: boolean }
→ data: { rejected: 128 }
```

### 5.4 待审阅计数（顶栏角标）

```
GET /library/import-suggestions/summary
→ data: { pending: 12, highConfidence: 8, jobs: 2 }
```

## 7. 数据流

```
导入任务（hash → copy → probe → cover → thumb）
  → 每个资源落库后写 source_name = 原始文件名/目录名
  → pipeline.run(resource, ctx)
      → 按类型取动作
      → clean-title.evaluate()
      → 产出 Suggestion（无理由不产出）
      → import_suggestions 落库（pending）

向导任务完成 / 顶栏角标
  → GET /library/import-suggestions?...  （按 field+value 分组）
  → 勾选（≥0.85 默认勾）
  → POST .../apply { groups, minConfidence: 0.85 }
      → 逐条写资源标题 / 关联分类
      → 建议置 accepted
```

## 9. 风险

- **清洗误伤**：中文标题里也有 `[` 或 `- 01`。靠「未命中噪音不出建议」+ 置信分档 + 默认不勾来兜底，不靠规则完美。
- **分类不存在**：采纳时分类可能已被删除 → 跳过并计数，不自动新建（L1 OUT）。
- **建议膨胀**：一次导入几千张会写几千行。S1 只对 `title` 产生建议，量级可控；S2 加分类建议时必须先做批量上限。
- **`import_service.py` 门禁**：先拆再挂，拆完必须跑 `check:file-size` 确认净值 ≤ 828。
- **向导内审阅**：导入任务已完成，审阅只是 PATCH，不会回滚已复制的文件——需在 UI 上说清楚「忽略建议不会删除已导入的资源」。
