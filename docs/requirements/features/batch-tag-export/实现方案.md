## 数据流

- 打标：批量条输入标签 → `POST /library/resources/batch {action:"add_tags", ids, tagNames}` → 用例 `add_tags_union` → 计数 → 列表软刷新
- 导出：`POST /library/collections/{id}/export {targetDir}` → 读成员（顺序）→ 每成员找 primary 文件 → 复制为 `{idx:03d}_{安全标题}{ext}` → `{exported, skipped}`
