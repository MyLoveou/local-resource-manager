# 漫展返图工作流（批量打标 + 合集导出）· 需求

> 状态：**已定稿**（L1 · 2026-10-07，设计已确认并实现）
> Feature ID：`batch-tag-export`
> 上游：漫展 coser 照片管理场景；组织方式用户已拍板「**按 coser 建分类**（每个 coser 一个分类）」

## 1. 问题

用户从漫展带回大量 coser 照片（几百张/场）。组织方式（分类=coser、标签=角色/漫展名、合集=某场精选）**现有能力已覆盖**，但两个动作不可行：

1. **逐张打标**：几百张照片在信息栏一张张打标签不现实，现有批量操作只有 回收站/恢复/删除，没有批量打标
2. **返图**：把一场精选（合集）发给 coser，没有导出手段，只能去库目录手动翻文件

## 2. IN / OUT

| 做 | 不做 |
|----|------|
| 顶栏批量条「打标」：对选中资源批量**加**标签 | 批量删标签、批量替换标签 |
| 合集页「导出」：把合集成员主文件复制到用户选定的文件夹（按合集顺序编号命名） | zip 打包、导出封面/缩略图/字幕等附属文件 |
| 复用词表：标签不存在则创建（与单条打标一致） | 新建表/字段 |

## 3. 用户故事与验收

- **US-B.1** 批量打标：选中 50 张照片 → 批量条「打标」→ 输入「某coser」→ 保存 → 全部加上该标签
- **US-B.2** 导出合集：打开「C104 返图」合集 → 点「导出」→ 选文件夹 → 完成提示「已导出 N 个文件」→ 文件夹里文件按合集顺序命名（`001_标题.jpg`）
- **US-B.3** 空选择打标：未选中时按钮禁用
- **US-B.4** 导出空合集：提示「合集没有成员」不创建目录

## 4. 开放问题（默认已给，确认设计时可改）

1. 导出命名：`{序号3位}_{标题}{后缀}`（默认）vs 保留原文件名？
2. 导出范围：仅主文件（primary，默认）vs 含附属？
3. 批量打标输入：单次一个标签（默认）vs 多个（Enter 切词，与信息栏一致）？
