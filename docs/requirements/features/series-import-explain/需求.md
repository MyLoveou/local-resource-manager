# 系列导入说明 · 需求

> 状态：**已落地**（D-20260919-06；L2：`设计.md`）  
> Feature ID：`series-import-explain`  
> OpenSpec：尚未建 change  
> 上游：`anime-av-types` A-min 已能自动识别则入库；无法识别只 `skipped_error+1`，向导只显示「错误 1」  
> 对齐：A-plus 完整预览改映射 **不在本刀**

## 1. 问题

番剧/AV 目录导入：`plan_series_videos` 返回 `None` 时整夹不入库，原因只打后端日志。向导结束仍是 `status=done`，用户只看到「错误 1」，不知道是季目录混用、缺集号、还是集号冲突。识别成功时也不知道分成了几季几集。

## 2. 已按口令收口

1. 本刀只做 **只读说明**（将怎样分 / 为何失败），不改映射、不强制乱入。  
2. 不做字幕组、女优、批量改名、增删集、刮削。  
3. 仍禁止无法识别时静默建成乱作品。

## 3. 范围

### IN

- 后端对 `plan_series_videos` 的失败分类成稳定 **code + 中文 message**；可选列出最多 20 个文件名及该文件的问题（无集号 / 无季 / 与已有 SxxExx 冲突）。  
- 识别失败：job 仍可不建作品，但进度 DTO 必须带上这段说明（向导能读到，不能只靠日志）。  
- 识别成功：进度 DTO 带只读摘要（例如「1 季 · 12 集 · 2 特典」；可选再列前几条 `S01E01 ← 文件名`）。  
- 导入向导进度步展示上述文案；失败时醒目，成功时弱提示。  
- 单测：现有无法识别夹具必须断言 message/code，不能只断言 skipped_error。

### OUT

- 预览里改季/集再确认拷贝（完整整理 UI）。  
- 「按文件名排序强制成 S01」一键导入。  
- 新解析器（Anitopy 包）、字幕组字段。  
- 事后向作品追加/删集。  
- 改图片/视频/游戏导入。

## 4. 用户故事

- **US-E.1** 导入无法识别的番剧夹 → 向导写明原因（如「部分文件在 Season 目录、部分不在」），库中无空作品。  
- **US-E.2** 导入标准 Season 01 夹 → 向导显示将导入的集数（或已导入摘要），网格一张卡。  
- **US-E.3** 两个文件解析到同一 S01E01 → 说明冲突文件名，不入库。

## 5. 验收

- [ ] 无法识别：不建资源；向导有具体中文原因，不只「错误 1」。  
- [ ] 成功：能看出集数/特典数量（或等价摘要）。  
- [ ] 现有能识别的布局回归：仍自动入库。  
- [ ] 无新整理交互；无强制导入按钮。

## 6. 契约草案

沿用 `GET /library/imports/{id}`。建议给 `ImportJob` 增加：

- `message: str | null` — 给人看的一段话（失败原因或成功摘要）  
- 可选 `details: list[str]` — 文件级短行，上限 20  

`error` 可继续表示任务级崩溃。识别失败不是进程崩溃：`status` 仍可为 `done`，用 `skippedError` + `message`。

禁止：为预览新开第二段导入 API（本刀无确认步）。

## 7. 开放问题

无。强制导入与改映射明确 OUT，留给以后的整理刀。
