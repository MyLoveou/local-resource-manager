# 查看器跨页切图 · 需求

> 状态：**已落地**（D-20260919-08；L2：`设计.md`；L3：`实现方案.md`）  
> Feature ID：`image-viewer-cross-page`  
> OpenSpec：尚未建  
> 上游：`image-consume` US-C.3「只切已加载」；`image-viewer-ux`；列表 `useResourcePage` limit=80 keyset  
> 盘点编号：图片深化 **D4**

## 1. 问题

图片查看器的上一张/下一张（含左右键）只在 `playlistIds` 里走。打开时 playlist = **当前网格已加载**的 id（默认每页 80）。库里还有下一页时，最后一张的「下一张」按钮是禁用的，必须关掉查看器再往下滚网格。连看会被分页打断。

这是 `image-consume` 当时故意收口，不是漏实现。本刀把这条改掉。

## 2. 要解决的问题

在**当前筛选**（类型=图片、状态、关键词、排序、标签）下，查看器能一直切到该结果集的真正两端，而不是已加载页的两端。

## 3. 范围

### IN

- 图片查看器：在 playlist 末尾且列表 `hasMore` 时，「下一张」有效；拉下一页（同一套 `GET /resources` keyset）后继续切。  
- 「上一张」：已加载列表的第一张就是当前筛选的第一张（列表从首页往后追加），到头禁用，**不环绕**。  
- 拉到的页同时写入网格 `items`（关掉查看器后格子与切过的顺序一致）。  
- 靠近 playlist 末尾时**后台预拉**下一页（避免点下一张空等）。  
- 从信息栏封面打开：若该 id 已在当前网格列表中，用整份已加载 ids，不要只传 `[id]`。  
- 键盘左右键与按钮同一套规则。  
- 回收站图片页、图片搜索/排序结果：同一套（都走 `useResourcePage`）。

### OUT

- 画廊沉浸（N1）、幻灯片定时连看（N15）。  
- 视频/音频 overlay 跨页。  
- 新 REST 前缀；把整库 id 一次拉完。  
- 环绕到第一张。  
- D3 HEIC、D5 GIF、D2 回填。  
- 改 Viewer.js 交互（缩放/拖拽）。

## 4. 用户故事

- **US-D4.1** 打开第 80 张（当前已加载最后一张），点下一张 → 出现第 81 张；网格在背后已追加。  
- **US-D4.2** 打开第 1 张，上一张禁用。  
- **US-D4.3** 带关键词/标签/排序时，切图顺序与网格一致，不串到筛掉的图。  
- **US-D4.4** 没有更多时，下一张禁用（与「已加载全部 N 项」一致）。  
- **US-D4.5** 加载下一页失败：下一张仍可用重试或保持当前张，不关闭查看器、不丢已加载。  
- **US-D4.6** 看图中途列表 bump（导入等）按现有 reset：查看器关闭或 playlist 作废，不拿旧 id 硬切。

## 5. 验收

- [ ] 已加载不足 `total` 时，末张「下一张」可点，能看到尚未滚到的图。  
- [ ] 关闭查看器后，网格含刚才跨页加载的卡片。  
- [ ] 筛选变化后新打开的查看器跟新筛选走。  
- [ ] 不环绕。  
- [ ] 无新 API 路径（仍 `afterKey`/`afterId`）。  
- [ ] 单测或组件测：末张 + hasMore → 触发追加再前进。
