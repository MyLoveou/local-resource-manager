# 设计 · image-viewer-cross-page（L2）

> 状态：**已落地**（D-20260919-08）  
> 需求：`需求.md`。施工图：`实现方案.md`。

## 0. 复杂度

跨查看器 store、分页 hook、网格数据。不改库表。不可跳过 L2（playlist 与 items 必须同源，否则关查看器后网格错位）。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 一条列表 | 切图顺序 = 当前 `items` 顺序 | 查看器另拉一套 id |
| 按需翻页 | 与网格同一 `loadMore` | 打开时拉全库 |
| 不环绕 | 结果集头尾就是头尾 | 最后一张下一张回到第一张 |
| 筛选跟随 | q/sort/tag/status 来自当前页 browseQuery | 查看器自己记一套过期筛选 |

## 2. 模型（前端）

沿用 `useImageViewerStore.playlistIds`。打开时：

```text
playlistIds = 当前页已加载图片资源 id（与 ResourceBrowser 点卡时 ids(type) 相同）
```

信息栏封面：若 `items` 含该 id，传入全部已加载 id；否则 `[id]`（无法跨页，因没有列表游标）。

`hasNext`：

```text
index < playlist.length - 1  OR  列表 hasMore  OR  正在 loadMore
```

末张且 hasMore 时按钮**不禁用**；点击时若下一页还没到，先 `loadMore` 再 `next`。

`hasPrev`：仍仅 `index > 0`（第一页第一张之前没有 keyset `before`，本刀不新增）。

## 3. 数据流

1. 用户在图片（或回收站/搜索）网格二次点击 → `open(id, items.map(id))`。  
2. 切下一张：若 `index < last`，现有 `show(nextId)`。  
3. 若 `index === last` 且 `hasMore`：`await loadMore()`（`afterKey`/`afterId` 与网格相同），成功则 `playlistIds` 同步为新 `items` 的 id 列表，再 `show` 新的下一张。  
4. **预拉**：`current` 位于 `length - 2` 或 `length - 1` 且 `hasMore` 且未在飞，后台 `loadMore`，成功后只更新 `playlistIds`/`items`，不自动换图。  
5. 原图预取（已有 `Image()` 邻张）仍只针对 **playlist 内已有 id**，不预拉未分页的原图。  
6. `library.bump`：现有 `useResourcePage` reset；查看器 `close()`（与列表被重置一致，避免切到已不在结果里的 id）。

失败：`loadMore` 失败时停留当前张，下一张保持可点以便重试；不 toast 新体系（可用现有列表脚「加载失败，点击重试」语义：查看器内按钮再点即重试）。

## 4. 模块

| 模块 | 职责 | 不进入 |
|------|------|--------|
| `useResourcePage` | 暴露 `loadMore`/`hasMore`/`items`；可加 `ensureLoadedPast(id)` | 新 API |
| `imageViewer` store | `hasNext` 考虑 hasMore；`next` 可 async 等一页 | 自己 axios 列表 |
| `ResourceBrowser` | 打开查看器时绑定 loadMore；watch items → 打开中则刷新 playlist | 复制分页状态 |
| InfoPanel 封面 | 用当前页 items ids | 另开查询 |

依赖：查看器 → 页面 hook 的 loadMore。禁止 overlay 直接调 `getResources` 拼第二份游标。

绑定方式（L3 二选一，推荐 A）：

- **A** 在 `ResourceBrowser`（或图片页）`watch(items)`：若 viewer.visible 则 `playlistIds = items.map(id)`；`next` 调用注入的 `loadMore`。  
- **B** 把 viewer 的 next 收到页面，store 只发事件。

推荐 A，改动面小。

## 5. 交互

下一张在「还有更多」时不灰。加载中可转圈或保持可点（防连点：in-flight 只跑一次 loadMore）。无新快捷键。

空：只有一张且无更多 → 两键皆灰（上一张灰、下一张灰）。
