# 库类型平台 · 实现方案（详细设计）

> 状态：**已定稿 · 实现中**  
> 与 `openspec/changes/library-type-platform/design.md` 同范围。  
> 拍板：D-20260917-01、D-20260917-02、**D-20260917-03**。  
> **本文件是 apply 的施工图**；未写业务代码。

## 1. 对齐与约束

- 分层不变：library API → 应用服务 → 仓储 / FileOps；桌面 `domain` → hooks/stores → 浏览壳 / InfoPanel。
- 不重写 `series_plan`；`ingestKind=series` 仍走现函数。
- 渲染进程不复制库文件；系统打开走已有 `openPath`。
- 类型分支只查 TypeProfile，禁止 `if (type === 'game')` 选过滤表/播放器。
- 新表/CHECK：`0009_library_types.sql`（重建 resources，列序对齐 0008，并加 `storage_kind`）。
- D-20260912-06 **对媒体文件仍有效**（图/视频/番剧/音频/小说/模型/漫画默认 **owned 复制**）。游戏为本切片唯一允许 `indexed` 的类型；**不**恢复持久 library_roots、**不**后台再扫。

## 2. 本设计锁定（避免 apply 再选）

| 项 | 锁定 | 理由 |
|----|------|------|
| 音频库 | **howler.js** | 专为音频；不拿 Video.js 凑音频产品 |
| 3D 预览 | **@google/model-viewer** | gltf/glb 路径短；obj/fbx 本刀可 ingest，预览降级系统打开 |
| 漫画消费 | **shell-open**（与小说同） | 本刀不做阅读器/翻页 overlay；阅读器与小说一并后立项 |
| 游戏入库 | **默认 indexed（扫描登记）**；向导可选 owned 复制 | 安装版/Steam 盘/数十 GB 不可复制；对照 GRM/Bakabase/Vnite 都是记路径启动 |
| Player 键 | **consumeKind** | 同一打开方式多 type 共用 |
| 类型页 | **单一 `TypeBrowse`** | 消灭 `views/{Image,Video,Anime,AV}/index.vue` 克隆 |

CSP（`apps/desktop/src/renderer/index.html`）：model-viewer 需 `script-src 'wasm-unsafe-eval'` 与 `worker-src blob:`。

## 3. 领域模型（DDD）

当前代码已有六边形外形（`library/api` / `application` / `infrastructure`），但**类型策略散在 `media_types` 常量 + 页面克隆**。本刀把「库」收成清晰限界上下文，**不**新开第二个 FastAPI 应用。

### 3.1 限界上下文

```text
┌─ Library（目录） ─────────────────────────────────┐
│  聚合：Work（resources 一行 = 网格一张卡）         │
│  实体：FileRef（files：打开单位）                  │
│        Season / Episode / Extra（仅 series）       │
│  值对象：ResourceType、IngestKind、ConsumeKind、    │
│          StorageKind、FileRole、TypeProfile        │
│  领域服务：IngestPolicy（按档案选策略，不含 IO）    │
│  仓储：WorkRepository / FileRepository（已有）     │
└───────────────────────────────────────────────────┘
        ▲ 应用服务编排
┌─ Ingest（导入作业） ──────────────────────────────┐
│  ImportJob（已有 jobs）                            │
│  策略：FileIngest / SeriesIngest / PackageIngest   │
│  Placement：OwnedCopy / IndexedRegister            │
│  基础设施：FileOps、Layout、ResourcePackage、probe │
└───────────────────────────────────────────────────┘
┌─ Desktop Consume（渲染进程） ─────────────────────┐
│  TypeCatalog（与后端 TypeProfile 字段同名）        │
│  BrowseShell（TypeBrowse + ResourceBrowser）       │
│  ConsumePort：PlayerByConsume[consumeKind]         │
└───────────────────────────────────────────────────┘
```

**不**把 TypeProfile 做成每行一张 DB 表：它是**编译期目录**（Python frozen dataclass + TS 常量），与 `ResourceType` CHECK 同步。运行时资源行只存 `type` + `storage_kind`。

### 3.2 聚合不变量

| 聚合 | 不变量 |
|------|--------|
| Work | 一张卡 = 一部作品；集/页/启动文件不是 Work |
| FileRef | `path` 全局唯一；`owned` 时 path 必须落在 `{store}/{type}/{id}/`；`indexed` 时 path 为源盘绝对路径 |
| Series | 仅 `ingestKind=series`；episodes 指向 FileRef |
| Package | 一目录一 Work；游戏有 0..1 个 `role=launch` |

### 3.3 TypeProfile（目录，单一事实）

后端 `app/library/domain/type_profile.py`（从 `media_types.py` **迁出并扩展**，`media_types` 只留扩展名集合与角色常量的再导出，避免调用方大爆炸）。前端 `domain/libraryTypes.ts` **字段同名、扩展名去点**。

```text
TypeProfile
  type              ResourceType
  label             中文侧栏/向导
  emptyHint         空列表文案
  routePath         /audio …
  routeIcon         mdi 名
  ingestKind        file | series | package
  consumeKind       overlay-image | overlay-video | overlay-audio
                    | overlay-series | overlay-model | shell-open
  defaultSource     file | directory
  defaultStorage    owned | indexed     # 导入默认落盘策略
  allowedStorage    frozenset[owned, indexed]
  extensions        带点后缀
  coverFallback     bool
  enabled           bool
```

查询（禁止调用方 if type 字面量）：

- `profile_for(type) -> TypeProfile | None`
- `ingest_kind` / `consume_kind` / `storage_allowed(type, kind)`
- `IMPORT_EXTENSIONS` / `SERIES_TYPES` / `DEFAULT_IMPORT_SOURCE_KIND` **从档案生成**

### 3.4 启用档案表（A-min）

| type | ingestKind | defaultSource | defaultStorage | allowedStorage | consumeKind |
|------|------------|---------------|----------------|----------------|-------------|
| image | file | file | owned | owned | overlay-image |
| video | file | file | owned | owned | overlay-video |
| anime | series | directory | owned | owned | overlay-series |
| av | series | directory | owned | owned | overlay-series |
| audio | file | file | owned | owned | overlay-audio |
| novel | file | file | owned | owned | shell-open |
| game | package | directory | **indexed** | indexed, owned | shell-open |
| model | file | file | owned | owned | overlay-model |
| comic | package | directory | owned | owned | **shell-open** |

扩展名初版：

- audio：`.mp3 .flac .wav .aac .ogg .m4a .wma .opus`
- novel：`.epub .pdf .txt .html .htm .mobi .azw3`
- game：收集 `.exe .bat .cmd .lnk`（Win）作 launch 候选；包本身是目录
- model：`.gltf .glb` 可预览；`.obj .fbx .stl` 入库、预览降级
- comic：包内图片用 `IMAGE_EXTENSIONS`；另允许单文件 `.cbz .cbr`（file 形态，见 5.4）

`layout_for` / `importer_for`：凡 enabled 都有 Layout。package 的 `Importer.collect(directory)` **yield 根目录一次**，不把每个文件当候选 Work。

## 4. 桌面浏览壳：消灭页面克隆

现状 `views/Image|Video|Anime|AV/index.vue` 仅 `type` / `empty-hint` 不同，违反开闭。

**本刀：**

1. 新建 `views/TypeBrowse/index.vue`：从 `route.meta.resourceType` 取 type，`emptyHint` 来自档案。
2. `route.ts`：`ENABLED_PROFILES` map 生成 `/image`…`/comic`；`meta.title/icon/resourceType` 来自档案。Home、Trash **仍手写**（非类型网格）。
3. **删除** `views/Image` `Video` `Anime` `AV` 目录（及本刀本不会再新建 Audio/Novel/Game/Model/Comic 页）。
4. `views/README.md` 改为：类型网格只有 TypeBrowse；页私有组件仍放 TypeBrowse 下（本刀预计无）。
5. 若仓库里有未挂路由的 `AnimeSeries` 等空壳，本刀一并删或并入 TypeBrowse，不留第二套番剧页。

```vue

<template>
  <div class="type-browse">
    <ResourceBrowser :type="type" :empty-hint="profile.emptyHint" />
  </div>

```

`ResourceBrowser` 二次点击、离页 close 仍只问 `consumeKind`。

## 5. 入库设计

`ImportService.run` 按 `ingest_kind` 三路分发。`validate_import`：档案 `defaultSource=directory` 或 ingestKind∈{series,package} 时强制 directory（comic cbz 例外）。`storageKind`：请求体可带；缺省用 `profile.defaultStorage`；不在 `allowedStorage` → 400。

### 5.1 StorageKind

| kind | 字节 | files.path | 去重 | 彻底删除 |
|------|------|------------|------|----------|
| owned | 复制进 `{store}/{type}/{id}/` | 库内路径 | 主文件 sha256 | 删 DB + 删包 |
| indexed | **不复制**游戏树 | 源绝对路径 | launch（或目录规范化路径）已存在则 skip | **只删 DB**；源盘不动 |

indexed **不是** library_roots：导入仍选一次路径；不监视、不增量再扫。源被挪走后，启动失败；可将 `status=lost`（若现网已有 lost；否则本刀启动时提示路径不存在即可，不强制做监视器）。

可选：indexed 游戏若目录内有 `cover.jpg`/`folder.jpg`，**只复制封面**到 `{store}/game/{id}/cover.jpg` 供网格（小文件）。无封面则无缩略图。不把整个游戏拷进封面目录。

### 5.2 file（audio / novel / model）

与图片相同：`owned` 复制 `primary{ext}`，probe：

- audio：ffprobe duration（失败空字段）
- novel/model：只记 size/format
- 无图则不生成 thumbs

### 5.3 package · 游戏

对照：绿色资源管理器 / Bakabase = 登记路径；Vnite = 档案与本地启动路径分离。本仓 Work 仍是一张卡；启动路径是 FileRef，不拆第二张「本地」表（A-min 够用；Vnite 的会话/成就 OUT）。

1. 校验 `paths[0]` 为目录。
2. 在**源树**找启动文件，优先级：`{目录名}.exe` → `launch.exe` → `game.exe` → 任意第一个 `.exe` → `.bat/.cmd/.lnk`。跳过隐藏名、`Thumbs.db`、`desktop.ini`（扫描与复制同一过滤）。
3. **indexed（默认）**：不 `copytree`。建 Work（可建空包目录仅放可选封面）。`files.path` = 源盘 launch 绝对路径，`role=launch`（无候选则无 launch 行，Work 仍建）。去重：同一规范化 launch 路径或同一 sha256 已存在 → `skipped_duplicate`（无包可删则只不插行）。
4. **owned（向导显式选择）**：复制整树到 `{store}/game/{id}/`（同过滤）。launch 映射到复制后路径。去重：launch/primary sha256；命中则删刚拷的包。
5. launch 兼 primary（无独立封面文件时）。
6. 无启动候选：**仍入库**；InfoPanel「启动」禁用；不 400。
7. `title` = 源目录名。
8. 向导文案：默认「扫描登记（不复制文件，适合已安装游戏）」；次选项「复制进库（便携小游戏）」。体积警告：owned 且目录 > 阈值（如 2GB）二次确认（主进程 `stat` 即可）。

### 5.4 package · 漫画（图片目录）

本刀：**入库 + 列表 + 系统打开**，**不做** ImageViewer 翻页。

1. 收集目录内（可递归一层）图片，自然序。
2. 无图片 → skipped_error。
3. **owned** 复制到 `{store}/comic/{id}/pages/001.ext`… 第一页 `role=primary`，其余 `role=page`（页角色留给后续阅读器，本刀 UI 不翻）。
4. 去重：第一页 sha256。缩略图从第一页。
5. title=源目录名。
6. 打开：`shell-open` primary（系统看图）。不实现 `openFiles`。

### 5.5 comic 单文件 cbz/cbr

- 向导：comic 默认文件夹；允许 source=file 且 cbz/cbr。
- 整文件 primary，`owned`；`shell-open`。不解压。

### 5.6 角色常量

`FILE_ROLE_LAUNCH`、`FILE_ROLE_PAGE`。前端 `FILE_ROLE` 同步。

## 6. 消费设计

### 6.1 Player 注册

```text
PlayerByConsume: Record<ConsumeKind, { open; close; prev?; next? }>
```

- `ResourceBrowser`：二次点击 `PlayerByConsume[profile.consumeKind].open`
- `onUnmounted`：只 close 本页 consumeKind
- `overlay-series` **不**进二次点击（单击选中，信息栏点集）
- `shell-open`：`openLaunchOrPrimary`；**indexed 用 files.path 绝对路径**；owned 用库内路径。无 overlay

### 6.2 overlay-audio

`audioPlayer.ts` + `AudioPlayerOverlay` + Howler；`GET .../content`。控件：播/暂停、进度、音量、关闭、Esc。无波形。

### 6.3 overlay-model

`modelPreview.ts` + `<model-viewer>`。仅 gltf/glb；否则主按钮禁用 + 「用外部应用打开」。`/content` MIME：`model/gltf-binary`。

### 6.4 漫画 / 小说 / 游戏

三者均为 `shell-open`。游戏优先 `role=launch`。漫画/小说用 primary。信息栏按钮文案查 consumeKind + 是否有 launch（「启动」vs「打开」），**不** `if type===game`。

**本刀不做** `overlay-comic`、**不**改 ImageViewer fileId 播放列表。

### 6.5 InfoPanel

类型标签、按钮组查 consumeKind + storageKind（indexed 可显示「源路径」，避免用户以为文件在库里）。游戏显示启动文件名；无 launch 则启动禁用。小说/漫画不进阅读器 UI。
