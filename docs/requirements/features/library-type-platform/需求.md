# 库类型平台 · 需求

> 状态：**评审中**（待「可以按此实现」）  
> OpenSpec：`openspec/changes/library-type-platform/`  
> 对齐：D-20260917-01、D-20260917-02、**D-20260917-03**、D-20260912-06（媒体 owned；游戏例外）

## 1. 背景

`anime-av-types` 第一刀已让番剧/AV 按作品进库。音频、小说、游戏、模型、漫画仍缺统一类型模型。类型页与扩展名表按名字分叉。游戏不能按图片那套整树复制。

本切片：**领域 TypeProfile** + 剩余库导入/展示/最低消费 + **浏览壳抽离**。

## 2. 范围

### IN

- 领域目录 TypeProfile：ingestKind、consumeKind、storageKind、扩展名、侧栏
- 新类型：`audio`、`novel`、`game`、`model`、`comic`
- 媒体默认复制进库；**游戏默认扫描登记源路径**，向导可选复制
- 列表/信息栏/回收站共用壳；类型网格只有 TypeBrowse
- 最低消费：
  - audio：Howler overlay
  - game：系统打开 launch
  - model：内置预览
  - comic / novel：系统打开（**无内置阅读器**）

### OUT

- 抓取、下载、合集、词表、画廊、主题、工作目录
- 番剧/AV 第二刀
- **内置小说阅读器、内置漫画阅读器**
- 游戏成就/时长；Steam 官方 API
- 持久 library_roots / 后台再扫
- 自研解码器

## 3. 更高层模型

| 层次 | 用户能看见 | 库里是什么 |
|------|------------|------------|
| 作品 | 网格一张卡 | Work / `resources` |
| 打开单位 | 图/视频/一集/音频/启动文件/模型 | FileRef / `files`（或 episodes） |
| ingestKind | file / series / package | 档案 |
| consumeKind | overlay-* / shell-open | 档案 |
| storageKind | 库内副本 / 源路径登记 | `resources.storage_kind` |

禁止 UI 按业务类型名 if，只问档案。禁止为每种库复制一份 `views/*/index.vue`。

## 4. 各类型 A-min

| type | ingestKind | 默认 storage | 最低打开 |
|------|------------|--------------|----------|
| image | file | owned | overlay-image |
| video | file | owned | overlay-video |
| anime/av | series | owned | overlay-series |
| audio | file | owned | overlay-audio |
| novel | file | owned | shell-open |
| game | package | **indexed** | shell-open launch |
| model | file | owned | overlay-model |
| comic | package 或 cbz file | owned | shell-open |
