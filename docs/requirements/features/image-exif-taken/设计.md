# 设计 · image-exif-taken（L2）

> 状态：**已落地**  
> 需求：`需求.md`。可手改；探测与 PATCH 共用 `normalize_taken_at`。

## 0. 复杂度

跨导入探测、files 写入、已有排序键、信息栏一行展示。列与 API 字段已在，本刀是把断的链路接上。不可跳过 L2（契约与时间格式必须锁死）。不新开服务、不新建表。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 新导入才探测 | 只在 `probe_image` 成功路径写列 | 启动扫描、详情打开补探测 |
| 失败不挡导入 | 无 EXIF / 解析失败 = null | 因拍摄时间失败整单回滚 |
| 只读档案默认探测 | 导入写 EXIF | 不写回磁盘 |
| 可手改 | PATCH 改 primary 列 | 非图片改拍摄时间 |
| 日历时间可排序 | 存无时区的本地日历串，字典序 = 时间序 | 存「今天」文案；乱序原串 |
| 目录化 | 只问 type=image 的 primary 探测 | 漫画页、视频 creation_time |

## 2. 模型

沿用 `files.exif_taken_at`（TEXT）+ 领域 `ResourceFile.exif_taken_at` + JSON `exifTakenAt`。

**来源优先级**（Pillow `getexif()`，数字标签）：

1. DateTimeOriginal（36867）  
2. DateTimeDigitized（36868）  
3. DateTime（306）  

都没有或解析失败 → null。不读 GPS 日期、不读 XMP、不读文件 `mtime` 冒充拍摄。

**存储格式**（锁定）：`YYYY-MM-DDTHH:MM:SS`（例 `2024-03-15T14:08:01`）。EXIF 常见 `YYYY:MM:DD HH:MM:SS` 经解析转换。无时区、不转 UTC。非法日期（如全零）丢弃为 null。

列表 `takenAt` 已是 `MAX(files.exif_taken_at)`：一图一 primary，即该值。

**类型对齐**：ORM 与领域均为 `str | None`；JSON `exifTakenAt`。

## 3. 交互

- 图片信息栏「技术信息」展示已保存拍摄时间。  
- 「编辑」区 `datetime-local`，随保存 PATCH。清空即列 null。  
- 导入：用户无感知。

## 4. 模块划分

| 模块 | 边界 | 不进入 |
|------|------|--------|
| `media_probe.probe_image` | Pillow 宽高 + 解析 EXIF → `ProbeFields.exif_taken_at` | 渲染进程、写文件 |
| `ImportService` `_ingest_file` | `add_file(..., exif_taken_at=)` | 其它 ingestKind |
| `ResourceRepository.add_file` | 增加可选参数写入列 | 批量 UPDATE 旧行 |
| InfoPanel | 图片技术行展示 | 编辑草稿、新路由 |

依赖方向：导入 → 探测 → files 行 → GET 详情 / 列表排序。禁止前端读库内 jpg 头。

## 5. 功能拆分（一刀交付）

| 切片 | 可感知结果 |
|------|------------|
| A | probe 写出 ISO 串；add_file 落列 |
| B | 信息栏「拍摄」 |
| C | 单测夹具 jpg / 无 EXIF png |
