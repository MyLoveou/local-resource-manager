# 系列详情页 · 需求

> 状态：草案（2026-10-29）｜前置：每集封面与字幕（已完成）

## 1. 背景

番剧/A 的季集结构现在只能在右侧信息栏里看：一排按钮 + 每集小卡片，宽度有限。
一部 2 季 24 集的作品，选集要靠滚动，且看不到作品级的概览（封面、简介、分类、标签统计）。

## 2. 范围

### IN

1. 独立页面 `/series/:id`，展示一部系列作品。
2. 头部：封面、标题、原始名（`source_name`）、类型、季数/集数/特典数。
3. 选集：复用 `EpisodeList`（每集封面、字幕角标、换封面/加字幕、补封面）。
4. 点击某集 → 直接播放该集（复用现有播放器与续播）。
5. 返回：回到进入前的列表页（浏览器历史后退）。
6. 入口：在资源网格里**双击**一部番剧/AV 卡片进入。

### OUT

- 新的数据模型（全部复用 `resources.seasons.extras`）。
- 编辑能力（标题/标签/分类仍走信息栏，不在此页重复）。
- 跨作品的连续播放、播放列表管理。

## 3. 交互

1. 页面顶部有返回按钮与标题；`Esc` 返回。
2. 无季集数据时显示「该作品还没有集」并给出「补封面/重新导入」的提示。
3. 加载失败显示错误与重试，不白屏。

## 4. 验收

| # | 场景 | 判定 |
|---|---|---|
| S1 | 双击番剧卡片 | 进入 `/series/{id}` |
| S2 | 打开 2 季作品 | 头部显示 `2 季 · 19 集 · 10 特典` |
| S3 | 点击某一集 | 播放该集，且能续播 |
| S4 | 页面内的「补封面」 | 与信息栏行为一致 |
| S5 | 返回 | 回到原来的类型列表页，筛选条件保留 |
| S6 | 资源不存在 | 显示「作品不存在」，可返回 |

## 5. 已知约束

- 复用 `GET /library/resources/{id}`，不新增接口。
- 新增页面与组件需遵守文件规模门禁（新文件 ≤500 行）。
