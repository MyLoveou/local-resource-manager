# 系列详情页 · 实现方案

## 1. 数据

复用 `GET /library/resources/{id}`：`seasons[].episodes[]` 已含 `coverUrl`、`hasCover`、
`hasSubtitles`，`extras[]` 含标题。**不需要后端改动。**

## 2. 文件清单

| 文件 | 作用 |
|---|---|
| `apps/desktop/src/renderer/src/views/SeriesDetail/index.vue` | 页面（新建） |
| `apps/desktop/src/renderer/src/router/route.ts` | 加 `/series/:id` 路由 |
| `apps/desktop/src/renderer/src/components/VirtualGrid/index.vue` | 卡片增加 `dblclick` 事件 |
| `apps/desktop/src/renderer/src/components/ResourceBrowser/index.vue` | 双击番剧/AV 卡片跳转 |

## 3. 页面结构

```text
[← 返回] 作品标题                       2 季 · 19 集 · 10 特典
┌──────────┐  原始名、类型、来源
│  封面    │  分类 / 标签（只读）
└──────────┘
── 选集 ────────────────────────────────
EpisodeList（复用：封面、字幕角标、更多菜单）
── 特典 ──（EpisodeList 内部已渲染）
```

## 4. 交互实现

- 路由参数 `id` → `getResource(id)`；`watch(() => route.params.id)` 重新加载。
- 播放：`openResource(resource, { playlist: episodeFileIds, fileId })`
  （与信息栏 `playEpisode` 一致，复用续播）。
- 返回：`router.back()`；若没有历史则回 `/library/anime`。
- `Esc` → 同返回。

## 5. 与信息栏的关系

信息栏保留（列表页仍需要快速预览）。详情页是**同数据的另一种布局**，不复制业务逻辑：
选集渲染统一走 `EpisodeList`，补封面/换封面/加字幕只在组件里实现一次。
