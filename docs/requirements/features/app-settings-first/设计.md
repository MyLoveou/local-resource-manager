# 设计 · app-settings-first

> 状态：**已定稿**（已编码）

沿用 `settings(key, value JSON)`。禁止新扫描根。密钥只写 KV 或继续用 env，Provider 统一一个读取函数。

## 1. 键

| key | value | 说明 |
|-----|--------|------|
| `scrape.tmdb` | `{ "apiKey": "..." }` | 空对象=未配 |
| `scrape.bangumi` | `{ "accessToken": "..." }` | 可选 |
| `scrape.mikan` | `{ "baseUrl": "https://..." }` | 空则代码默认 kas.pub |

不把 token 写入 `adapters` 表（本刀不碰该表）。

## 2. 读取顺序

`tmdb_api_key()`：`os.environ["TMDB_API_KEY"]` 非空 → 否则 KV。Bangumi / Mikan 同理（Mikan 的 env 仍是 `MIKAN_BASE_URL`）。

PATCH 后进程内缓存失效（函数每次读库或短缓存，保存时 `invalidate`）。

## 3. API

前缀 `/settings`（挂主应用，不进 `/library`）。

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/` | 刮削掩码 + 系统路径 + `envLocked` |
| PATCH | `/scrape` | 只更新提交的字段；空字符串=清除该 KV（env 仍在则锁住且 400） |
| POST | `/backup` | sqlite backup → `data/backups/library-时间.db` |

GET scrape 字段示例：

```json
{
  "tmdb": { "configured": true, "hint": "••••wxyz", "envLocked": false },
  "bangumi": { "configured": false, "hint": null, "envLocked": false },
  "mikan": { "baseUrl": "https://mikanani.kas.pub", "envLocked": false }
}
```

`hint` 仅后四位。系统：`dbPath`、`libraryPath`、`logDir`、`downloadDir`、`backupDir`、`backendVersion`。

## 4. UI

顶栏「设置」（导入/下载旁）。`n-modal` 宽约 560。

- 刮削：密码框 TMDB / Bangumi；蜜柑 URL 普通输入。保存按钮。envLocked 禁用并提示。  
- 系统：路径只读 +「打开」；「立即备份」；关于一行版本。

不新增 IPC。打开目录走现有 `window.electron` `openPath`。

## 5. 失败

备份时库忙 → 中文错误，不写半文件。非法蜜柑 URL → 400。PATCH 在 envLocked 字段上传值 → 400。

## 6. 不做

改 `db_path`、四空页签、adapters CRUD。
