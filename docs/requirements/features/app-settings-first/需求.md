## 1. 问题

刮削要 TMDB Key，现在只能靠环境变量，应用内无处填写。库文件、日志在哪也看不见，不能备份。原文 M6 还要「资源目录扫描根」，与已拍板的复制入库冲突。

## 2. 本刀收口

1. 顶栏 **设置** 打开模态框，两页签：**刮削**、**系统**。不做四空页签凑数。  
2. 刮削可填 **TMDB API Key**、可选 **Bangumi Token**、**蜜柑 Base URL**。保存后 **立即生效**，不必重启。  
3. 环境变量若已设同名项，则该项只读，文案「由环境变量提供」，环境变量优先。  
4. GET **不回传完整密钥**，只回已配置/掩码。  
5. 系统页只读展示：数据库路径、库目录、日志目录、下载暂存目录；按钮打开对应文件夹（已有 `openPath`）。  
6. **备份**：用 SQLite backup API 复制到 `data/backups/`，不改当前库路径。  
7. **关于**：后端版本号 + 上述路径说明。  
8. **禁止** `library.roots`、扫描、改库根路径、适配器表 CRUD、SearXNG、播放器/消费渠道、下载限速、主题（主题仍在顶栏）。

## 3. 范围

### IN

- `settings` KV 表写入刮削凭证与蜜柑 URL。  
- Provider 读：`env` 非空用 env，否则用 KV。  
- 设置 GET/PATCH API；密钥掩码。  
- 顶栏入口 + 模态。  
- 备份接口 + 打开备份目录。  
- 单测：无 key 时仍失败明文；写入 KV 后 `tmdb_api_key()` 能读到（无 env 时）。

### OUT

- 扫描根、监视文件夹、改 `db_path`。  
- `adapters` 表管理页、Pixiv/豆瓣开关。  
- FTS、词表治理、Notify、鉴权 token UI。  
- 下载并发/限速。  
- 把主题迁进设置页。

## 4. 用户故事

- **US-Z.1** 打开设置 → 刮削页填 TMDB Key → 保存 → 立刻对视频获取元数据不再报未配置。  
- **US-Z.2** 已设 `TMDB_API_KEY` 环境变量 → 输入框禁用，不覆盖 env。  
- **US-Z.3** 系统页能打开日志目录、库目录。  
- **US-Z.4** 点备份 → `data/backups/` 出现新 `.db`，当前库仍可用。  
- **US-Z.5** GET 设置响应里看不到完整 API Key。

## 5. 验收
