# 设置第一刀 · 实现方案（L3）

> 状态：**已落地**  
> L2：`设计.md`。已按「开始实现」编码。

## 1. 对齐

- KV 用现表，不新建表。  
- Provider 改读函数，禁止组件直读 env。  
- 渲染进程不写密钥到 localStorage。

## 2. 文件清单

| 路径 | 动作 |
|------|------|
| `app/shared/infrastructure/settings_repo.py` | get/put KV |
| `app/settings/application/service.py` | 掩码、PATCH、backup |
| `app/settings/api/router.py` | GET/PATCH/POST |
| `app/main.py` | include `/settings` |
| `app/scrape/application/providers/tmdb.py` 等 | 读 KV 回退 |
| `tests/test_settings.py` | 掩码、env 优先、backup |
| `desktop/.../http/settings.ts` | 客户端 |
| `desktop/.../components/SettingsModal/` | 两页签 |
| `desktop/.../ui/layouts/ToolBar/index.vue` | 入口 |

备份：`sqlite3.Connection.backup` 到 `settings.db_path.parent / "backups"`。

## 3. 数据流

```
设置保存 → PATCH /settings/scrape → settings 表
刮削 search → tmdb_api_key() → env 或 KV
备份 → POST /settings/backup → data/backups/*.db
打开目录 → GET 路径 → preload openPath
```

## 4. 测试

- PATCH 后 GET 仅 hint，无明文。  
- 无 env 时 PATCH key，provider 读取函数返回该 key。  
- 设 env 后 PATCH → 400。  
- backup 产出的文件能 `SELECT COUNT(*) FROM settings`。

## 5. 步骤

1. repo + GET 掩码  
2. PATCH + provider 回退  
3. backup  
4. 模态 UI  
5. 文档已落地

## 6. 风险

WAL 下 backup 仍应用官方 backup API，不要 `shutil.copy` 活库。
