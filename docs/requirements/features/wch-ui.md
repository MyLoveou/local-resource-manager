# 页面结构 · work-consumption-hub

> 状态：**已定稿**（2026-09-27 · 随 `work-consumption-hub` 定稿，`D-20260927-05`）
> 主需求见 [work-consumption-hub.md](work-consumption-hub.md)。
> 基础布局继承 [lrm-ui.md](lrm-ui.md) 三栏结构，以下为 **增量变更**。

## 1. 定位变更摘要

| 维度 | LRM（已有） | WCH（增量） |
|------|-------------|-------------|
| 首页 | 按类型数量统计 | + 进行中工作、最近消费 |
| 左侧菜单 | 图片、视频、占位 | + **工作目录**、**模型** |
| 双击行为 | 图片预览 / 视频播放 | 按类型走 **消费渠道路由** |
| 右侧面板 | 元数据面板（媒体） | 工作目录 → **工作区面板** |
| 设置 | 播放器默认方式 | + **消费渠道配置** 页签 |

## 2. 左侧菜单（更新）

```
首页
资源（可展开）
├── 图片
├── 视频
├── 工作目录          ← 新增（P0）
├── 模型              ← 新增（P1，可先占位可点击）
├── 小说（占位）
├── 番剧（占位）
├── AV（占位）
回收站
[底部] 设置按钮 → 弹窗
```

| 元素 | 说明 |
|------|------|
| 首页 | 工作向概览入口（M10） |
| 工作目录 | 列表展示所有 `work_directory` 资源 |
| 模型 | P1：列表 + 外部打开；初期可与工作目录同等列表态 |

## 3. 首页（Home）布局

```
┌────────────────────────────────────────────────────────────┐
│ 概览统计（按类型卡片，保留现有）                            │
├────────────────────────────────────────────────────────────┤
│ 进行中的工作                                                │
│ ┌──────────┐ ┌──────────┐                                  │
│ │ 项目 A    │ │ 项目 B    │  …                             │
│ │ 3 待办    │ │ 最近活跃  │                                  │
│ └──────────┘ └──────────┘                                  │
├────────────────────────────────────────────────────────────┤
│ 最近消费                                                    │
│ 缩略图条 / 列表：最近打开的图片、视频、工作目录…              │
└────────────────────────────────────────────────────────────┘
```

| 区块 | 内容 | 优先级 |
|------|------|--------|
| 概览统计 | `stats.byType` 卡片 | 已有 |
| 进行中的工作 | 有未完成待办或近期活跃的工作目录 | P1 |
| 最近消费 | 最近 N 次消费动作记录 | P1 |

空态：无数据时保留现有「暂无数据」，各区块独立空态文案。

## 4. 工作目录视图（三栏）

### 4.1 中间栏：工作目录列表

| 行为 | 说明 |
|------|------|
| 卡片内容 | 目录名、路径摘要、待办进度（如 2/5）、工作状态标签 |
| 单击 | 选中 → 右侧工作区面板更新 |
| 双击 | **进入工作区**（焦点在右侧面板，非打开文件夹） |
| 右键菜单 | 在外部打开、用…打开、在文件管理器中显示、编辑、移到回收站 |

### 4.2 右侧栏：工作区面板（替代元数据面板）

```
┌─────────────────────────────┐
│ 头部：标题、路径、状态        │
│ [在外部打开] [文件管理器]     │
├─────────────────────────────┤
│ 待办                         │
│ ☐ 任务 1                     │
│ ☑ 任务 2                     │
│ [+ 添加待办]                 │
├─────────────────────────────┤
│ 备注                         │
│ ┌─────────────────────────┐ │
│ │ 备注标题 / 内容预览      │ │
│ └─────────────────────────┘ │
│ [+ 添加备注]                 │
├─────────────────────────────┤
│ （P1）快捷链接 / 关联资源     │
└─────────────────────────────┘
```

| 区块 | 交互 |
|------|------|
| 头部 | 标题可编辑；路径可复制；丢失时显示警告条 |
| 待办 | 勾选完成、内联编辑、删除、拖拽排序（P1 可选） |
| 备注 | 列表 + 点击展开编辑；支持多段 |
| 操作按钮 | 消费渠道动作，与 M7 统一 |

## 5. 媒体 / 模型视图（消费入口）

继承 LRM 三栏，**增量**：

| 位置 | 变更 |
|------|------|
| 双击 | 走消费渠道路由（不再视图内 hardcode） |
| 右键菜单 | 增加「用…打开」（当类型支持 `external_command`） |
| 元数据面板底部 | 「打开」「用…打开」按钮；模型类型无播放按钮 |

## 6. 设置弹窗（增量页签）

| 页签 | 内容 | 优先级 |
|------|------|--------|
| 资源目录 | （LRM 已有） | — |
| 适配器 | （LRM 已有） | — |
| **消费渠道** | 按资源类型配置默认方式：内嵌 / 系统默认 / 自定义命令 | **P0** |
| 播放器 | （LRM 已有，可合并入消费渠道页签） | — |
| 系统 | （LRM 已有） | — |

**消费渠道配置 UI 示例**

| 类型 | 默认方式 | 自定义命令（可选） |
|------|----------|-------------------|
| 图片 | 内嵌预览 ▼ | — |
| 视频 | 内嵌播放 / 系统播放器 ▼ | — |
| 工作目录 | 工作区 / 外部打开 ▼ | `cursor "{path}"` |
| 模型 | 系统默认 / 外部打开 ▼ | — |

## 7. 消费动作反馈

| 场景 | UI 反馈 |
|------|---------|
| 外部打开成功 | 无阻塞 toast（可选） |
| 命令不存在 | 错误 toast + 跳转设置页链接 |
| 路径丢失 | 面板内警告 + 「重新定位」入口（复用 LRM 丢失流程） |
| 内嵌播放/预览 | 现有 LRM 行为 |

## 8. 与 LRM UI 的兼容原则

- 三栏宽度可拖拽：**不变**
- 元数据面板暂不支持折叠：**不变**（工作目录右侧为工作区面板，同等不可折叠）
- 虚拟列表 / 卡片网格：**工作目录列表复用同一列表组件**
- 回收站：工作目录软删后，工作上下文只读保留，恢复后可用
