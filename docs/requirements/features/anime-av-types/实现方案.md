# 番剧与 AV 系列 · 实现方案

> 与 `openspec/changes/anime-av-types/design.md` 同一清单。  
> 决策：专属子表 + Resource 作品外壳；正片集/特典不是网格 Resource。

## 1. 对齐

- 作品列表/回收站/词表：沿用 `resources` + `LibraryQueryService`  
- 季/集/特典：library 下新 repository，详情组装进 Resource DTO 或并列 `SeriesDetail`  
- 播放：现有 overlay + `files/{id}/content`  
- 导入：现有 job；**新 layout** 把目录收成 seasons/extras，而不是每个 mkv 一条 Resource  
- **不**新 FastAPI 应用、不新播放器工程

## 2. 目标 / 非目标

**目标：** 作品一卡、栏内选集播放、特典分组、专用 profile、旧 video 不动。  
**非目标：** 刮削、每集独立回收站卡片、把 files.role 当季树。

## 4. 数据流

### 导入（目录）

1. 向导 type=anime，sourceKind=directory  
2. 解析树 → 一个 `resources` + seasons/episodes/extras + copy 进包  
3. 每集 ffprobe 写对应 files 行  
4. 封面：用户图或留空（本切片不抽帧，与 video 无封面策略一致，除非目录内有 cover.*）  
5. bump 后番剧网格出现 **一张卡**

### 浏览播放

1. `GET /library/resources?type=anime` 作品列表  
2. 单击 → `GET /{id}` 含树  
3. 点集 → overlay 打开，src=该 file content  
4. 切路由 → close overlay

### 错误

- 目录无法解析出任何视频：job skippedError，不建空作品（或建空作品——建议 **不建**）  
- 未知 type 导入仍 400  

## 5. 决策

| 决策 | 选择 | 不选 |
|------|------|------|
| 网格单位 | 作品 Resource | 每集 Resource |
| 结构 | seasons/episodes/extras 表 | 只 extra JSON |
| 特典 | 独立 extras；不计入正片集数 | 全部当 S00 正片 |
| 播放 | file content + 现有 overlay | 作品级 primary |
| 旧数据 | 不动 video | 批量改 type |

## 6. 风险

| 风险 | 缓解 |
|------|------|
| 导入一文件一资源误用于系列 | import_service 按 type 分支 |
| InfoPanel 过重 | 季折叠；默认展开第一季 |
| CHECK 迁移漏列 | 对照 0001–0004 全列 |

## 7. 注释

系列子表旁注明：作品才是 Resource；集与特典不是列表项。
