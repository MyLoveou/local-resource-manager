# UI Shell 重设计 · 设计

> 状态：**L2 设计待确认**（2026-10-22）  
> 上游：`需求.md`  
> 本轮只做信息架构、交互层级和组件边界；不写业务代码，不进入 L3。

## 1. 设计原则

1. **稳定骨架，增量能力**：新功能优先进入已有容器，不优先增加顶级导航。
2. **操作分层**：全局动作、页面动作、选中态动作、对象动作四层分离。
3. **按钮预算**：每个区域最多 1–3 个主操作，其余进 overflow / 右键 / 命令面板。
4. **上下文出现**：批量操作只在选中态出现；AI 动作只在对象上下文出现。
5. **AI 是一个能力层，不是一组导航**：AI 搜索、找相似、智能导入、智能合集共享 AI 中心与建议入口。
6. **桌面优先**：高密度、键盘可达、可折叠；不为移动端牺牲桌面效率。
7. **现有主题不推翻**：沿用 `theme-tokens`，只重做结构、层级和控件密度。
8. **可回退**：先替换 Shell，不重写业务页；页面内部按阶段迁移。

## 2. 信息架构

### 2.1 左侧导航（推荐）

```text
浏览
  首页
  资源库

视图
  时间线
  地图

组织
  合集
  角色
  扮演者

工具
  AI 中心
  回收站
```

说明：

- 「资源库」承载全部类型；类型 tabs 留在资源库页面内，不进入左侧。
- 「时间线 / 地图」是常用视图，继续同级。
- 「合集 / 角色 / 扮演者」是组织维度，收进「组织」组。
- 「AI 中心」是工具，不是内容类型；适合底部工具区。
- 「回收站」保留工具区，避免污染浏览路径。
- 「设置 / 主题 / 更新」收进顶栏「设置」组，不再占用侧栏底部。

### 2.2 顶栏

采用「全局动作 + 工具组」：

```text
[搜索 / 命令] [导入] [整理▾] [AI▾] [设置▾]        [AI 状态]
```

- 全局搜索输入框常驻；`Ctrl/Cmd+K` 打开命令面板。
- **导入**：文件 / 文件夹 / 监视目录 / 最近导入。
- **整理**：选择资源、批量分类、批量标签、设置角色、设置扮演者、加入合集、更多。
  - 没有选中资源时，显示「先选择资源」或直接进入选择模式。
- **AI**：智能搜图、找相似、模型管理、任务、建议。
- **设置**：设置、主题、检查更新、日志、数据维护。
- 工具组点击才展开，不 hover 展开；同一时间只开一个组，`Esc`/外部点击关闭。
- 每组最多 5–7 项；危险操作放最后并二次确认。
- 主题、更新、模型等低频项不再直接铺在顶栏。
- **批量操作不再出现在顶栏**；顶部「整理」是命令入口，不是常驻按钮集合。

### 2.3 页面头部

```text
面包屑 / 页面标题                  [视图切换] [筛选] [排序] [选择] [更多]
```

- 类型 tabs 只出现在资源库页面。
- 页面主操作最多 2–3 个；删除等放进「更多」。
- 时间线/地图/网格切换属于页面视图切换，不进入左侧导航。

### 2.4 选中态操作栏

批量模式出现，固定在内容区底部：

```text
已选 12 项   [整理▾] [退出]
```

- 高频动作统一从「整理」展开，不在底栏重复铺 5–6 个按钮。
- 「整理」与顶部「整理」使用同一套命令定义。
- 退出批量模式后整条消失。
- 该层是未来批量 AI 操作的统一入口，例如「AI 建议标签」「智能加入合集」。

### 2.5 右侧 Inspector

建议改成可折叠、带 tab 的上下文面板：

```text
[详情] [关联] [AI]
```

- 详情：标题、文件、EXIF、时间、地点、尺寸、格式
- 关联：分类、标签、合集、角色、扮演者
- AI：找相似、AI 标签建议、描述、OCR、合集建议
- 默认宽度 320–360；窄窗口改为抽屉
- Inspector 只做对象级操作，不承载全局导航

│  资源库       │                              │  关联          │
│              │                              │  AI            │
│ 视图          │        页面内容               │               │
│  时间线       │                              │               │
│  地图         │                              │               │
│              │                              │               │
│ 组织          │                              │               │
│  合集         │                              │               │
│  角色         │                              │               │
│  扮演者       │                              │               │

│ 工具          │                              │               │

- 侧栏：展开 200–220，折叠 64
- 顶栏：44
- 页面头部：48–56
- Inspector：320–360；可折叠
- 内容区独立滚动，三个区域不互相挤动
- 批量操作栏浮在内容区底部，不改变内容高度

## 4. 组件边界

| 组件 | 负责 | 不负责 |
|---|---|---|
| `AppShell` | 三栏结构、侧栏/Inspector 开合 | 业务数据、具体页面规则 |
| `GlobalCommandBar` | 搜索、命令、导入、AI 状态、通知、设置 | 页面筛选、批量动作 |
| `AppSidebar` | 分组导航、AI 中心、设置、折叠 | 具体资源筛选 |
| `PageHeader` | 标题、类型 tabs、视图切换、页面操作 | 全局动作 |
| `SelectionBar` | 选中数量、批量动作、退出 | 未选中时的常驻操作 |
| `Inspector` | 当前对象详情/关联/AI | 全局搜索、导航 |
| `AICenter` | 模型、任务、建议、AI 搜索 | 具体资源对象编辑 |
| `CommandPalette` | 搜索/命令/跳转/AI 入口 | 替代所有页面按钮 |

## 5. AI 功能放置

### 5.1 AI 中心

建议 `/ai`，作为唯一 AI 工具入口，内部 tabs：

- **搜索**：以文搜图、以图搜图
- **模型**：模型状态、下载、删除、更新
- **任务**：索引、OCR、描述、智能导入、合集建议任务
- **建议**：待确认的分类/标签/角色/扮演者/合集建议

顶栏 AI 状态只做入口和徽标，不做所有 AI 功能的按钮集合。

### 5.2 上下文 AI 动作

| 场景 | 入口 |
|---|---|
| 全局搜索 | 搜索框切「智能搜图」或 `/ai?tab=search` |
| 图片查看器 / Inspector | 「找相似」 |
| 导入向导 | 可选「导入后智能分析」 |
| 资源批量选中 | `SelectionBar → 更多 → AI 建议` |
| 合集页 | 「AI 生成合集建议」 |
| 角色/扮演者页 | 「AI 建议关联」 |
| 设置 | AI 模型/远程 Provider/隐私 |

### 5.3 模型未安装

- 顶栏显示 `AI 未启用`
- 相关 AI 按钮不隐藏，但点击进入模型安装/说明
- 或显示为禁用态 + 「安装模型」tooltip
- 不在每个页面重复放「下载模型」按钮
- 下载完成后统一刷新可用状态

## 7. 按钮规则

1. 顶栏只放全局动作，最多 4 个可见控件。
2. 页面头部最多 3 个主动作，其余进「更多」。
3. 批量动作只出现在 `SelectionBar`。
4. 对象操作只出现在 Inspector、右键菜单或卡片「…」。
5. 新功能若不属于上述层级，先进入 AI 中心/设置/更多，不新增顶栏按钮。
6. 同一动作不在多个层级重复出现；提供命令面板作为键盘入口。
7. 危险操作默认在「更多」中，需要二次确认。
8. 模型未安装时显示 CTA，但不让每个页面各自实现下载逻辑。

## 8. 交互主路径

### 初看资源

```text
首页/资源库
  → 页面头部筛选
  → 点卡片
  → Inspector 详情
  → 查看器/播放器
```

### 批量整理

```text
页面头部「选择」
  → 点选/Shift 范围
  → SelectionBar
  → 设置分类/角色/扮演者/加入合集
  → 完成/退出
```

### AI 搜图

```text
顶栏搜索框
  → 切换到「智能搜图」
  → 输入中文描述 / 当前图片找相似
  → AI 中心搜索结果
  → 点结果回资源库/查看器
```

### 模型首次使用

```text
AI 动作
  → 模型未安装提示
  → AI 中心模型 tab
  → 下载/校验
  → 完成
  → 返回原动作
```

### 智能导入

```text
导入向导
  → 勾选「导入后智能分析」
  → 导入完成
  → AI 中心任务/建议
  → 用户确认分类/标签/角色/合集
```

## 9. 状态与响应式

### 状态

- 空：说明下一步，不堆按钮
- 加载：骨架/局部 loading
- 失败：错误 + 重试
- 离线：AI 远程功能禁用，本地功能继续
- 模型未安装：CTA 指向 AI 中心
- 任务运行中：顶栏徽标 + AI 中心任务 tab
- 批量模式：SelectionBar 始终可见
- 窄窗口：Inspector 变抽屉；侧栏图标化

### 宽度

| 宽度 | 行为 |
|---|---|
| ≥1440 | 三栏完整，Inspector 320–360 |
| 1200–1439 | 三栏压缩，筛选折叠 |
| 900–1199 | Inspector 抽屉，侧栏图标化 |
| <900 | 单栏/抽屉优先，不承诺完整桌面布局 |

## 10. 迁移阶段

### 阶段 1：Shell

- 侧栏分组/底部设置
- 顶栏移除批量与主题

## 11. 验收

- 顶栏没有批量操作按钮
- 侧栏不超过 4 组，1280 宽无横向滚动
- 选中后才出现 SelectionBar，退出后消失
- 所有 AI 功能可在 AI 中心找到
- 找相似在 Inspector AI tab 可达
- 模型未安装的状态有统一 CTA
- 页面头部主动作 ≤3 个
- 新增功能可按放置矩阵落位，不需要改 Shell
