# UI Shell 重设计 · 需求

> 状态：**L1 已确认方向 / L2 设计待确认**（2026-10-22）  
> Feature ID：`ui-shell-redesign`  
> 关联：`lrm-ui`、`theme-tokens`、`library-workspace`、`photo-management-next`

## 1. 背景

当前功能持续增加：

- 左侧已有首页、资源库、角色、扮演者、时间线、地图、合集、回收站
- 顶部已出现导入、设置、搜索、主题、批量操作、多个批量动作
- 右侧信息栏承载元数据、地图/时间线开关、角色/扮演者等上下文操作
- 后续还有 AI 搜索、智能导入、智能合集、OCR/描述、模型下载、任务中心

问题不是单个页面不好看，而是：

- 功能入口按“新增功能”不断增加，缺少稳定层级
- 全局动作、页面动作、选中态动作混在同一个顶栏
- 未来 AI 功能如果继续加按钮，会让界面失控
- 用户很难判断“这个功能在哪个层级、什么时候出现”

## 2. 目标

1. 设计一个能容纳未来 AI 功能的桌面 UI Shell
2. 全局动作、页面动作、选中态动作、对象动作分层
3. 左侧导航稳定、可分组，不因每个新功能增加一项
4. AI 能力统一收口，不散落成大量按钮
5. 保留现有三栏结构、主题令牌和主要页面，不重写业务
6. 1280 宽桌面窗口下不拥挤，窄窗口可降级

## 3. IN / OUT

### IN

- 左侧导航分组与层级
- 顶部全局命令栏
- 页面级工具栏/视图切换
- 选中态批量操作栏
- 右侧 Inspector 的上下文与 AI 扩展位
- AI 中心（搜索、模型、任务、建议）
- 未来功能放置规则
- 空态、加载、失败、模型未安装状态
- 响应式降级规则

### OUT

- 新的业务能力实现
- AI 模型具体实现
- 推翻现有主题令牌
- 移动端布局
- 多用户/协作
- 重新设计每一个业务组件

## 4. 验收方向

- 顶栏只保留全局动作，不再承载批量按钮
- 批量操作在选中态出现，退出后消失
- 新功能有明确的放置矩阵，不能随意加顶栏按钮
- AI 搜索、找相似、智能导入、智能合集都有固定入口
- 左侧导航在 1280 宽下不产生横向滚动
- 用户能在 2 次点击内找到 AI 搜索/AI 中心
- 现有页面路由和业务行为不被破坏
- 窄窗口下 Inspector 可收起，导航可折叠

## 5. 已确认方向

- 左侧导航采用「浏览 / 视图 / 组织 / 工具」四组
- AI 中心固定在侧栏工具组
- 顶部采用「导入 / 整理 / AI / 设置」工具组，点击展开
- 选中态使用底部「整理 / 退出」入口

## 6. L3 再细化

- Inspector 默认展开还是按页面记忆
- 资源库类型 tabs 的最终位置
- 工具组具体菜单项与快捷键
- Shell 迁移的组件/文件清单
