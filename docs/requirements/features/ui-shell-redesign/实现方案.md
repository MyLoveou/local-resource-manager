# UI Shell 重设计 · 实现方案

> 状态：**核心切片已实施**（2026-10-22）；页面头部统一/响应式细化为余项  
> 上游：`需求.md`、`设计.md`  
> 范围：UI Shell、导航、顶部工具组、选中态操作栏、Inspector 容器、AI 中心入口占位。  
> 不在本切片：AI 模型、搜索算法、智能导入/合集业务实现。  
> 实施备注：首版选中态操作栏暂由 `ToolBar` 的 batch 区承载，后续再抽成独立组件。

## 1. 施工原则

- 复用现有 `ui/layouts`、`components`、`application/stores`，不新建平行页面框架。
- 先改 Shell，再逐页迁移；每步保持现有路由和业务行为。
- `App.vue` 继续作为全局组合根；页面内部不复制导航/顶栏。
- 先做结构，再做视觉细节；沿用 `theme-tokens`。
- AI 中心先做入口和空态，不接模型。

## 2. 目标结构

```text
App.vue
  AppShell
    GlobalToolGroups
    MenuBar (grouped)
    main
      page router-view
      SelectionBar (conditional)
    InfoPanel (tabs, phase 2)
  overlays
```

组件职责：

| 组件 | 路径 | 职责 |
|---|---|---|
| `AppShell` | `ui/layouts/AppShell/index.vue` | 三栏骨架、顶栏/侧栏/Inspector 槽位 |
| `GlobalToolGroups` | `ui/layouts/GlobalToolGroups/index.vue` | 搜索、导入、整理、AI、设置分组 |
| `MenuBar` | `ui/layouts/MenuBar/index.vue` | 分组导航、折叠、active key |
| `SelectionBar` | `ui/layouts/SelectionBar/index.vue` | 选中数量、整理入口、退出 |
| `CommandPalette` | `components/CommandPalette/index.vue` | 搜索/跳转/命令（可分步） |
| `AI` 入口页 | `views/AI/index.vue` | AI 中心空态与 tabs 骨架 |
| `InfoPanel` | `ui/layouts/InfoPanel/index.vue` | 详情/关联/AI tabs（阶段 2） |

## 3. 路由与导航

### 3.1 路由

新增：

```text
/ai   AI 中心
```

保留现有路由；暂不改业务路由。

`route.meta` 增加可选的导航分组信息，避免 `MenuBar` 手写导航：

```text
meta: {
  title: '首页',
  icon: 'home',
  menuGroup: 'browse'
}
```

分组：

```text
browse: 首页、资源库
view: 时间线、地图
organize: 合集、角色、扮演者
tools: AI 中心、回收站
```

### 3.2 菜单模型

- `domain/menu.ts` 从 route 生成 groups；没有 `menuGroup` 的路由不进入侧栏。
- `MenuBar` 渲染分组标题/子项；折叠时只显示图标。
- 设置不进入侧栏；由 `GlobalToolGroups` 的「设置」组承载。

## 4. 顶部工具组

### 4.1 配置

新增 `ui/layouts/GlobalToolGroups/config.ts`：

```text
导入：文件、文件夹、监视目录、最近导入
整理：选择资源、批量分类、批量标签、设置角色、设置扮演者、加入合集、更多
AI：智能搜图、找相似、模型管理、任务、建议
设置：设置、主题、检查更新、日志、数据维护
```

每个 item：

```text
id / label / icon / shortcut? / disabled? / action
```

### 4.2 行为

- 点击展开；同一时间只开一个组；`Esc`/外点关闭。
- 没有选中资源时，「整理」只显示「进入选择模式」，批量项 disabled 或提示先选择。
- AI 模型未安装时，「AI」组显示「安装模型」CTA，点击进入 AI 中心。
- AI 任务状态徽标来自后续 store；本切片先留徽标位。
- 低频操作进入「更多」；危险动作放最后并二次确认。
- `Ctrl/Cmd+K` 打开命令面板，作为键盘替代入口。

## 5. 选中态操作栏

- 从 `shellBatch` 读取 `batchMode/selectedCount`。
- 只在批量模式显示；悬浮在内容区底部。
- 主按钮「整理」打开与顶部相同命令配置；右侧「退出」。
- 不再在 `ToolBar` 显示批量按钮。
- 现有 `ResourceBrowser` 的 batch action 逻辑不重写，只改变入口和展示。

## 6. Inspector 容器

阶段 1 先保留现有 InfoPanel 内容，只做外层：

- 可折叠
- 宽度 320–360
- 窄窗口抽屉
- tabs 先占位「详情 / 关联 / AI」；内容迁移放阶段 2
- 对象级动作不进入顶部工具组

## 7. AI 中心

阶段 3 先做：

- 路由 `/ai`
- tabs：搜索、模型、任务、建议
- 空态：模型未安装/尚未索引
- 不接 AI 后端；不展示假功能按钮
- 入口只有：侧栏工具组、顶栏 AI 状态、顶栏 AI 组

## 8. 实施切片

### 切片 A：导航模型

- `route.ts` 增加 `menuGroup`
- `domain/menu.ts` 生成 groups
- `MenuBar` 分组渲染

### 切片 B：Shell + 顶部工具组

- 把现有导入/设置/主题/批量入口迁移到组

### 切片 C：选中态操作栏

- 新建 `SelectionBar`
- 绑定 `shellBatch`

- 保持批量动作调用不变

### 切片 D：Inspector 壳

- 现有内容进「详情」
- 关系/角色/扮演者进「关联」

### 切片 E：AI 中心入口

- 新建 `views/AI/index.vue`
- 路由 `/ai`
- 四个 tab 空态
- 顶栏/侧栏入口

### 切片 F：页面头部与响应式

- 统一 page header 结构
- 副标题/筛选/视图切换收口
- 1280/1440 宽度验收
- 键盘可达、focus、`Esc`

## 9. 数据流

```text
route meta
  → menu groups
  → MenuBar

GlobalToolGroups config
  → action handlers
  → router / import wizard / selection store / settings / AI center

shellBatch
  → SelectionBar
  → 现有 runBatch / selection 逻辑
```

## 11. 验证

- typecheck / build / lint
- 现有批量操作回归：选择、分类、标签、角色、扮演者、加入合集
- 路由回归：首页、资源库、时间线、地图、合集、角色、扮演者、回收站
- 1280/1440 窗口截图检查
- 无横向滚动、无顶栏溢出
- 键盘：`Ctrl/Cmd+K`、`Esc`、Tab/focus
- 模型未安装时 AI 入口有明确 CTA
- 不出现空按钮/假功能

## 12. 风险

- `ToolBar` 现有批量逻辑和弹窗较多，迁移时先保持逻辑，只换入口
- `InfoPanel` 内容复杂，阶段 1 只做外壳，不重写字段
- 路由 meta 分组要兼容 `hideMenu` 与 `isSectionHidden`
- AI 中心先空态，避免让用户误以为功能已可用
- 页面头部统一不能改变现有筛选/滚动行为

## 13. 交付顺序

1. 导航分组
2. AppShell + 顶部工具组
3. SelectionBar
4. Inspector 外壳
5. AI 中心入口
6. 页面头部/响应式
7. 回归、截图、文档

每个切片可独立提交；最终以页面组合和主路径验收为完成标准。
