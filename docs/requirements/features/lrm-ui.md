# 页面结构 · local-resource-manager

> 状态：**已定稿**（2026-08-30）
> 主需求见 [local-resource-manager.md](local-resource-manager.md)。

## 1. 整体布局（三栏 + 顶栏）

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：搜索 + 排序 + 工具栏按钮（全局）                     │
├────────────┬───────────────────────────────┬───────────────┤
│ 左侧菜单    │ 中间：资源列表                 │ 右侧：元数据   │
│            │ 卡片 / 虚拟列表               │ 面板（全部资源 │
│            │                              │ 均有）         │
└────────────┴───────────────────────────────┴───────────────┘
```

- 三栏固定，宽度可拖拽调整
- **所有资源视图均带右侧元数据面板**（图片、视频、回收站内资源）
- 元数据面板**暂不支持折叠/隐藏**

## 2. 顶栏（全局）

| 元素 | 说明 |
|------|------|
| 工具栏按钮 | **添加目录、立即扫描**、回收站入口（可扩展） |
| 搜索框 | 全局搜索，匹配标题/标签/简介，支持实时输入 |
| 排序控件 | 名称 / 时间 / 大小 / 评分，升/降序 |
| 视图切换 | 网格卡片 / 紧凑列表（可选） |

## 3. 左侧菜单

```
资源（可展开）
├── 图片
├── 视频
├── 小说（占位）
├── 番剧（占位）
├── AV（占位）
回收站
[底部] 设置按钮 → 弹窗
```

| 元素 | 说明 |
|------|------|
| 资源 | 默认选中；**子菜单按资源种类**，点击进入对应类型视图 |
| 子菜单占位 | 小说/番剧/AV 显示但置灰/标记「后续版本」，不可进入 |
| 回收站 | 软删除资源，支持恢复 / 彻底删除 |
| 设置按钮（底部固定） | **打开设置弹窗**，非页面跳转 |

## 4. 中间：资源列表（卡片 / 虚拟列表）

| 行为 | 说明 |
|------|------|
| 渲染 | 卡片网格 + **虚拟列表**（滚动按需渲染，万级资源流畅） |
| 卡片内容 | 缩略图/封面、标题、类型标记、关键元数据（视频：时长/分辨率；图片：宽高） |
| 单击 | 选中 → 右侧元数据面板更新 |
| 双击 | 图片：大图预览；视频：内嵌播放 / 唤起系统播放器 |
| 右键菜单 | 获取元数据、**编辑**、移到回收站、在文件管理器中定位、重新扫描 |
| 多选 | Ctrl/Shift 多选，支持批量操作（批量打标、批量获取元数据、批量删除） |
| 空态 | 无资源/无结果/加载中均有对应状态 |

## 5. 右侧：元数据面板（所有资源均有）

| 区块 | 内容 |
|------|------|
| 头部 | 封面/缩略图大图、标题（可编辑）、类型标记、评分 |
| 文件信息 | 路径、大小、格式、分辨率、时长/宽高、拍摄时间、哈希 |
| 标签 | 标签列表（可增删），批量打标入口 |
| 简介 | 可编辑文本域 |
| 元数据来源 | 抓取来源、抓取时间（审计） |
| 操作按钮 | 获取元数据（触发抓取候选）、预览/播放、在文件管理器中打开、移到回收站 |

> 编辑入口：**右键菜单「编辑」与面板内直接编辑并存**。

## 6. 回收站视图

- 列表展示已删除资源（软删除），右侧面板显示原元数据与删除时间
- 操作：**恢复**（回原目录视图）/ **彻底删除**（删除文件记录，可选同时删除磁盘文件）

## 7. 设置弹窗（Modal）

| 页签 | 内容 |
|------|------|
| 资源目录 | 添加/移除目录、手动扫描、扫描进度 |
| 适配器 | 元数据站点适配器开关与参数配置 |
| 播放器 | 默认播放方式（内嵌/系统） |
| 系统 | 日志查看、数据库备份/导出、关于 |
