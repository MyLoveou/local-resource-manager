## 1. 问题

刮削已能找片名。用户还要把网上的**成片文件**拉进库。`/download` 只有 health；`download_tasks` 表空转。M5 原文一次要 aria2 + rqbit + yt-dlp + 磁力 + 设置限速，一刀做不完。

## 2. 本刀收口

1. **同一 FastAPI `/download`**，不另起下载服务进程。  
2. **只做 HTTP/HTTPS 直链**（Content-Length 或 chunked 的文件 URL）。  
3. **执行器用 httpx 流式写盘**，本刀不装、不起 aria2 / rqbit / yt-dlp。`engine` 存 `httpx`。  
4. **落盘到库旁暂存**（`data/downloads/<taskId>/`），完成后再走现有 **复制入库**（`ImportService`），**不**把下载目录登记成可再扫的根。  
5. **本刀类型：视频**（扩展名走现有 video 表）。其它类型、番剧整季、BT 后续刀。  
6. **完成后自动入库**；去重命中则挂已有 `target_resource_id`，删暂存。  
7. **入口**：顶栏「下载」打开任务抽屉（贴链接 + 列表），不新开壳级工作台页。  
8. **失败可读**：中文原因；可取消；暂停后带 Range 续传（源不支持 Range 则从头）。  
9. **状态权威在 SQLite**；进程重启后 `queued`/`running`/`paused` 再入队。  
10. **蜜柑磁力/RSS、B 站原片、登录站点 OUT。**

## 3. 范围

### IN

- 粘贴 `http(s)://` 文件直链 → 建 `download_tasks` → 后台拉字节。  
- 列表：状态、进度、速度、错误；暂停 / 恢复 / 取消。  
- SSRF：禁止非 http(s)、禁止解析到回环/链路本地/私网（含 IPv6 ULA）。  
- 完成：`ImportService` 按 **video** 复制进 owned 包；写 `target_resource_id`；可跳转该资源。  
- 单测：非法 URL 不建任务；假 HTTP 源下完后库内有视频记录。

### OUT

- magnet / torrent / FTP / SFTP / ED2K / WebDAV。  
- aria2c、rqbit、yt-dlp 子进程。  
- 蜜柑 RSS、站点登录、B 站/番剧原片。  
- 并发多路、全局限速、重试次数设置页。  
- OS 通知、设置库路径、扫描根目录。  
- 图片/音频/小说等类型分流（后续可按扩展名加）。

## 4. 用户故事

- **US-D.1** 顶栏打开下载 → 贴一条 mp4 直链 → 进度走到完成 → 视频库出现该片，点开能播。  
- **US-D.2** 暂停再恢复：支持 Range 的源从断点续；不支持则提示后重下。  
- **US-D.3** 取消：任务 failed「已取消」，暂存删除，库内无新资源。  
- **US-D.4** 私网/file/磁力 → 400，不建任务。  
- **US-D.5** 与已入库文件 sha256 相同 → 不建第二份包，任务 done 并关联已有资源。

## 5. 验收

- [ ] US-D.1 本机 httpx mock 或真实直链各至少一条。  
- [ ] 无 aria2/rqbit 进程。  
- [ ] 下载目录未出现在任何 roots/扫描 API。  
- [ ] 磁力/localhost 被拒。  
- [ ] 重启后未完成任务能继续或可点恢复。
