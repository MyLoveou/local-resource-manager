# 网格媒体性能 · 需求

> 状态：**已定稿**（2026-09-12 · 用户确认可按此实现）  
> Feature ID：`grid-media-performance`  
> OpenSpec：`openspec/changes/grid-media-performance/`  
> 所属产品：[local-resource-manager](../local-resource-manager.md) 的 **M2 体验债**  
> 规划落点：[00-路线图与里程碑](../../../design/00-路线图与里程碑.md) · MS2 · T-2.1

## 1. 问题

网格卡片把**原图**当封面拉 HTTP 并解码；拖窗口时列宽每像素重算。封面出得慢，缩放卡。

## 2. 已按口令收口

1. **缩略图在导入时生成**，不是首次浏览再做、也不是只靠前端缩小原图。  
2. **落盘路径必须在资源包内**、角色清晰、随资源删除；禁止全局散列缓存目录。  
3. 网格用缩略图 URL；**信息栏 / 换封面仍用原封面**（`coverPath` 含义不变）。  
4. 本切片不抽视频帧（无封面的视频仍占位）。换封面后**重生成**网格缩略图。  
5. 旧库不回填。生成失败不挡导入，网格回退 `coverPath` 或占位。  
6. 窗口缩放：拖动中**节流重排**（约 100–200ms），不冻结到松手才变列。  
7. 本轮验收以**首屏 + 约千级库可感流畅**为准；L1「万级」作方向，不作本切片硬门槛。

## 3. 本轮做 / 不做

| 做 | 不做 |
|----|------|
| 导入 copy+probe 之后生成一档网格 WebP | 浏览时现算；全局 `_cache/` 缩略图池 |
| 包内 `thumbs/grid.webp` + `files.role=thumbnail` | 改 `cover_path` 去指小图（会糊掉信息栏） |
| 列表字段 `thumbnailPath`；网格优先它 | 信息栏/弹窗改吃缩略图 |
| 换封面后重生成该档缩略图 | 视频 ffmpeg 抽帧当封面（仍后置） |
| VirtualGrid 对宽度节流再算列 | 冷启动、导入吞吐专项、预览播放 |

导入会多花一点时间，本切片不优化导入吞吐。

## 4. 用户故事

- **US-P.1** 导入一张图 → 包内有 `thumbs/grid.webp`；打开图片页卡片用小图，详情封面仍是原图。  
- **US-P.2** 导入无封面视频 → 导入成功，网格占位，不生成空文件。  
- **US-P.3** 换封面 → 缩略图跟着新封面更新。  
- **US-P.4** 缩略图生成失败 → 资源仍在库，网格回退原封面或占位。  
- **US-P.5** 拖窗口 → 列数节流更新，不每像素卡死。

## 5. 验收

- [ ] 新导入图片：磁盘 `{library}/{type}/{id}/thumbs/grid.webp` 存在；`files` 有 `role=thumbnail`。  
- [ ] 列表 JSON 有 `thumbnailPath`，指向该文件的 content URL；网格 `<img>` 用它，不用原图。  
- [ ] 详情 `coverPath` 仍指向原封面/primary 内容，不是 `thumbs/grid.webp`。  
- [ ] 根目录只有约定角色文件（`primary*` / `cover*`），缩略图不散落根上。  
- [ ] 软删/去重失败回滚时，包目录（含 `thumbs/`）一并删掉。  
- [ ] 生成失败：导入成功，无坏掉的半文件挡下次导入。  
- [ ] 无封面视频：无 thumbnail 行，网格占位。  
- [ ] 换封面后 `thumbs/grid.webp` 内容更新。  
- [ ] 拖窗口：列宽计算不跟 `width` 同步每帧触发（节流后对齐）。  
- [ ] 旧资源无 thumbnail：网格仍能显示（回退 `coverPath`）。

## 6. 契约草案

- 列表/详情资源增加可选 `thumbnailPath`（camelCase）。  
- `thumbnailPath` 形如 `/library/resources/{id}/files/{fileId}/content`（已有文件流，不新开路由）。  
- `files.role` 增加 `thumbnail`。物理路径相对包根：`thumbs/grid.webp`。  
- 不新增表。不改 `cover_path` 语义。  
- 常量：最大边长、WebP 质量、目录名、文件名进 `media_types`（前后端对齐）。

禁止：渲染进程写库目录；GET 任意磁盘路径。

## 7. 包内路径（必须遵守）

```
{library_store}/{type}/{id}/
  primary.jpg          # 或视频 primary.mp4
  cover.jpg            # 仅用户换封面时
  thumbs/grid.webp     # 本切片：仅网格用
  subtitles/…          # 已有
```

| 规则 | 说明 |
|------|------|
| 跟资源走 | 只允许 `ResourcePackage` 拼接；禁止 `{store}/_thumbs/{hash}.webp` |
| 子目录 | 派生图进 `thumbs/`，避免和 `primary`/`cover` 抢根目录 |
| 单档 | 本轮一档 `grid.webp`；以后加 `panel.webp` 只加文件，不改目录约定 |
| 覆盖写 | 换封面覆盖同一路径，不留 `grid-2.webp` |

## 8. 假设（未另拍板则按此实现）

1. 缩略图源：有 `cover` 角色用封面；否则图片用 `primary`；视频无封面则不生成。  
2. 最大边 480px（适配约 160px 列宽 × 高 DPI）；格式 WebP。  
3. 窗口缩放节流 100–200ms。  
4. 不回填旧库。
