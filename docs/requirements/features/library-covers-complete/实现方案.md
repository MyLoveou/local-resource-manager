# 全类型封面收口 · 实现方案（L3）

> 状态：**已落地**（D-20260919-07）  
> L2：`设计.md`。用户已授权写方案，**未**授权编码。等「可以按此实现」。

沿用 `covers/` + `attach_cover_image`。不新建表、不改列表契约、不引入 unrar、不回填。

## 1. 对齐

- 渲染进程不解析 EPUB/PDF/zip。  
- 失败不挡导入；临时图必须可被 Pillow 打开再 attach。  
- 旁路图在**源路径**上找（单文件用导入前的 `source`，不要用包内 `primary.mp3`）。  
- 系列/游戏/漫画**目录**只扫作品根海报名，不扫同名剧照。  
- 旧库不回填；cbr 不抽页。

## 2. 锁定

| 项 | 锁定 |
|----|------|
| 优先级 | `user` → 旁路 `folder` → 类型专用 |
| 旁路海报名 | stem ∈ `{cover, folder, poster}`，扩展名 ∈ 图片表；**先于**同 stem |
| 同 stem | `source.stem` + `.jpg/.jpeg/.png/.webp`（不含主文件自己；大小写不敏感） |
| EPUB | stdlib `zipfile` + OPF：`meta name=cover` 的 id 或 `item properties` 含 `cover-image` → href；否则 zip 内文件名 stem 为 cover/folder/poster 的图。**不**用书里第一张插图冒充 |
| PDF | 依赖 **`pypdfium2`** 渲第 1 页为 JPEG；无系统 poppler。坏 PDF / 0 页 → 空 |
| cbz | `zipfile`；条目跳过目录与隐藏名；后缀 ∈ 图片表；`_natural_key` 排序取第一张抽出 |
| cbr | 后缀 `.cbr`：跳过抽页（仍可旁路/手选） |
| origin | 旁路 `folder`；EPUB `embedded`；PDF/漫画页 `page` |
| 漫画目录 | 第一页 primary **走 `attach_cover_image`**，删掉「只改 cover_path 指 `/content`」的提前 return |
| 单文件 comic | primary 为 `.cbz` 则抽 zip；为图片则 attach 该页；为 `.cbr` 则不抽 |

PDF 渲：`to_thread`；最长边不超过现有 `THUMB_MAX_EDGE_PX` 的 4 倍再交给 attach（attach 会再缩成 grid.webp）。超时/异常：warning，无封面。

## 3. `apply_ingest_cover` 控制流

```text
if IMAGE: return
if user locked: return
sidecar = 目录根 find_folder_cover(source_root) 或 单文件 find_sidecar_cover(source_file)
if sidecar: attach(..., folder); return
类型专用:
  VIDEO / ANIME / AV → 现有抽帧
  AUDIO → 现有内嵌
  NOVEL → epub 则 extract_epub_cover；pdf 则 render_pdf_page；其它格式结束
  COMIC → 目录/图片 primary attach page；cbz extract；cbr 结束
  GAME → 现有 exe
  MODEL → 结束（只靠 sidecar）
```

新参数：`source_file: Path | None`（单文件导入的**源**路径）。`source_root` 仍给目录导入。两者都有时：目录导入只用 `source_root` 海报名（L2：不扫每集同名）。

`_ingest_one`：`source_file=source`（复制前的用户文件）。小说/模型/音频/视频/漫画文件均传入。

## 4. 数据流

1. ingest commit 资源行。  
2. `apply_ingest_cover` 在源盘找到图或抽到 tmp → `attach_cover_image`（写 cover + 刷新 thumbnail）。  
3. `_try_register_thumbnail`：已有 thumbnail 则跳过。  
4. 抽失败：资源仍 active，无卡。

## 6. 决策

| 决策 | 选择 | 不选 |
|------|------|------|
| PDF | pypdfium2 | pdf2image+poppler；PyMuPDF |
| EPUB | zip+OPF，无封面条目则仅 cover.* 文件名 | mutagen；把第一章插图当封面 |
| cbz | zipfile | 7zip 子进程 |
| cbr | 跳过 | unrar / 7z |
| 旁路 | 源目录扫描 | 复制进包后再找（包内无旁图） |

## 7. 测试

| 用例 | 期望 |
|------|------|
| `book.epub` 旁 `cover.png` | origin=folder，不读内嵌 |
| 无旁路、OPF 指向图的 epub | origin=embedded |
| 无 cover 条目、只有正文图的 epub | 无 cover 角色 |
| 最小一页 PDF | origin=page，有 thumbnail |
| 空/坏 PDF | 导入成功，无 cover |
| `foo.glb` + `foo.png` | origin=folder |
| 海报名与同名同时存在 | 用 `cover.jpg` 不是 `foo.png` |
| 目录漫画第一页 png | origin=page，cover_path 含 `/files/` |
| zip 夹具 `.cbz` 两张图 | 自然序第一张，origin=page |
| `.cbr` 任意字节 | 导入不炸，无自动 cover |
| `user` 后再 apply | 文件不变 |
| txt 无旁图 | 无 cover |

夹具：测试里写最小 ZIP（EPUB 容器 XML + 一张 png；cbz 两张 png）。PDF 可用 pypdfium2 生成一页或仓库内 tiny.pdf 字节。

## 8. 风险

| 风险 | 缓解 |
|------|------|
| EPUB 命名空间/相对 href | 解析失败当无封面；测常见 OPF |
| PDF 极大页 | 渲时缩放；OOM 则 catch |
| cbz 内 webp/heic | Pillow 失败则无卡 |
| Windows 文件占用 | 抽到 NamedTemporaryDirectory 再 attach |

## 9. 明确不做

- cbr 抽页、刮削、3D 截图、阅读器、每集封面、回填  
- txt/html/mobi/azw3 内嵌  
- 改 ffmpeg 打包
