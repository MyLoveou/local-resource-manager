## 0. 复杂度

补自动源，不改 Resource 表、不改列表契约。跨 zip/EPUB/PDF 渲页与 ingest 选源。不可跳过 L2（源优先级与 origin 枚举要锁死）。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 一处选源 | ingest 按类型走同一优先级函数 | 各 importer 复制一套找封面 |
| 先旁路再内嵌 | 用户放在旁边的图优先于从文件里抽 | 内嵌盖掉用户海报 |
| 写成包内 cover | 自动源都 `attach_cover_image` | 列表吃 cbz/pdf 原文件 |
| 失败不挡 | 抽不出则空 | 因封面回滚整单 |
| 新导入 | 只 ingest | 回填任务 |
| cbr 明示空 | 当 zip 失败的兄弟格式 | 本刀引入 unrar |

## 2. 选源顺序（所有非图片）

`user` 锁定则整段跳过。

1. **旁路图**（`folder`）：  
   - 目录导入：现有 `find_folder_cover(root)`（stem ∈ cover/folder/poster）。  
   - **单文件导入**：在 `primary.parent` 上同样找海报名；再找 `primary.stem` + 图片扩展名（不含主文件自己）。  
   - 系列/游戏/漫画目录：仍只扫**作品根**海报名，不扫每一集同名图（避免把剧照当作品封面）。  
2. **类型专用**：见下。  
3. 都没有：不写 cover。

类型专用（仅当步骤 1 没有命中）：

| 类型 | 动作 | origin |
|------|------|--------|
| 视频 / 番剧 / AV | 现有抽帧 | `frame` |
| 音频 | 现有内嵌图 | `embedded` |
| 小说 `.epub` | zip+OPF 或常见 `cover.*` 条目，抽出一张图 | `embedded` |
| 小说 `.pdf` | 渲第 1 页为 JPEG/PNG | `page` |
| 漫画目录 | 第一页图片（已是 primary）`attach_cover` | `page` |
| 漫画 `.cbz` | zip 内图片自然序第一张，抽出再 attach | `page` |
| 漫画 `.cbr` | 跳过抽页 | — |
| 游戏 | 现有 exe 图标 | `exe` |
| 模型 | 无专用（只靠步骤 1） | — |
| 图片 | 不走本解析（主文件 + grid） | — |

同名图与海报名冲突：海报名（cover/folder/poster）先于同 stem。

## 3. 实现落点（模块，非施工清单）

| 模块 | 职责 |
|------|------|
| `ingest/placement.py` | `find_sidecar_cover(primary: Path)`：海报名 + 同 stem |
| `covers/ingest.py` | 统一顺序；漫画不再提前 return 只改 cover_path |
| `covers/epub.py` | 抽 EPUB 封面字节到临时图 |
| `covers/pdf_page.py` | 第一页渲图；库在 L3 选定（倾向 `pypdfium2`，无系统 poppler） |
| `covers/cbz.py` | zip 内图片扩展名自然序第一张 |
| `import_service._ingest_one` | 单文件传入 `source_root=primary.parent` 或直接 sidecar |
| 单测 | EPUB 夹具、最小 PDF、cbz、同名 png、cbr 不炸、user 不覆盖 |

依赖：可加 **pypdfium2**（PDF）。EPUB/cbz 用 stdlib `zipfile`。不引入 unrar。

## 4. 交互

无新按钮。导入后网格有卡或「无封面」。手换封面逻辑不变。

空态：PDF 坏文件 / EPUB 无封面 / cbz 无图片 / cbr → 导入成功，无卡。

## 5. 不变量

- `thumbnailPath` 仍是列表唯一图。`attach_cover_image` 已刷新 grid.webp。漫画目录必须走 attach，避免 primary 很大时列表解原图（当前 cover_fallback 已能缩第一页；本刀仍写成 cover，与其它类型一致）。  
- indexed 游戏不改。  
- 同名图必须是独立文件，不能把 `foo.glb` 自己当图。
