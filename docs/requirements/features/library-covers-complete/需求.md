## 1. 问题

九种库类型要有完整自动封面链。已有：图片主文件、视频/番剧抽帧、目录海报、游戏图标、音频内嵌。缺口：单文件旁海报/同名图、EPUB、PDF 首页、漫画 cbz 首页、目录漫画未写成 cover 角色、模型无旁路图。

## 2. 已按口令收口

1. PDF 小说本刀抽第一页当封面（失败则空）。  
2. 同名贴图算自动封面（`foo.glb`+`foo.png`、`书名.epub`+`书名.jpg` 等）。  
3. **cbr**：漫画的 RAR 压缩包（Comic Book RAR）。本刀**不**自动解压抽页（要额外 RAR 工具，失败面大）。仍可导入；只能靠旁边海报、手选，或以后另刀。**cbz**（zip）本刀抽第一张图。  
4. 旁海报 + 同名图 + EPUB + PDF + cbz **一刀做完**。  
5. 旧库 **仍不** 回填；开发阶段清库重导。

## 3. 范围

### IN

- 按类型自动链（见 §5）；ingest 一处解析，失败不挡导入。  
- 单文件：源文件所在目录的 `cover`/`folder`/`poster` 图，或与主文件 **同 stem** 的 `.jpg/.jpeg/.png/.webp`。  
- 小说：EPUB 内嵌封面；PDF 第一页光栅化。  
- 漫画：目录第一页写成 cover；**cbz** 从 zip 抽排序后第一张图。  
- `coverOrigin` 沿用：`user|folder|frame|exe|page|embedded`。同名图/目录海报 = `folder`；EPUB = `embedded`；漫画页与 PDF 首页 = `page`。  
- 目录漫画不再只改 `cover_path` 指 content，要 `attach_cover_image` 以便列表有 `grid.webp`。

### OUT

- 刮削；3D 截图；阅读器；每集封面。  
- **cbr 自动抽页**。  
- txt/html/mobi/azw3 内嵌封面（无图则空，仍可用旁海报/手选）。  
- 旧库批量补。  
- 改搜索/播放/系列映射。  
- 把 poppler/unrar/ffmpeg 打进安装包。

## 4. 共用不变量（沿用）

手指定 > 任何自动。列表只用 `thumbnailPath`。无源则「无封面」。图片仍不能换封面。

## 5. 按类型自动链（已锁）

| 类型 | 自动链 |
|------|--------|
| 图片 | 主文件 → grid（不变） |
| 视频 | 旁海报/同名图 → 抽帧 |
| 番剧 / AV | 作品目录海报 → 第一集抽帧 |
| 音频 | 旁海报/同名图 → 内嵌图 |
| 小说 | 旁海报/同名图 → EPUB 内嵌 → PDF 首页 |
| 漫画 | 目录海报 → 第一页 / cbz 内第一图 |
| 游戏 | 目录海报 → exe 图标（不变） |
| 模型 | 旁海报/同名图 |

## 6. 用户故事

- **US-C.1** 新 EPUB 有内嵌封面 → 网格有卡。  
- **US-C.2** 新 cbz → 网格有首页缩略图。  
- **US-C.3** 单文件旁 `cover.jpg` 或同名 png → 用它。  
- **US-C.4** 新 PDF → 有第一页缩略图（库能渲）；渲失败则空，导入成功。  
- **US-C.5** `foo.glb`+`foo.png` → 有卡。  
- **US-C.6** 手选封面后自动逻辑不改图。  
- **US-C.7** 仅 txt / 仅 cbr 无旁图 → 导入成功，「无封面」。  
- **US-C.8** 目录漫画第一页 → 有 `thumbnailPath`，不是只靠原图 content。
