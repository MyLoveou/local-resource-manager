## 1. 后端

| 文件 | 职责 |
|---|---|
| `apps/backend/app/ai/infrastructure/model_store.py` | 模型目录、安装检测、代理解析、流式下载 |
| `apps/backend/app/ai/infrastructure/person_detector.py` | YOLOv8n 人数检测 |
| `apps/backend/app/ai/application/query.py` | 人数/方向/标签查询解析 |
| `apps/backend/app/ai/application/labels.py` | 固定中文标签词表与零样本选标 |
| `apps/backend/app/ai/infrastructure/runtime.py` | ONNX session、tokenizer、图片/文本编码 |
| `apps/backend/app/ai/application/jobs.py` | 下载/索引任务状态 |
| `apps/backend/app/ai/application/service.py` | 状态、下载、构建索引、特征过滤、余弦搜索 |
| `apps/backend/app/ai/application/schemas.py` | AI API 模型 |
| `apps/backend/app/ai/api/router.py` | `/ai/*` |
| `apps/backend/app/shared/db/migrations/0025_ai_vectors.sql` | 向量表 |
| `apps/backend/app/shared/db/migrations/0026_ai_attributes.sql` | 人数/方向特征表 |
| `apps/backend/app/main.py` | 注册 `/ai` router |

依赖：

```text
numpy
onnxruntime
tokenizers
```

模型下载通过 `httpx`，优先读取环境代理，Windows 下回退读取 IE/WinINET 代理；写入 `.part` 后原子替换。
