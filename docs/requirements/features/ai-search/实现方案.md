## 3. API

```text
GET  /ai/status
POST /ai/models/install
POST /ai/index
POST /ai/analyze
POST /ai/vlm/pull
GET  /ai/jobs/{job_id}
GET  /ai/search?q=...&limit=30
GET  /ai/similar?resourceId=...&mode=auto&limit=30
POST /ai/similar/file
POST /ai/search/fusion
```

`/ai/search` 和 `/ai/similar` 额外返回：

- `queryInsight`：查询来源、解析后的语义文本、硬条件、图片 caption/tags、人数、方向、检索路径。
- `explanations`：与结果数组对齐的匹配依据；`/ai/similar` 另返回 `duplicateExplanations`。
- 解释只展示可观察的检索信号，不返回或伪造模型内部思维链。
