# 学习型重排器（Learning to Rank）

状态：v0 反馈重排已实现（相关/不相关反馈、查询-结果加权和反馈表）；训练型重排器仍未实现，列为中期方案。当前检索仍使用 CLIP 相似度、硬过滤、dHash 和 RRF。

## 目标

以文搜图先由 CLIP 召回 Top 100，再由轻量重排器精排出 Top 10。重排器不修改 CLIP 向量，只对候选结果重新打分；它负责把“语义相近但用户真正想要”的结果往上排。

首版目标是可观测、可回退，不追求复杂模型：

- 基线：逻辑回归，可解释、训练和推理都便宜。
- 进阶：LambdaMART 或小型 MLP。
- 输出：Top-K 重排分数；低于置信阈值时回退 CLIP 原始排序。
- 不允许绕过人数、方向、标签等硬过滤。

## 候选与特征

### 查询侧

- 原始查询、解析后的语义文本
- 人数条件、方向条件、固定标签/文案标签
- 查询长度、是否含否定词、查询语言
- 查询图片的 CLIP 标签、VLM 文案、人数、方向

### 结果侧

- CLIP 文本/图片相似度（原始召回分）
- 图片 dHash 距离、是否近似重复
- 图片质量分：分辨率、清晰度、长宽比、文件大小
- 已有 caption/tags 与查询的文字重合度
- 人数、方向、标签等结构化属性
- 来源目录/导入批次/是否收藏等轻量先验

### 行为与画像

- 曝光、点击、收藏、加入合集、标记相关/不相关
- 查询-结果共现次数
- 历史点击率（按查询、结果、查询类别分桶）
- 用户画像：常用标签、常用人数/方向偏好、近期操作
- 位置偏差：记录结果位次，训练时做位置纠偏

购买类反馈暂不适用：本地图库没有购买行为；保留字段，未来有商城或外部来源时再启用。

## 标签

- 点击：弱正样本，需要位置纠偏。
- 收藏、加入合集、标记相关：强正样本。
- 明确标记不相关：强负样本。
- 未点击：不能直接当负样本，只能作为“未观察/未选择”；用曝光日志和随机探索补足。
- 训练样本按查询分组，评估 NDCG@10、MRR、Top10 相关率，而不是只看点击率。

## 存储与隐私

新增表（迁移尚未创建）：

- `ai_search_queries`：查询文本、解析特征、时间、结果数量。
- `ai_search_impressions`：查询 ID、资源 ID、位次、召回分、特征快照。
- `ai_feedback_events`：点击/收藏/相关/不相关/加入合集，资源 ID、查询 ID、时间。
- `ai_ranker_models`：模型版本、特征版本、训练时间、离线指标、是否启用。

约束：

- 默认只保存在本地 SQLite，不上传查询、文案、图片或反馈。
- 用户可关闭反馈采集、清空反馈和模型。
- 查询文本可能包含敏感信息，日志中只保留训练所需字段，并支持清理。
- 训练集、验证集按时间切分，避免用未来反馈训练过去。

## 训练与上线

1. 先记录曝光和反馈，不立即改变排序。
2. 达到最小样本量后训练逻辑回归基线；特征做归一化和缺失值处理。
3. 离线评估 NDCG@10、MRR、Top10 相关率；和 CLIP 基线做同查询对比。
4. 影子模式：只计算不生效，记录与线上排序的差异。
5. 小流量 A/B：按查询哈希分流；保留一键回退。
6. 定期增量训练；模型版本和特征版本一起发布。

模型体积目标：小于 10 MB；推理不引入 GPU 依赖。优先导出为 JSON 系数或 ONNX，随应用本地加载。

## 接口接入点

```text
CLIP 召回 Top 100
  -> 特征拼装
  -> ranker.predict
  -> 硬过滤复核
  -> Top 10
  -> 回退：ranker 不可用/低置信时用 CLIP 分数
```

重排器只调整顺序，不改变 `matched` 的硬过滤语义；搜索结果中的解释需要同时显示原始 CLIP 分和重排分，避免“为什么排在前面”不可见。

## 分阶段

### M1 反馈与数据

- 记录查询、曝光、点击、收藏、相关/不相关。
- 增加反馈开关和清空入口。
- 离线统计查询-结果共现和 CTR，先不训练。

### M2 逻辑回归基线

- 特征快照和训练脚本。
- 离线评估与影子模式。
- 配置开关；默认关闭。

### M3 精排上线

- 小流量 A/B。
- 低置信回退。
- 解释面板显示重排依据和模型版本。

### M4 进阶

- LambdaMART / 小型 MLP。
- 增量训练、位置纠偏、冷启动策略。
- VLM caption/tags 作为特征参与重排。

## 验收标准

- 重排器不可用时，搜索仍按 CLIP 正常返回。
- 硬过滤不被重排绕过。
- 同查询可复现；模型版本、特征版本可追踪。
- 离线指标优于基线，且 A/B 不显著伤害长尾查询。
- 用户能关闭反馈采集并清空数据。

## 当前不做

- 不引入在线学习或每请求训练。
- 不在首版引入深度排序模型。
- 不上传行为数据。
- 不把购买/交易反馈用于本地图库。
- 不在没有曝光日志的情况下把“未点击”当负样本。
