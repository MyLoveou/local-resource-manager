# AI 本地搜图 · 需求

> 状态：L1 已定，随首版实现同步落地（2026-10-23）  
> 上游：`ui-shell-redesign` 已预留 AI 中心入口。

## 1. 问题

图库已支持关键词、标签、分类、角色/扮演者筛选，但这些都依赖已有文字元数据。用户记得画面内容时，无法用自然语言找到图片，也无法按相似图片继续浏览。

## 2. 目标

- 用中文描述搜索本机图片，例如「海边」「两人合照」「蓝色头发」。
- 全部在本机完成；图片不上传，不依赖云端 API。
- 模型、索引和任务状态都在 AI 中心可见。
- 首版不引入向量数据库、RAG 或 LangChain。

## 3. 范围

### 3.1 IN

- 安装/检测中文 CLIP 本地模型（可选下载）。
- 为 active 图片建立本地向量索引。
- 为图片提取结构化特征：人数、横竖方向、场景/动作/颜色/物体标签；查询支持「一个人 / 两个人 / 合影 / 横图 / 红帽子 / 跑步」等条件。
- 由标签合成一段可读描述（caption），作为后续自由文案/VLM 的落点。
- 文字搜索图片，返回按相似度排序的资源卡片，并区分 `indexed / matched / returned`。
- 模型安装进度、索引进度、失败提示。
- AI 中心「搜索 / 模型 / 任务 / 建议」结构。
- 顶栏 AI 状态与入口。
- 数据库迁移、后端 API、前端类型与回归测试。

### 3.2 OUT

- 以图搜图 / 找相似（下一刀）。
- 人脸识别、人物聚类。
- OCR、自动标签、自动描述、智能合集。
- 视频/音频向量。
- 远程 AI Provider、云端索引。
- 自动监听导入并增量索引。
- 向量数据库 / FAISS / LanceDB / sqlite-vec。
- 模型微调。

## 4. 用户流程

### 首次使用

1. 打开 AI 中心。
2. 看到「安装模型」，下载约 182 MB。
3. 安装完成后看到「建立索引」。
4. 索引完成后输入中文描述搜索。

### 日常使用

1. 顶栏显示「AI 就绪」。
2. 打开 AI 中心或顶栏 AI → 智能搜图。
3. 输入描述，点击/回车搜索。
4. 点击结果打开图片查看器。

## 5. 验收

- 未安装模型时，不显示可用的搜索框；显示安装入口。
- 模型安装失败有明确错误，不假装完成。
- 索引期间显示已处理/总数；失败可重试。
- 搜索只查 active 图片；软删图片不返回。
- 索引/搜索不把图片或描述上传。
- 现有图库、时间线、地图、角色、扮演者功能不回归。
- 236 张测试图可在 1 分钟内完成索引；单次文字搜索 < 2 秒（不含首次模型加载）。

## 6. 约束

- 当前 Python 3.14；使用 `onnxruntime` CPU。
- 模型文件不进入 Git，不进入默认安装包；首次下载。
- 数据目录跟随 `settings.db_path` 所在目录。
- 不新增顶级导航；AI 入口固定在「AI 中心」。
