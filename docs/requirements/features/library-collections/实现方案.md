## 数据流

- 全库混排：`GET /library/resources`（type 空、无 q/标签/分类）→ 后端 UNION（resources + collections 按时间）→ items 混排；有过滤条件时不含合集卡
- 合集管理：`/library/collections` CRUD；`/collections/:id/items` 成员列表（返回 Resource 形状）
- 自动归集：watch 导入成功 → 读开关 → 按**目录名**定位/新建合集 → 加入导入的资源 id
- EP 前缀：video 导入时 `titleWithEp` 开 → `{ep:02d}. {title}`
