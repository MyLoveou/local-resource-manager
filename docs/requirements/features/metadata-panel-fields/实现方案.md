## 目标 / 不交付

与需求一致。沿用 InfoPanel + `library` + `ResourcePackage`。

## 工具落点

- **Pillow**：后端依赖。`Image.open(path)` 读 size；不把图解码进渲染进程。  
- **ffprobe**：`asyncio.create_subprocess_exec("ffprobe", "-v", "error", "-show_format", "-show_streams", "-of", "json", path)`，解析 JSON。找不到可执行文件或非 0 退出 → 空探测，导入继续。  
- 清晰度/画质：纯函数，阈值与分辨率对在 `media_labels` 常量中查表。  
- 类型扩展名：`app/shared/media_types.py` 与桌面 `domain/mediaTypes.ts` 映射表；导入对话框 `fileFilterForResourceType(type)`，禁止三元硬编码。
