## 1. 问题

通用面板缺描述/待办/格式与类型专属技术信息；视频不能挂字幕。导入阶段名义 `probe` 未真正读取媒体，面板即使做了也会空。

## 2. 已按口令收口

1. **描述**：面板展示并可编辑；随现有「保存」写入。  
2. **待办**：当前资源；增/改/勾/删**立刻请求**。  
3. **格式**：主文件 `format`。  
4. **图片**：分辨率、作者；导入用 **Pillow** 写入宽高。  
5. **视频**：时长、作者、清晰度、分辨率、**帧率、码率、画质**；导入用 **ffprobe** 写入可探测字段。  
6. **字幕**：复制进 `subtitles/`；名对齐**导入原始视频文件名**；多语言。  
7. 面板**不**在打开详情时补探测；只读库中已有列。新导入必须写入。旧资源不回填。  
8. 仍走 InfoPanel；渲染进程不写库目录。  
9. **扩展名与过滤配置化**：封面/字幕/导入对话框均查映射表（`RESOURCE_FILE_FILTERS` / `SUBTITLE_FILE_FILTER` / `COVER_FILE_FILTER`），不在组件内写死 jpg/srt 列表。

## 3. Pillow 与 ffprobe 是什么

二者都是**后端探测用的现成工具**，不是本仓库自研算法。渲染进程不调用它们。

| | Pillow | ffprobe |
|--|--------|---------|
| 是什么 | Python 图片库（`pip` 包 `Pillow`） | FFmpeg 套件里的**只读探测**命令行，不转码、不重编码 |
| 本切片用来 | 打开刚复制进库的图片，读 `width` / `height` | 读视频流的宽高、时长、帧率、码率、编码 |
| 怎么进项目 | 写入后端 `requirements.txt`，随 Python 环境安装 | 调用本机 PATH 上的 `ffprobe`；没有则视频探测字段留空，**导入仍成功** |
| 不是 | 不是 Photoshop；不改像素当封面 | 不是播放器；本切片不做抽帧、不做转码 |

清晰度、画质是我们用探测结果**算出的展示文案**，不另装工具。

## 5. 用户故事

- **US-F.1** 选图片 → 描述、格式、分辨率、作者、待办。  
- **US-F.2** 选视频 → 时长、清晰度、分辨率、帧率、码率、画质、作者、添加字幕。缺列「—」。  
- **US-F.3–F.5** 字幕多语言命名（同轮次 2）。  
- **US-F.6** 新导入一张图 → 详情分辨率有数。新导入一条视频（本机有 ffprobe）→ 宽高/时长/帧率/码率有数，清晰度与画质可算。无 ffprobe → 导入成功，视频技术字段「—」。  

## 6. 验收

- [ ] 描述、待办立刻写、字幕命名：同轮次 2。  
- [ ] 图片：分辨率、作者；无添加字幕；无帧率/码率/画质。  
- [ ] 视频：时长、分辨率、清晰度、帧率、码率、画质、作者、添加字幕。  
- [ ] 新导入图片写入 width/height；探测失败不挡导入。  
- [ ] 新导入视频在 ffprobe 可用时写入 width/height/duration/fps/bitrate/codec；不可用或失败不挡导入。  
- [ ] 清晰度、画质不落库。  
- [ ] 码率展示为可读单位（如 `8.5 Mbps`）；帧率为 `24 fps` / `23.98 fps` 一类。  

## 7. 契约草案

- `PATCH`：`author`；描述仍走现有。  
- `GET` 详情：`author`、`todos[]`；`files[]` 含 format、width、height、duration、**fps、bitrate、codec**。  
- 待办立刻 API：同轮次 2。  
- `POST .../subtitles`：同轮次 2。  
- 迁移：`resources.author`；`resource_todos`；`files.fps REAL`；`files.bitrate INTEGER`（**比特/秒**）。`codec` 已有列，probe 写入。

禁止：渲染进程写库；GET 任意磁盘路径。

### 字幕命名

同轮次 2：`subtitles/{originalStem}[.{lang}]{ext}`。

### 清晰度（展示）

同轮次 2：标准分辨率双向匹配，否则 `min(宽,高)` 落档。缺宽高 →「—」。

### 帧率 / 码率（存储 + 展示）

- `fps`：主视频流平均帧率。  
- `bitrate`：容器总码率（`format.bit_rate`）；没有则退视频流码率。  
- 展示缺值 →「—」。

### 画质（展示，不是清晰度）

清晰度 = 画面有多少像素（1080p / 4K）。  
画质 = 这些像素**压得有多狠**（码率相对分辨率和帧率）。

用每像素比特（bpp）：

`bpp = bitrate / (width × height × fps)`  
（bitrate 为比特/秒；三者缺一则画质「—」。）

编码效率不同：HEVC / AV1 / VP9 在同样观感下 bpp 更低，计算前把 bpp **乘 1.6** 再分档；H.264 / AVC / 其它不加权。

| 加权后 bpp | 文案 |
|------------|------|
| ≥ 0.20 | 高 |
| ≥ 0.10 | 中 |
| ≥ 0.05 | 一般 |
| < 0.05 | 偏低 |

这是经验档，不是实验室测分。面板同时给出精确码率、帧率、分辨率，避免只看一个词。不手填。

## 8. 已确认假设

1. 作者：自由文本。  
2. 待办：立刻 API。  
3. 字幕：原始视频名 + 语言后缀。  
4. 面板 GET 不探测；**新导入 probe 纳入本切片**。旧库不回填。  
5. 清晰度、画质只展示。  
6. 无 ffprobe 不挡导入。  
7. 本切片不把 FFmpeg 打进安装包。
