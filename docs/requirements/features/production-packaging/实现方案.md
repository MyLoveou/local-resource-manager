## 数据流

### 生产运行

1. `main/index.ts`：`app.isPackaged` → `app.setPath('userData', %APPDATA%/local-resource-manager)`
2. `loadBackendConfig()` → `{ mode:'frozen', backendExe: resources/backend/source-manager-backend.exe }`
3. `startBackend()`：空闲端口 + token → spawn exe（cwd=exe 目录；env：`BACKEND_TOKEN/BACKEND_VERSION/LOG_DIR/BACKEND_DB_PATH`）→ `/health` 轮询
4. 后端首启建库（migrations 从 `_MEIPASS` 读）→ 库包目录 = DB 同级 `library/`

### 发布

`pnpm release:win` → 清理 → typecheck/lint/pytest → electron-vite build → PyInstaller → electron-builder（nsis+zip）→ verify（产物/版本/冒烟/SHA256）

## 纵向步骤

1. **运行时切换**：`config.ts`/`backend.ts`/`index.ts`；验证：`pnpm dev` 仍起后端
2. **冻结资源**：`run_server.py`、`backend.spec`、`migrations.py`、`_VERSION`；验证：直接 spawn 冻结 exe → `/health` 200、DB 生成
3. **打包描述**：`electron-builder.yml` + desktop `package.json`；验证：`electron-builder --dir` 产物含 `resources/backend`
4. **发布编排与校验**：两个脚本 + 根脚本 + gitignore；验证：`pnpm release:win` 全链路零退出
5. **CI**：workflow 复用同一入口；验证：本地等价命令通过，CI 由 tag/dispatch 触发
6. **组合验收**：干净目录跑 `release:win`，安装器/zip 与 SHA256 齐全；`pnpm dev` 回归
