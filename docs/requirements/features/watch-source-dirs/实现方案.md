## 数据流

- 读：GET /settings → get_view → load_watch_dirs(KV) → `watch.dirs`（camelCase）
- 写：PATCH /settings/watch → normalize → validate → put_json(KEY_WATCH) → WatchManager.apply → 返回 view
- 启动：main.py lifespan → env 有值用 env，否则 DB → apply

## 步骤（纵向）

1. 后端算法层 + 常量 + schemas
2. 后端 service + WatchManager + main 接入
3. 后端路由 + 冒烟（含 envLocked / 400 / 重配生效）
4. 前端类型 + API + SettingsModal 页签
5. 组合验收：设置保存 → 监视目录放文件 → 后端日志出现按类型事件
