# 监视目录配置 · 能力设计

> 状态：**已定稿**（2026-10-07）
> 上游需求：[需求.md](需求.md)

## 1. 设计原则

- 复用 settings 域既有模式：KV 仓储、`PATCH /settings/*`、`envLocked` 提示，不新造范式
- 监视目录是**设置数据**（运行时真源 DB），env 仅作开发引导/锁定
- 重配 = 整体重启监视器（简单可靠）；不做增量 schedule/unschedule

## 2. 模型

- 持久化：`settings` 表 KV，`KEY_WATCH = "watch.dirs"`，值 `{"dirs": {"image": ["D:\\Pics"], ...}}`
- 键为 ResourceType 值；合法类型 = `File_Extension_Map` 键：image/video/**anime/av**/audio/novel/comic/model（anime/av 扩展名同视频；game 为 package 型、work_directory 无扩展名，均不可监视）
- 不变量：目录去空、去重、去尾分隔符；保存前目录必须存在
- 自动导入：file 型（image/video/audio/novel/comic/model）监视事件经 WatchBridge 接入 ImportService；anime/av 为剧集型，事件级导入未接入（需要目录级上下文，后续立项）

## 3. 交互（主路径）

```
打开设置 → 「监视」页签（载入 watch.dirs）
  ├─ 某类型「添加目录」→ 原生 selectDirectory → 加入本地列表（重复项忽略）
  ├─ 目录 tag 上 × → 从本地列表移除
  └─ 「保存」→ PATCH /settings/watch → 后端 normalize+校验 → 持久化 → WatchManager.apply → 返回新 view → toast
空态：无目录时类型行显示「未监视」；envLocked 时顶部提示且全部禁用。
失败：目录不存在 400 → notify 错误，本地列表保留待改。
```

## 4. 模块划分（落在现有分层）

| 层 | 模块 | 职责 | 不进入 |
|----|------|------|--------|
| 算法 | `app/settings/application/watch_dirs.py`（新） | `normalize_watch_dirs` / `validate_watch_dirs`（纯函数） | 无 IO/DB |
| 功能 | `app/settings/application/service.py` | `load_watch_dirs` / `patch_watch` / `get_view` 接 `watch` | 不碰 watchdog |
| 基础设施 | `app/shared/utils/watch_manager.py`（新） | `WatchManager`：持有 FileEventHandler，`apply(dirs)` 停旧起新 | 无业务规则 |
| UI | `components/SettingsModal/index.vue` | 「监视」页签 | 不直接打库 |

依赖方向：UI → 功能(patch API) → 算法；功能 → WatchManager（基础设施）。

## 5. 功能拆分（组合式）

| 切片 | 提供 | 组合 |
|------|------|------|
| 算法 | normalize/validate（纯函数，可单测） | 被功能调用 |
| 功能 | patch_watch 用例（持久化 + 重配） | PATCH 端点 |
| UI | 页签展示/增删/提交 | SettingsModal（组合根） |

## 6. 契约

- `GET /settings`：`watch = { dirs: {"image": [...]}, envLocked }`（camelCase）
- `PATCH /settings/watch`：body `{ dirs: {...} }` → 完整 SettingsView；错误：目录不存在/未知类型 → 400，envLocked → 400

## 7. 已确认决策（2026-10-07）

1. env 优先且锁定 UI（沿用刮削凭证模式）
2. 保存后整体重启监视器
3. 目录不存在 400
4. 目录选择复用 `window.electron.selectDirectory()`
