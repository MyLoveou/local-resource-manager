## D2 · 后端校验 `BACKEND_TOKEN`

### 背景

主进程已为每次启动生成随机 token，经 `additionalArguments` 注入渲染进程，axios 拦截器也已带 `Authorization: Bearer <token>`（`infrastructure/http/client.ts`）。后端**完全不校验**，与需求「进程间 token 鉴权」不一致；且 `Settings.token` 字段名与 `BACKEND_TOKEN` 环境变量不对应，实际取不到值。

### IN

- 后端对**非豁免路径**校验请求头 `Authorization: Bearer <token>`；不通过返回 401，走统一信封。
- token 由环境变量 `BACKEND_TOKEN` 注入（修正现有字段名/前缀映射）。
- 豁免清单必须覆盖应用启动探针与 OpenAPI 文档。

### OUT

- 用户登录、多用户、角色权限。
- token 轮换 UI、证书 / HTTPS、把后端暴露到 127.0.0.1 之外。

### 验收（可测）

| # | 场景 | 期望 |
|---|------|------|
| A1 | 不带 `Authorization` 请求受保护路径 | 401，信封 `status=error` `code=401` |
| A2 | 带错误 token | 401 |
| A3 | 带正确 token | 200，业务体不变 |
| A4 | 请求豁免路径（`/health`、`/docs`、`/openapi.json`） | 200，无需 token |
| A5 | 在 Electron 应用内走一遍导入 → 网格 → 看图 → 播放 → 回收站 | 全部正常（不应因鉴权出现 401） |
| A6 | 现有后端测试 | 全部通过（或按新契约显式带上 token） |

## D4 · 后台重活不堵事件循环

### 背景

导入是后台 `asyncio.Task`，但其中**部分同步 IO 直接在事件循环上执行**，会让同一进程内的 `/health`、列表请求被拖住（单进程单事件循环）。

已排查的现状：

| 位置 | 现状 |
|------|------|
| `media_probe`（Pillow / ffprobe）、缩略图、封面抽帧/图标提取 | **已**走 `asyncio.to_thread` |
| `importers.collect`（枚举）、`copy_tree_filtered`、`FileOps` 复制 | **已**走 `asyncio.to_thread` |
| `ingest/placement.py::comic_pages()` | **未**；在事件循环上 `os.walk` |
| `ingest/placement.py::find_launch()` | **未**；在事件循环上 `os.walk` |

### IN

- 导入路径上剩余的同步 IO 全部移出事件循环，形成**显式清单**（而非零散补丁）。
- 一条可复现的验证手段：导入大目录期间并发打 `GET /library/health`，延迟不被拖住。

### OUT

- 把导入搬到独立进程 / 独立 worker 服务（属架构级，另立项）。
- 抓取、下载 worker 的并发模型重构（本刀只收口导入路径；如发现同类问题另记）。

### 验收（可测）

| # | 场景 | 期望 |
|---|------|------|
| B1 | 导入一个含大量图片的漫画目录 | 导入期间 `GET /library/health` 的 p95 < 200ms（对比修改前记录基线） |
| B2 | 导入游戏目录（`find_launch` 走整棵树） | 同上 |
| B3 | 各导入分支回归 | 现有后端测试全绿；`comic` / `game` / `series` / 单文件四类都能入库 |
