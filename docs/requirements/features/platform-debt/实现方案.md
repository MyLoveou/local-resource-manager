## 1. 主路径与错误路径

```text
渲染进程 axios（带 Bearer）
  → log_requests
  → require_token：token 为空？命中豁免？Bearer 匹配？
      ├─ 通过 ─► wrap_json_envelope ─► 路由 ─► 信封
      └─ 不通过 ─► 401 error_envelope（已是信封，wrap 原样放行）

<img>/<video>/model-viewer（无请求头）
  → 命中 AUTH_EXEMPT_SUFFIXES("/content") 或 AUTH_EXEMPT_PATHS
  → 直接放行
```
