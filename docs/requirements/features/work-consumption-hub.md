## 1. 背景与动机

原 [local-resource-manager](local-resource-manager.md) 聚焦本地媒体资源的 **入库、元数据、检索、播放**。实际使用中，用户还需要：

1. **消费**：添加资源后不仅是「看见」，还要能 **按类型正确使用**（看视频、看模型、打开工程目录）。
2. **工作上下文**：项目文件夹不只是文件集合，需要 **待办、备注** 等辅助信息来推进工作。
3. **统一入口**：从「我有什么文件」转为「我在做什么、需要什么资源、怎么打开」。

## 2. 目标用户

- 在本地维护多种资源（媒体、工程目录、模型权重等）的创作者/开发者
- 需要围绕 **具体项目/任务** 组织资源，而非仅按类型浏览的用户
- 希望 **一键打开** 到合适工具（IDE、Blender、系统播放器等）的用户

## 3. 核心概念

### 3.1 消费渠道（Consumption Channel）

每种资源类型除入库与元数据外，必须定义 **如何被使用**：

```
资源 → 消费渠道 → 具体动作
         ├── 内嵌消费（应用内完成）
         ├── 外部唤起（系统/第三方应用）
         └── 工作区视图（工作目录专属）
```

- 每种类型有 **默认消费渠道**，用户可在设置中覆盖
- 单个资源可 **单独覆盖** 全局默认（如某工作目录指定用 Cursor 打开）
- 消费动作入口：**双击**、**右键菜单**、**详情/工作区面板按钮**

### 3.2 工作目录（Work Directory）

**工作目录** = 本地文件夹作为资源入库，消费方式为 **工作区视图** + **外部打开**。

绑定在工作目录上的辅助内容（目录级，非全局）：

| 辅助项 | MVP | 说明 |
|--------|-----|------|
| 待办（Todo） | P0 | 下一步任务，可勾选完成 |
| 备注（Note） | P0 | 进度、决策、备忘 |
| 快捷链接 | P1 | 外部 URL、文档链接 |
| 关联资源 | P1 | 关联库内其他资源（图片/视频/模型） |
| 工作状态 | P1 | 进行中 / 暂停 / 完成 |
| 活动记录 | P2 | 最近打开、目录变更摘要 |

### 3.3 扩展资源类型（以模型为例）

**模型** 作为可扩展类型的代表：入库后可 **查看元数据 + 外部打开**，内嵌查看器不在 MVP 范围。

后续可扩展：文档、音频等，均通过 **消费渠道注册机制** 接入。

## 4. IN SCOPE

- M7：消费渠道框架（类型默认行为、内嵌/外部/自定义命令）
- M8：工作目录（入库、工作区 UI、待办/备注 CRUD、外部打开）
- M9（P1）：模型等扩展类型占位 + 消费入口
- M10（P1）：首页工作向概览（进行中工作、最近消费）
- 设置页扩展：**消费渠道配置** 页签
- 左侧菜单：新增 **工作目录**、**模型（占位）**

## 5. OUT OF SCOPE

- 完整项目管理（甘特图、里程碑、多人协作）
- 工作目录内文件的在线编辑（备注是辅助文本，非 IDE）
- 模型/3D 内嵌查看器（MVP 仅外部打开）
- 待办/备注与 Obsidian、Notion 等双向同步
- 多物理路径绑定同一工作目录（MVP 严格 1 目录 = 1 资源）
- 常驻文件系统监视

## 6. 与 LRM 的衔接

| LRM 已有 | 本 Feature 扩展 |
|----------|-----------------|
| `ResourceType`: image, video | 新增 `work_directory`；预留 `model` |
| 双击：图片预览 / 视频播放 | 按类型路由到消费渠道 |
| 设置：播放器默认方式 | 扩展为按类型的消费渠道配置 |
| 首页概览：按类型统计 | 增加进行中工作、最近消费（M10） |
| 三栏布局 | 工作目录复用三栏，右侧改为工作区面板 |

## 7. 开放问题（须用户回答）

1. **「模型」具体指什么？** AI 权重（Safetensors/CKPT）、3D 模型（GLB/OBJ），还是泛指所有可扩展类型？影响扫描规则与元数据字段。
2. **待办/备注是否需要导出？** 仅应用内存储，还是支持导出 Markdown / 同步到外部笔记？
3. **产品对外名称** 是否从「资源管理器」调整为更偏工作的名称？（不影响技术实现，影响文案）
4. **实施顺序**：M7（消费渠道框架）与 M8（工作目录）是否并行，还是先做 M8 再抽象 M7？

## 8. 非功能要求

- 外部打开命令执行需 **安全校验**（禁止任意 shell 注入；路径参数转义）
- 工作区待办/备注 CRUD 响应 ≤ 200ms（本地 SQLite）
- 消费渠道配置修改 **即时生效**，无需重启（自定义命令除外需说明）
- 工作目录丢失（路径不存在）时标记为 `lost`，与 LRM 文件丢失策略一致

## 9. 建议实施阶段

```
Phase A（P0）
  M7 消费渠道框架
  M8 工作目录（待办 + 备注 + 外部打开）

Phase B（P1）
  M10 首页工作概览
  M8 扩展：快捷链接、关联资源、工作状态
  M9 模型类型占位 + 消费入口

Phase C（P2）
  M9 各类型专属内嵌消费 UI（如模型预览）
  活动记录、跨类型工作流
```
