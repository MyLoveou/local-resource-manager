# 回收站与批量删除/恢复 · 需求

> 状态：**已定稿**（2026-09-12 · 用户确认可以按此实现）  
> Feature ID：`library-trash`  
> OpenSpec：`openspec/changes/library-trash/`  
> 所属：[local-resource-manager](../local-resource-manager.md) M2 · T-2.8 / T-2.9  
> 上游：面板已能单条确认后软删；领域模型已有 `restore()`；**无回收站页、无恢复 API、无多选**

## 1. 问题

用户只能从信息栏把一条资源软删进 `trashed`，之后没有入口看见、恢复或彻底删掉。网格不能多选，无法一次收拾一批。删除后列表有时与库不一致（已知债）。

库内文件是导入**副本**，回收站必须能：软删可见、恢复回图片/视频页、彻底删除时清掉库内包，且不碰用户原来的源文件。

## 2. 本轮做 / 不做

| 做 | 不做 |
|----|------|
| 左侧「回收站」路由 `/trash`，列表 `status=trashed` | 定时自动清空；lost 重定位（T-2.10） |
| 单条/批量：移入回收站、恢复、彻底删除 | 完整右键菜单（T-2.7 后置） |
| 网格进入「批量删除/选择」模式后再点选卡片；该模式下才出现移入/恢复/彻底删除 | 批量打标 / 批量抓取；平时 Ctrl/Shift 多选 |
| 彻底删除：DROP 行 + 删除**库内资源包** | 删除用户导入源路径上的原文件 |
| 删除/恢复/彻底删后当前网格立刻与库一致 | 全局 Notify 系统（仍用现有确认框） |
| 清空回收站（确认后 purge 当前站内全部，可分页连续） | 只删库记录、把包留在磁盘上变成孤儿 |

## 3. 用户故事

- **US-T.1** 图片页选一张 → 确认 → 进回收站；该页卡片消失；打开回收站能看到。  
- **US-T.2** 回收站选一条 → 恢复 → 回到对应类型页；回收站不再列出。  
- **US-T.3** 回收站彻底删除（确认）→ 列表与库都没有；磁盘 `{library}/{type}/{id}/` 没了；用户电脑上当初选的源文件还在。  
- **US-T.4** 点「批量删除」进入选择模式 → 点卡片勾选 → 点「移入回收站」（确认一次）。未进模式时单击只打开信息栏。  
- **US-T.5** 回收站点「批量选择」→ 勾选后批量恢复或批量彻底删除。  
- **US-T.6** 清空回收站（确认）→ 站内条目与对应库内包都清除。  
- **US-T.7** 已在回收站的条目再点「移入」不报错、不重复造时间戳乱跳（幂等）。

## 4. 验收

- [ ] 左侧有「回收站」；`GET /library/resources?status=trashed` 分页网格；信息栏可看删除时间。  
- [ ] 类型页列表只出现 `active`（与现在一致）。  
- [ ] 移入 / 恢复 / 彻底删：单条与批量都要确认框；取消不改库。  
- [ ] 移入后类型页无该卡；恢复后类型页有、回收站无。  
- [ ] 彻底删除后 DB 无该 `resources` 行（CASCADE files/todos/tags）；包目录不存在。  
- [ ] 批量部分失败：返回成功/失败 id；已成功的仍生效；界面提示失败条数。  
- [ ] 清空回收站与逐条彻底删除效果相同。  
- [ ] 多选：须先进入批量模式；模式内单击切换选中；「移入回收站」仅在该模式出现；取消退出模式且不改库。  
- [ ] 不修改用户导入源文件。

## 5. 契约草案

已有：`DELETE /library/resources/{id}` = 软删。

新增：

| 方法 | 路径 | 含义 |
|------|------|------|
| POST | `/library/resources/{id}/restore` | 仅 `trashed` → `active`，清 `deletedAt` |
| POST | `/library/resources/{id}/purge` | 彻底删除：删包 + DROP 行 |
| POST | `/library/resources/batch` | body：`{ action: trash\|restore\|purge, ids: number[] }` |

- `ids` 去重、上限 200。  
- 批量响应：`{ ok: number[], failed: { id: number, message: string }[] }`。  
- 对已是目标态的 trash/restore：计入 `ok`（幂等）。  
- 单条 restore 非 trashed → HTTP 409；批量则该 id 进 `failed`。  
- purge 找不到 → `failed`。  
- 列表仍用现有分页 + `status=trashed`；`type` 可空（回收站混排图+视频）。

禁止：渲染进程删盘；GET 任意路径；`/v1`。

## 6. 假设（未另拍板则按此实现）

1. 彻底删除**总是**删库内包，不提供「只删记录」。  
2. 回收站**混排**所有类型，不按图/视频拆页。  
3. 本轮不做卡片右键菜单。批量须先点「批量删除/选择」进入模式，再点「移入回收站」等操作；平时单击只选中看面板。  
4. 无自动过期清空。  
5. 确认文案区分「可恢复」与「不可恢复」。
