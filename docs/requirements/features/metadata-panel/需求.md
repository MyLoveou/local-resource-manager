# 元数据面板 · 需求

> 状态：**已定稿**（2026-09-12 用户确认可按此实现）  
> Feature ID：`metadata-panel`  
> OpenSpec：`openspec/changes/metadata-panel/`  
> 上游：L1 M2；词表治理（管理页、统计、删词条）见 [tag-category-hygiene](../tag-category-hygiene.md)（**本切片不做**）

## 1. 问题

右侧信息栏已能拉详情并软删，但几乎只显示标题/类型/只读评分。用户要把通用元数据看全、改得动；评分/分类/标签不必先开弹窗，但**点保存才写库**。

## 2. 已按口令收口

1. 展示：封面、标题、大小、评分（5 星）、标签、分类、创建时间；type 与分类分开展示。  
2. 操作：编辑、删除、保存；**更换封面仅视频**（图片主文件即封面）。弹窗对视频同样可换封面。  
3. 「编辑」打开弹窗；弹窗内可改标题、简介、评分、分类、标签、封面。  
4. 评分、分类、标签在**面板上即可改草稿**，不必开弹窗。  
5. 标签：Enter 切词进本地列表，**禁止**每次 Enter 写库。  
6. **点「保存」才提交**评分/分类/标签（及弹窗里的标题/简介）；面板保存与弹窗保存都是这一语义。  
7. 分类、标签均为**独立词表**（表内词条）；保存时不存在的名字就新建词条。  
8. 删除：确认框后再软删。  
9. 词条治理（统计、删词、合并、管理页）不在本切片，沿用已有 `tag-category-hygiene`。

## 3. 本轮做 / 不做

| 做 | 不做 |
|----|------|
| 右侧通用字段展示 | 抓取回填、按标签过滤、搜索 |
| `categories` 表 + 资源单选一类；`tags` 多对多（表已有） | 词表管理页、引用统计、删词条、合并 |
| 保存时按名字找或建分类/标签 | 每次 Enter / 改星 / 改分类就 PATCH |
| 面板 + 弹窗换封面；弹窗取消则封面草稿不落地 | 视频抽帧封面；从其它资源挑封面 |
| 删除确认框 + 软删 + 网格同步 | 彻底删磁盘、回收站 UI |
| GET 词表列表供下拉（可新建） | 导入管道、新类型 |

## 4. 用户故事

- **US-M.1** 点选 → 右侧看到封面、标题、大小、5 星评分、标签、分类、创建时间。  
- **US-M.2** 面板改星/分类/标签（Enter 切词）→ **未点保存**则刷新或重选后仍是旧值。  
- **US-M.3** 面板点「保存」→ 一次写入当前草稿（评分、分类、完整 tagNames）。  
- **US-M.4** 编辑弹窗改标题/简介/评分/分类/标签/封面 → 保存落地；取消全部不写（含未保存封面）。  
- **US-M.5** 视频：面板点「更换封面」并选图 → 封面更新。图片无此按钮，网格封面即主图。  
- **US-M.6** 删除 → 确认框 → 软删，卡从网格消失，面板空态。  
- **US-M.7** 保存时分类或标签输入了库里没有的名字 → 新建词条并挂到该资源。

## 5. 验收

- [ ] 空态/字段/封面 URL/大小/创建时间/分类≠type：同前。  
- [ ] 评分控件为 5 星（允许半星），写入值为星数 × 2（0–10）。  
- [ ] Enter 切词不发 HTTP；空 Enter 不加芯片。  
- [ ] 面板改星/分类/标签后**不自动**写库；点面板「保存」一次 PATCH（无变化可跳过）。  
- [ ] 弹窗「保存」一次提交弹窗草稿；「取消」不改库、不换封面。  
- [ ] 分类为词表单选（可空）；可从已有项选或输入新名，保存时创建 `categories` 行。  
- [ ] 标签可多枚；新名字保存时创建 `tags` 行。  
- [ ] 图片不出现「更换封面」；视频面板与弹窗有该按钮。弹窗内选图未保存则库内封面不变。  
- [ ] 删除弹出确认；取消不删；确认后软删且网格一致。  
- [ ] 无标签/分类管理入口（不假装 hygiene 已做）。

## 6. 契约草案

- `GET /library/resources/{id}`：`tags[]`、`category: { id, name } | null`、`files[]`（至少 primary 的 size 等）  
- `GET /library/categories`：`{ items: { id, name }[] }`（供下拉）  
- `GET /library/tags`：`{ items: { id, name }[] }`（供建议；可空）  
- `PATCH /library/resources/{id}`：  
  - `title` / `description` / `rating`（0–10）  
  - `categoryName: string | null`（null 清空；非空则按名查找或创建分类再设 FK）  
  - `tagNames: string[]`（出现则整表替换；新名创建标签）  
- `POST /library/resources/{id}/cover`：`{ path }` → `put_cover`（面板换封面直接调；弹窗换封面等保存时再调）  
- `DELETE` 仍软删  

禁止：渲染进程写库目录；词表管理 CRUD 本切片不上（只随资源保存创建词条）。
