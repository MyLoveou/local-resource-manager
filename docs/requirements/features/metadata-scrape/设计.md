# 设计 · metadata-scrape（L2）

> 状态：**已落地**（D-20260919-10；实现：`实现方案.md`）  
> 施工图：`实现方案.md`。禁止编码直至「可以按此实现」。

## 0. 复杂度

跨 `/scrape` job、library 回填、导入后入队、批量确认、TMDB/Bangumi、封面锁定。不可跳过 L2。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 发现与回填分离 | search 只写 job+candidates | search 结束改 title |
| 人确认才是写库 | select 才覆盖标题简介、写封面 | 定时/导入自动 apply |
| 类型绑定源 | video=TMDB；anime=**Bangumi 主源 + 蜜柑附加** | 渠道唯一；蜜柑当下载引擎 |
| 凭证缺失即失败 | 无 TMDB key 则视频 job failed 明文 | 静默空列表装成功 |
| 导入不阻塞 | 复制成功后再入队 search | 刮削失败回滚入库 |
| 封面锁定 | apply 走现有 honor_user_lock | 刮削强行 POST cover |

## 2. 模型

沿用表：`scrape_jobs`、`candidates`、`adapters`（或 settings KV 存 token）。

Job 增加语义（extra 或列，L3 定）：`phase=search|apply`。search-only 在 `done` 且 `match_count>0` 且无 `selected` 候选 = **待确认**。

回填（select 之后 `fetchDetail` + apply）：

- `title`、`synopsis`：**覆盖**；`description`（我的评价）不改；站点字段进 `catalog`  
- 标签：按名 upsert，**只加不删**  
- 封面：非 `coverOrigin=user` 则下载进包 + thumbnail  
- `last_scraped_at`、`scraped_source`（`tmdb:<id>` / `bangumi:<id>`）

查询词：当前 `resource.title`（导入时多为文件/文件夹名）。

并发：进程内队列 + 每源 Semaphore；导入批量触发时排队，不打爆 API。

## 3. 交互

### 单条

信息栏「获取元数据」（仅 video/anime）。进行中禁用。完成弹候选列表；空则 Toast/文案原因。选一条确认 → 关弹层、bump 列表。

### 导入预搜（US-S.6）

ingest 成功且 type∈{video,anime}：enqueue search，**不等待**。  
网格：该 id 最新 search job 待确认 → 角标「候选」。点卡片仍先选中；信息栏可「查看候选」无需再搜（已有 job 则展示，可「重新搜索」）。

### 批量（US-S.5）

批量模式增加「获取元数据」：过滤出 video/anime，其余计入跳过。  
对每人队 search（已有待确认 job 可跳过 search 直接进入确认队列）。  
确认队列：一次一条候选 UI，按钮确认 / 跳过 / 全部跳过剩余。不阻塞网格滚动（job 在后端跑）。

### 空态 / 失败

- 无 key：job.failed「未配置 TMDB API Key」等。  
- 0 候选：done + match_count=0，无角标。  
- apply 时详情失败：不改标题，error 可读，候选仍在可重试。

## 4. 模块划分

| 模块 | 边界 | 不进入 |
|------|------|--------|
| SearchProvider | 输入 query+type → Candidate 列表 | 写 Resource |
| TmdbProvider / BangumiProvider | 直连官方 API | SearXNG |
| SiteProvider/detail | id → 标题简介标签封面 URL | 登录 Cookie |
| ScrapeJobService | 状态机、入队、select→apply | UI |
| library apply | PATCH 字段 + 封面附件 | 自己 httpx 站点 |
| 导入钩子 | 成功后 enqueue | 等 job |
| InfoPanel / 批量条 / 角标 | 触发与确认 | 解析 API JSON |

依赖：UI → scrape REST → job → provider →（select）library。禁止渲染进程直连 TMDB。

## 5. 切片顺序（仍一刀交付）

1. Provider + job search API + 单测不写库  
2. select apply + 封面锁  
3. 信息栏单条  
4. 导入 enqueue + 角标  
5. 批量确认队列  

## 6. 风险

| 风险 | 缓解 |
|------|------|
| 导入 80 部打爆 TMDB | 队列+限速；key 缺失整批快速 fail |
| 文件名搜不准 | 候选让人挑；不自动 apply |
| 番剧用了视频导入 | 本刀按 **库内 type** 选源，不猜 |
| 角标与 bump | job 结束 bump 或列表字段 `scrapePending` L3 定 |

## 7. 明确不做

SearXNG、AV/图、登录、远程爬虫、确认前改标题。
