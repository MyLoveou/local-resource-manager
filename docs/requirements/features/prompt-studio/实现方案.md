# 提示词工作台（Prompt Studio）· 实现方案

> 路线：**B 一次原生化**（2026-11-10 用户拍板）。不只管理，还要能"用"：选标签、套预设、反向、体检、出图参数。
> 数据来源：`PromptForge-交接包`，已抽取为 JSON（见 §2）。

## 1. 与原工具的差异

| 维度 | PromptForge | 本项目 |
|---|---|---|
| 存储 | localStorage | SQLite（内置库为 JSON，用户数据入库） |
| 使用 | 单页 HTML | 原生页面，与角色/作品联动 |
| 出图 | 页面直连或代理 | 后端代理，无 CORS/403 |
| 备份 | 手工导出 | 跟随现有备份与修订 |

## 2. 内置数据（已抽取，`apps/backend/app/prompts/data/`）

| 文件 | 内容 | 规模 |
|---|---|---|
| `tags.json` | 25 个分类，`tags` 为 `en\|zh` 行文本 | 2976 个标签 |
| `characters.json` | 角色（game/name/tag/charZh/auto 外观标签） | 1401 |
| `presets.json` | 预设（name/desc/tags） | 299 |
| `tpls.json` | 模板（含 MOSS layout） | 12 |
| `models.json` | Anima / MOSS 前缀、负面、推荐参数 | 2 |
| `pinyin.json` | 汉字→拼音字典 | 2087 |
| `extra_zh.json` / `zh_synonym.json` | 中文补充与同义词表 | — |
| `rules.json` | 反向规则与冲突表（NEG_*、CONFLICTS） | 30 对规则 + 71 条额外词 |

> 内置库只读、随版本升级替换；用户自建内容入 DB，升级不覆盖。

## 3. 数据模型（迁移 0038）

```sql
prompt_saves(id, title, model, positive, negative, params_json, note,
             categories_json, favorite, created_at, updated_at, resource_id?)
prompt_save_tags(save_id, tag)                      -- 按标签筛选
prompt_custom_tags(id, en, zh, category, created_at)
prompt_custom_presets(id, name, category, tags_text, created_at)
prompt_history(id, save_id?, model, positive, negative, pinned, created_at)
prompt_settings(key, value)                          -- 默认模型、前缀开关、ComfyUI 地址
prompt_gallery(id, save_id?, file_id, params_json, created_at)   -- P3
```

## 4. 后端（`app/prompts/`）

```
api/router.py       GET  /prompts/library        内置库（tags/chars/presets/tpls/models/rules）
                    GET  /prompts/saves          列表（q / tag / favorite）
                    POST /prompts/saves          新建
                    PATCH/DELETE /prompts/saves/{id}
                    POST /prompts/saves/{id}/copy 复制为新存档
                    GET/POST /prompts/custom/tags
                    GET/POST /prompts/custom/presets
                    GET/POST /prompts/history
                    GET/PUT  /prompts/settings
                    GET  /prompts/export         导出（兼容 PromptForge 结构）
                    POST /prompts/import         导入（兼容其导出 JSON）
application/library.py   读取内置 JSON、拼装索引（分类/标签/角色）
application/algorithms.py 反向生成 negFromPositive、体检 lintPrompt（移植自原工具）
infrastructure/repo.py   SQLite 读写
```

## 5. 前端（`views/Prompts/`）

```
┌ 顶栏：模型 Anima / MOSS  ·  搜索  ·  导出/导入  ·  设置
├ 左栏：分类导航（25 类）+ ★收藏 + 🕘最近
├ 中栏：标签网格 / 角色卡 / 预设卡 / 模板卡
└ 右栏：输出（正向/负面）· 权重与排序 · 保存为存档 · 复制
        📜历史  🩺体检  ↩反向  🎨出图(P3)
```

关键状态（`usePromptStudio`）：

- `selected: {en, zh, weight}[]`、`negative`、`model`、`locked`
- 派生：`positive`（按模型拼前缀）、`negativeAuto`
- 操作：加/删/加权/排序、套用预设/模板/角色、随机组合、反向、体检

搜索：中/英/全拼/首字母，用抽取的 `pinyin.json` 建首字母索引（与 PromptForge 一致）。

## 6. 算法移植

| 算法 | 来源 | 要点 |
|---|---|---|
| `negFromPositive` | 原工具 | 按选中标签的分类取 `NEG_BY_CAT`、合并 `NEG_CORE/EXTRA/QUALITY/LIGHT/TEXT`、去重、剔除与正向冲突项、NSFW 时去掉压制词 |
| 体检 | 原工具 | 8 项：缺主语、缺质量词、正负重复、冲突对、标签过多/过少、未闭合括号、空负面 |
| 冲突表 | `CONFLICTS` | 选中即提示，可一键移除其一 |

## 7. 分期

| 期 | 内容 | 验收 |
|---|---|---|
| P0 | 迁移 0038 + `/prompts/library` + 存档 CRUD + 测试 | 接口可存/查/改/删；内置库一次返回 |
| P1 | 页面骨架：模型切换、标签选择、输出栏、保存/复制 | 能拼出 Anima 提示词并保存 |
| P2 | 预设/模板/角色套用、反向、体检、历史 | 不需要原 HTML 也能完成日常出词 |
| P3 | ComfyUI 后端代理 + 画廊 | 应用内出图并回看 |

## 8. 风险

- 内置库 535 KB JSON：`/prompts/library` 首次加载较大，需前端缓存 + 可按需分片
- NSFW 分类：默认折叠，设置里开启
- 原工具有 1401 角色、2976 标签，前端渲染需虚拟滚动
- ComfyUI 参数因模型而异，P3 再接
