# 每集封面与字幕 · 实现方案

> 对应需求：同目录 `需求.md`（IN 1–8）
> 迁移：`0033_episode_cover_subtitles.sql`

## 1. 数据模型

```sql
-- 0033
ALTER TABLE episodes ADD COLUMN cover_file_id INTEGER REFERENCES files(id);

CREATE TABLE subtitle_tracks (
  id          INTEGER PRIMARY KEY,
  resource_id INTEGER NOT NULL REFERENCES resources(id) ON DELETE CASCADE,
  file_id     INTEGER NOT NULL REFERENCES files(id)      ON DELETE CASCADE,
  episode_id  INTEGER          REFERENCES episodes(id)   ON DELETE CASCADE,
  language    TEXT,
  title       TEXT,
  is_default  INTEGER NOT NULL DEFAULT 0,
  sort_index  INTEGER NOT NULL DEFAULT 0,
  created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE UNIQUE INDEX ux_subtitle_tracks_file_episode
  ON subtitle_tracks(file_id, COALESCE(episode_id, 0));
CREATE INDEX ix_subtitle_tracks_episode ON subtitle_tracks(episode_id);
CREATE INDEX ix_subtitle_tracks_resource ON subtitle_tracks(resource_id);
```

要点：

- `episode_id` 为空表示**资源级字幕**（单文件视频走这条）。
- 唯一索引防重复挂载；`ON DELETE CASCADE` 保证删集/删资源不留孤儿（验收 A10）。
- 封面用 `cover_file_id` 指向 `files` 里 `role='episode_cover'` 的文件，不复制二进制列。

## 2. 字幕发现与匹配（导入期）

新增 `library/application/subtitles.py`：

```python
SUBTITLE_SUFFIXES = {".srt", ".vtt", ".ass", ".ssa"}

def discover(videos_dir: Path) -> list[Path]        # 含 Subs/ 字幕/ 子目录
def match(video: Path, candidates: list[Path]) -> Path | None
def infer_language(path: Path) -> str | None        # 简繁/CHS/JPN→语言码
```

匹配顺序（需求 IN 3）：

1. **集号相等**：视频与字幕都能解析出集号且相等 → 命中
2. **主干相似**：去掉括号段与集号后，`difflib.SequenceMatcher` 比值 ≥ 0.8 → 命中
3. 都不中 → 若该资源只有一个视频，挂资源级；否则不挂（宁缺勿错）

接入点：`import_service._ingest_series` 与 `_ingest_one` 落库后调用 `register_subtitles()`；失败只记日志，不中断导入。

## 3. 每集封面

新增 `library/application/episode_covers.py`：

```python
async def ensure_episode_cover(resource_id, episode_id, video_path, at_seconds=3.0) -> int | None
```

- 用 `ffmpeg -ss 3 -i <video> -frames:v 1 -vf scale=320:-1 -y <tmp>.jpg`
- 成功 → 复制进包内 `covers/ep-<NN>.jpg`，写 `files(role='episode_cover')`，回填 `episodes.cover_file_id`
- 找不到 ffmpeg / 执行失败 → 返回 None，UI 回退作品封面（验收 A8）
- 触发时机：导入收尾**异步**执行，避免拖慢导入；失败不影响导入结果

读取：

- 新增 `media_paths.episode_cover_url(resource_id, episode_id)`：有封面走该文件签名 URL，无则回退 `resource_thumb_url`
- `GET /library/resources/{id}/episodes` 返回体加 `coverUrl`、`hasSubtitles`

## 4. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/library/resources/{id}/subtitles` | 返回 `[{id, episodeId, fileName, language, title, renderable, url}]` |
| POST | `/library/resources/{id}/subtitles` | `{filePath, episodeId?}`：复制进库 + 建关联 |
| DELETE | `/library/subtitles/{trackId}` | 解除关联（文件保留，可在库里看到） |
| GET | `/library/episodes/{id}/cover` | 302/直出该集封面（签名 URL 由列表接口给出，此接口用于手动刷新） |
| PUT | `/library/episodes/{id}` | `{coverFromSeconds?}` 或 `{useResourceCover:true}` |

`renderable` 字段：`srt/vtt → true`，`ass/ssa → false`，前端据此显示「暂不支持渲染」（验收 A4）。

## 6. 数据流

```text
导入（series）
  → 复制视频 → 落 files/episodes
  → 扫描字幕 → register_subtitles() → subtitle_tracks
  → 异步 ensure_episode_cover() → files(role=episode_cover) → episodes.cover_file_id
播放
  → GET /resources/{id}/episodes → coverUrl + hasSubtitles
  → 点选集 → GET /resources/{id}/subtitles?episodeId= → tracks
  → <video> + <track src=signedUrl>（srt 前端转 vtt）
```

## 8. 未做 / 风险

- `.ass/.ssa` 渲染：明确不做，只在 UI 标注（避免"以为支持"）。
- ffmpeg 未随包分发：无 ffmpeg 的机器只有作品封面；后续若要保证，需评估体积或改用首帧缩略图的服务端方案。
- 字幕编码：GB18030 的 srt 需要转码，本次按 UTF-8 读取，异常时提示而不是乱码输出。
