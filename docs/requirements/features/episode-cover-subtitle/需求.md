# 每集封面与字幕 · 需求

> 状态：草案 → 待定稿（2026-10-29 起）
> 关联：`docs/requirements/by-type/anime.md`、`features/video-management/`

## 1. 背景

番剧与视频已经能导入、播放、续播，但两条信息链是断的：

1. **每集封面**：`episodes` 表只有 `id/season_id/file_id/episode_number/title/sort_index/status`，**没有封面列**。选集列表只能显示文字，用户无法从画面上找「那一集」。
2. **字幕**：字幕只是 `files` 里 `role='subtitle'` 的文件，**与集没有关联**；播放器用原生 `<video controls>`，**没有 `<track>`**，所以即便字幕文件在库里也放不出来。

视频侧同理：单文件视频的字幕同样无法被播放器使用。

## 2. 现状（代码证据）

| 事实 | 证据 |
|---|---|
| `episodes` 无封面列 | `pragma table_info(episodes)` → 7 列，无 cover |
| `extras` 无封面列 | `pragma table_info(extras)` → 6 列 |
| 播放器无字幕轨 | `VideoPlayer/index.vue` 仅匹配到 `autoplay`，无 `track`/`subtitle` |
| 已有 `files.role` | 包含 `subtitle` 角色，说明字幕入库但不参与播放 |
| ffmpeg 可用性 | 本机 PATH 有 ffmpeg 9.0；仓库只带 `ffprobe.exe` |

## 3. 范围

### IN

**字幕**

1. 导入时**自动发现**视频同目录（含 `Subs/`、`字幕/` 子目录）的字幕文件：`.srt` `.vtt` `.ass` `.ssa`。
2. 字幕文件入库为 `files(role='subtitle')`，并建立**与集/视频的关联**（新表 `subtitle_tracks`）。
3. 匹配规则：先按**集号**匹配同目录视频；无集号时按**文件名主干相似度**匹配；仍无法确定则挂到资源层级（视频直接用）。
4. 播放器支持**字幕选择与开关**：番剧选集播放、单文件视频播放都可用。
5. 支持**手动添加字幕**：为某一集或某个视频指定本地字幕文件（复制进库，不改原文件）。

**每集封面**

6. 为每一集生成**抽帧封面**（ffmpeg 存在时）；生成失败或没有 ffmpeg 时**回退到作品封面**，不报错。
7. 支持**手动替换**某集封面。
8. 选集列表与播放器标题处显示该集封面。

### OUT（本次不做）

- 字幕的**字体嵌入与样式覆盖**：ass 由 libass-wasm 渲染，使用内置字体，不做字体子集匹配与自定义字体包。
- 外挂字幕的**在线搜索/下载**。
- 字幕**编辑**、时间轴调整、样式设置。
- 内嵌字幕轨（mkv 内封）的提取与切换——那是容器内轨，与文件级字幕是两条路径。
- 系列独立详情页（另立 EPIC，本次只改信息栏与播放器）。

## 4. 交互要求

1. 选集卡片显示：集号、标题、封面缩略图、（有字幕时）字幕角标。
2. 播放器底部或控制区提供「字幕」选择：关闭 / 字幕列表（按语言与文件名标注）。
3. 没有字幕时不显示字幕入口（不要放一个点了没反应的按钮）。
4. 手动添加字幕的入口放在信息栏与播放器两处，行为一致。

## 5. 验收（每条可判定）

| # | 场景 | 判定 |
|---|---|---|
| A1 | 导入含 `Subs/xx.ass` 的番剧目录 | 该集在库中有 ≥1 条字幕关联；选集卡片出现字幕角标 |
| A2 | 播放有 `.srt` 的集 | 播放器可选到该字幕并正确显示中文 |
| A3 | 播放有 `.vtt` 的集 | 同上 |
| A4 | 播放只有 `.ass` 的集 | 由 libass 渲染出字幕；渲染失败时给出明确提示，**不静默失效** |
| A5 | 无字幕的集 | 播放器无字幕入口 |
| A6 | 单文件视频 + 同名字幕 | 视频播放器可选该字幕 |
| A7 | 导入后每集有封面 | 选集卡片显示可区分的缩略图（不同集不应是同一张） |
| A8 | 没有 ffmpeg 的机器 | 导入不失败；选集回退作品封面 |
| A9 | 手动替换某集封面 | 刷新后仍生效（持久化） |
| A10 | 删除一集 | 其字幕关联与封面引用被清理，不留孤儿行 |

## 6. 已确认决策

| 决策 | 结论 |
|---|---|
| 字幕与集的关联方式 | 新建 `subtitle_tracks`，`episode_id` 可空（空 = 资源级，供单文件视频用） |
| 抽帧依赖 | 有 ffmpeg 就抽帧，没有就回退作品封面；**不把 ffmpeg 打进安装包**（体积） |
| ass/ssa | 入库 + 用 **libass-wasm**（`@jellyfin/libass-wasm`）渲染，srt/vtt 走原生 `<track>` |
| 第三方依赖 | 引入 `@jellyfin/libass-wasm`（含 wasm + worker，约 2.7MB），随渲染进程打包 |
| 字幕语言字段 | 从文件名/目录名推断（`简繁`/`CHS`/`JPN` 等），推断不出留空 |
