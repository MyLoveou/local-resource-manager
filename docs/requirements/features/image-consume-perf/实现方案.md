# 图片消费性能 · 实现方案

> 状态：**评审中**（与 OpenSpec `design.md` 同一范围）  
> Feature ID：`image-consume-perf`

## 目标 / 不交付

与 [`需求.md`](./需求.md) 六条一致。不换 IPC 形状、不新表。

## 与现有架构的取舍

| 做法 | 为何 |
|------|------|
| 沿用包内 `thumbs/grid.webp` + `thumbnailPath` | 已有管线，面板不要再喂原图 |
| 词表与列表拆开请求 | 分类/标签不是首屏硬依赖 |
| 后端只改 hydrate 与 FileResponse 头 | JSON 契约不变 |
| 先调 Viewer 再考虑自绘 | D-17 |

## 模块边界

```
懒加载     Card loading=lazy；虚拟列表只挂可见格；content 仅 Overlay 打开后
缩略图     InfoPanel / EditResourceModal 预览 = thumbnailPath ?? coverPath
词表       getCategories/getTags 不进入列表首屏 await；不挡住 resource 赋值
缓存       前端：详情 Map、词表；HTTP 缓存头。bump 清空
后端       _hydrate 一次加载关联；FileResponse Cache-Control
前端手势   createInlineImageViewer + Host 防抖 resize
```

## 文件路径清单

| 路径 | 新建/改 | 职责 |
|------|---------|------|
| `Card/index.vue` | 核 | 已有 lazy；核对 decoding |
| `InfoPanel` / `EditResourceModal` | 改 | 预览只用缩略图；词表后台填 options |
| `http/resources.ts` | 改 | getResource 内存缓存；bump 失效 |
| `http/vocab.ts` | 改 | 分类/标签缓存（分类已有雏形）；bump/保存失效 |
| `library` store 或 http 订阅 revision | 改 | 失效详情与词表 |
| `ImageViewerOverlay` | 改 | 打开后再 content；±1 预取 |
| `createInlineImageViewer` + Host | 改 | rAF/防抖；少 update/initImage |
| `apps/backend/.../resources.py` | 改 | content/file FileResponse 缓存头 |
| `apps/backend/.../repositories.py` | 改 | `_hydrate` selectinload/一次查关联 |
| `package.json` | 或改 | 仅确认换库时卸 viewerjs |

**不改：** 打开规则、IPC 通道名、缩略图生成算法（除非发现详情未带 `thumbnailPath` 则补 hydrate）。

## 数据流

**列表首屏** `getResources` → 网格（lazy 图）→ 词表并行或延后，失败不影响格子。  
**点选** 有缓存则立刻画字段+缩略图；否则 GET 详情；词表已缓存则下拉立刻有项。  
**打开查看器** 才 GET content；邻居预取可 idle。  
**resize/拖拽** 只动封装。  
**写入** patch/导入/删除 → bump → 清详情缓存。

## 后端要点

- `get()` 今日：category `get` + tags join + files + todos 多次 await。改为一次（`selectinload` 或打包 query）。  
- `FileResponse`：缩略图角色长缓存；primary content 可用较短缓存或协商缓存。  
- 列表已批量贴 `thumbnail_path`，保持。

## 风险

| 风险 | 缓解 |
|------|------|
| 无缩略图旧资源 | 退回 coverPath，不挡本切片 |
| Viewer 拖拽无法外钩 | 停，问是否自绘 |
| 缓存脏读 | bump 与保存词条必失效 |
