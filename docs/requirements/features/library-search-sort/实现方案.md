## 1. 对齐与约束

- 只扩展现有 `GET /library/resources` + TypeBrowse/回收站/顶栏，**不**新建搜索服务或表（无 FTS 虚拟表）。
- 分层：API → `LibraryQueryService` → `ResourceRepository`；桌面 `domain/libraryTypes` 与后端 TypeProfile **同名键**；`browseQuery` store → `useResourcePage` → HTTP。
- 渲染进程不算 LIKE、不拉全库。
- 非法 `sort`：**422**（`HTTPException`），与 Pydantic 校验一致。
- `/search` **不进侧栏**（`meta.hideMenu`；`menuFromRoutes` 跳过）。
- 不改导入 / 打开 / 软删契约。
- 不分词、不上 FTS5。

## 2. 本设计锁定

| 项 | 锁定 |
|----|------|
| 匹配 | `LIKE '%' \|\| escaped \|\| '%'`，大小写不敏感：`LOWER(列) LIKE LOWER(pattern)`；`q` trim 后空则不加 haystack；最长 **200** 字 |
| LIKE 转义 | `\` `%` `_` 转义后再拼；`ESCAPE '\'` |
| 文件名 | `files.path` 整段 LIKE（覆盖 basename 与游戏绝对路径） |
| 体积 | `SUM(files.size)`，无文件则 NULL，排序 NULLS LAST |
| 分辨率排序 | `pixelArea = width*height`（取该作品文件中 max）；`resolution` 同 pixelArea |
| 时长/码率/宽高 | 该作品文件 `MAX(duration)` 等 |
| 拍摄时间 | `MAX(files.exif_taken_at)` |
| 页数 | `COUNT` `role=page` |
| 集数 | `COUNT(episodes)`，不含 extras |
| 清晰度关键词 | `q` 为纯数字且 ∈ {480,720,1080,1440,2160,4320} 时 OR `width=q OR height=q` |
| 标签 AND | 每个 `tagId` 一条 `EXISTS resource_tags` |
| 游标 | `afterKey`（排序列序列化）+ `afterId`；响应 `nextKey` + `nextId`。**废弃作为唯一游标的 `afterCreatedAt`**（`createdAt` 排序时 `afterKey` 即时间戳字符串）。过渡：仍接受 `afterCreatedAt` 仅当 `sort=createdAt`，内部当成 `afterKey` |
| 防抖 | 顶栏与本类搜索 **300ms**；Enter 立即 |
| persist | Pinia persist，key `browseQuery`，map `scopeKey → { q, sort, order, tagIds }` |
| 空 `/search` | 不请求全库；UI「输入关键词搜索全库」 |

## 3. 查询校验

`ResourceSortField` 扩为共用 ∪ 全部类型键（一个 Enum，JSON camelCase）。

`LibraryQueryService.list_page`：

1. 解析 `q`、`tag_ids`、`sort`、`order`
2. `allowed = SHARED_SORT | profile.sort_keys`；`type is None`（全库或回收站）时 **仅 SHARED_SORT**
3. `sort not in allowed` → 422 `"sort not allowed"`
4. `count` 与 `list` **同一套 where**（含 q/tags）

Haystack（`q` 非空，OR）：

- `LOWER(resources.title/author/description)`
- `categories.name`（LEFT JOIN）
- `tags.name`（EXISTS）
- `files.path`、`files.format`（EXISTS）
- 数字清晰度档（见上）

游戏无单独 format 键时 path LIKE 已覆盖源路径。

## 4. SQL / keyset（仓储）

列表用子查询或 labeled expr：

```text
sort_expr =
  createdAt     → resources.created_at
  updatedAt     → resources.updated_at
  title         → resources.title COLLATE NOCASE
  rating        → resources.rating
  size          → (SELECT SUM(size) FROM files WHERE resource_id = r.id)
  width/height/duration/bitrate/takenAt → (SELECT MAX(...) FROM files WHERE resource_id = r.id)
  pixelArea / resolution → (SELECT MAX(width*height) FROM files WHERE resource_id = r.id AND width/height NOT NULL)
  pageCount     → (SELECT COUNT(*) FROM files WHERE resource_id = r.id AND role = 'page')
  episodeCount  → (SELECT COUNT(*) FROM episodes WHERE resource_id = r.id)
```

`ORDER BY sort_expr IS NULL, sort_expr ASC|DESC, id ASC|DESC`（NULL 永远在后）。

Keyset（desc 例）：`(sort_expr IS NULL AND prev IS NULL AND id < afterId) OR (sort_expr < afterKey) OR (sort_expr = afterKey AND id < afterId)` —— L3 apply 时用与 SQLite NULL 比较一致的写法测黄金数据，避免漏行。

`afterKey` 一律字符串；数字/时间原样转 str。标题游标用原始 title。

`count()` 增加相同 filter 参数，**禁止**筛完列表却用未筛选 total。

## 5. API

`GET /library/resources` 增加：

| query | 说明 |
|-------|------|
| `q` | optional string |
| `tagIds` | 可重复 `tagIds=1&tagIds=2` |
| `sort` | 扩展 Enum，默认 `createdAt` |
| `order` | `asc` \| `desc`，默认 `desc` |
| `afterKey` | 与 `afterId` 成对 |
| `afterId` | 已有 |
| `afterCreatedAt` | 仅兼容 `sort=createdAt` |

`ResourcePage` 增加 `nextKey: str | null`（有下一页时）。保留 `nextCreatedAt`：当 sort=createdAt 时与 nextKey 相同，避免旧客户端立刻坏掉。

## 6. TypeProfile

后端 `TypeProfile` 增加：

```text
search_keys: frozenset[str]   # 额外 haystack，如 format、path
sort_keys: frozenset[str]     # 额外排序
```

共用键不写进档案，代码里 `SHARED_SEARCH` / `SHARED_SORT` 常量。

前端 `libraryTypes.ts` 同名字段。禁止页面 `if (type==='video')` 拼下拉。

| type | search_keys | sort_keys |
|------|-------------|-----------|
| image | format | width, height, pixelArea, takenAt |
| video | format | duration, resolution, bitrate |
| audio | format | duration |
| novel | ∅ | ∅ |
| game | path | ∅ |
| model | format | ∅ |
| comic | ∅ | pageCount |
| anime, av | ∅ | episodeCount |

`format` 不单独 query 参数，只进 haystack（EXISTS files.format LIKE）。

## 7. 桌面

### browseQuery store

`application/stores/browseQuery.ts`，persist。

```text
sessions: Record<scopeKey, { q, sort, order, tagIds }>
scopeKey(route) → type:image | scope:all | scope:trash
ensureSortAllowed(scope)  // 记住的时长在小说页则回退 createdAt
```

### useResourcePage

入参增加 `q/sort/order/tagIds`（ref）；变化则 reset 首页。游标用 `nextKey`/`afterKey`。

### UI

- `components/BrowseControls/index.vue`：本类/回收站/搜索页共用。关键词、排序 select、升降、`n-select` 多选标签（`getTags()`）。
- `ResourceBrowser`：顶部插 BrowseControls；`emptyHint` 在有 q 或 tagIds 时改为「无匹配」。
- `ToolBar`：导入右侧输入框 placeholder「全库搜索」；debounce 后 `router.push({ path:'/search', query:{ q } })`；空串且当前在 `/search` 则 `router.back()` 或去 `/`。
- `views/Search/index.vue`：`q` 空只展示提示；否则 `<ResourceBrowser :empty-hint="无匹配" />` 不传 type，status=active。
- `route.ts`：`/search`，`meta.hideMenu: true`。
- `menuFromRoutes`：跳过 `hideMenu`。

类型页关键词改的是 `type:xx` 会话，**不**跳转 `/search`。顶栏只写 `scope:all` 并跳转。
