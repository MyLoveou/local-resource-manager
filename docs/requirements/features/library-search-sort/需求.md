# 库内搜索与排序 · 需求

> 状态：**已编码，待手验**（D-20260919-01；施工图 `实现方案.md`）  
> OpenSpec：`openspec/changes/library-search-sort/`

## 1. 背景

类型网格已能按 type 分页浏览，但用户无法在库内找资源、也无法换排序。现状：

- `GET /library/resources` 有 `sort`（枚举仅 `createdAt`）与 `order`；仓储 keyset 写死 `created_at + id`
- 前端 `useResourcePage` 固定 `createdAt desc`
- 无 `q` / 标签筛选；TypeProfile 无搜排目录

本切片把 M4 检索提前为独立能力，**不含**词表治理、以图搜图、正文全文。

## 2. 要解决的问题

| 用户感知 | 现状 |
|----------|------|
| 标题/作者/标签/文件名找不到 | 只能滚网格 |
| 要按名称、评分、体积排 | 永远最新在前 |
| 视频时长、图片分辨率 | 无类型键 |
| 有时要跨类型搜，有时要在本类筛标签 | 没有查询会话 |

## 3. 范围

### IN

- **共用搜索字段**：标题、作者、描述、分类名、标签名、**文件名**（`files.path` 的文件名部分）
- **顶栏跨类型搜索**：与类型页同一套字段语义；结果为作品卡混合列表
- **共用排序**：创建时间、更新时间、标题、评分、体积；默认创建时间降序
- **分类型键（本刀表内全部）**：见 §4；女优/字幕组 OUT；表外键后续再补
- **标签**：独立多选筛选 **且** 关键词可命中标签名
- **按类型记住** 排序与筛选（localStorage）
- **LIKE** 子串匹配（本刀不做 FTS5；FTS5 记在仓库根 `todo.md`）
- 目录化搜排键；仍虚拟网格；换条件重拉第一页；无匹配空态

### OUT

- 词表治理、以图搜图、刮削
- 小说/漫画正文、歌词、游戏整树内容 FTS
- 智能合集 / 保存复杂筛选器
- 改导入、打开、软删
- 中文分词引擎、独立搜索服务

## 4. 模型（需求级）

命中单位仍是作品 Resource。番剧/AV 不按集拆卡。

| 类型 | 额外搜索（本刀） | 额外排序（本刀） |
|------|------------------|------------------|
| 图片 | 格式 | 宽、高、像素面积、拍摄时间 |
| 视频 | 格式；清晰度按分辨率档（数字如 1080） | 时长、分辨率、码率 |
| 音频 | 格式 | 时长 |
| 小说 | （作者已共用） | — |
| 游戏 | 源路径 / 启动文件名 | — |
| 模型 | 格式 | — |
| 漫画 | — | 页数（`files` 页角色计数，算得出才排） |
| 番剧/AV | — | 集数（episodes 计数） |
