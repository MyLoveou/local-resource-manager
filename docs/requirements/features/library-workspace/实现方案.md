## 1. 架构决策

| 决策 | 结论 | 理由 |
|------|------|------|
| 分类存储 | `categories.type + parent_id` + `resource_categories` 多对多 | 每类型独立树、资源多分类 |
| 旧分类列 | 迁移后停止读写，保留一版回滚；下一版删除 | 避免同版重建 resources 的高风险 |
| 分类筛选 | API 收 `categoryIds[]`，内部递归展开后代；单值 `categoryId` 兼容 | 资源库单节点、时间线多分类共用 |
| 时间线 | `saved_views` 保存筛选 JSON；无成员表 | 资源只存一份，规则实时匹配 |
| 路由 | 规范路由 `/library/:type`；旧类型路由与 `/photos` 重定向 | 菜单/视图上下文稳定 |
| 首页 | `GET /library/home` 聚合；合集预览一次批量查询 | 避免首页 N+1 与多入口 |
| 快捷键 | 复用 `selection.selectRange`；Shift 替换 | 现有 store 已有范围能力 |
| 组合根 | `views/LibraryWorkspace` 组装 tabs/tree/views/filters | UI/功能/算法不互相穿透 |

## 2. 数据与迁移

### 2.1 新表/字段

- `categories`：新增 `type`、`parent_id`、`sort`、`is_system`；移除全局 name 唯一，改为 `(type,parent_id,name)` 唯一（根节点用部分唯一索引）。
- `resource_categories(resource_id, category_id, PRIMARY KEY(...))`。
- `saved_views(id, kind, type, name, filters_json, sort, created_at, updated_at)`；`UNIQUE(kind,type,name)`。
- `resources.category_id` 保留但标记 deprecated；代码不再读写。

### 2.2 迁移步骤（0018/0019）

**0018_category_tree.sql**

1. `PRAGMA foreign_keys=OFF`。
2. 重建 `categories`：新列 + 无全局唯一；旧行按资源实际使用类型复制。
   - 每个旧分类至少保留一条；多类型共用 → 每类型一条。
   - 无资源使用的旧分类 → 图片树 `待整理分类` 系统根下。
3. 建 `resource_categories`；按 `(resources.category_id, resources.type)` 回填。
4. 建索引：`categories(type,parent_id)`、`resource_categories(category_id,resource_id)`；唯一索引覆盖根/非根。
5. `PRAGMA foreign_key_check`；`PRAGMA foreign_keys=ON`。
6. 保留 `resources.category_id` 与本迁移的映射临时表清理。

**0019_saved_views.sql**

1. 建 `saved_views` 与唯一索引。
2. 不迁移旧时间线（旧时间线是全局视图，不产生保存项）。

**对账（迁移测试必须断言）**

- 资源数不变；每个旧 `category_id` 都有对应新关系；合集成员数不变。
- 图片/视频分类树各自节点数符合旧分类使用情况。
- 无资源旧分类进入 `待整理分类`；库内文件路径未变。

### 2.3 查询算法

- `CategoryRepository.descendant_ids(ids)`：递归 CTE 展开；`list`/`timeline_photos` 用 `EXISTS` 或 join。
- 分类树计数：一次递归 CTE 得到 `(ancestor, descendant)`，对 `resource_categories` 去重计数。
- `categoryIds` 多值按 OR；单值兼容。
- `uncategorized=true` 用 `NOT EXISTS (resource_categories)`。
- 保存时间线：读取 filters → 校验 categoryIds 属于 type → 复用列表/时间线查询；空分类列表=无分类条件。
- 删除空分类：事务内删除分类并遍历保存视图 filters 移除 ID。

## 3. 契约

| 方法 | 路径 | 入参/出参 | 错误 |
|------|------|-----------|------|
| GET | `/library/categories?type=image` | 树节点 `id/type/parentId/name/sort/count/children` | 400 未知类型 |
| POST | `/library/categories` | `type,parentId,name` | 422 类型不符/深度/重名 |
| PATCH | `/library/categories/{id}` | `name,parentId,sort` | 409 循环/占用；422 深度 |
| DELETE | `/library/categories/{id}` | — | 409 有子/资源；空分类删除并清时间线引用 |
| GET | `/library/resources` | `type,categoryIds,uncategorized,tagIds,dateFrom,dateTo,...` | 400 非法参数 |
| PATCH | `/library/resources/{id}` | `categoryIds[]` | 422 分类不存在/类型不符 |
| GET | `/library/photos/timeline` | `type,categoryIds,tagIds,dateFrom,dateTo,includeUntimed` | 400 非法日期 |
| GET/POST/PATCH/DELETE | `/library/saved-views` | `kind=timeline,type,name,filters,sort` | 409 重名；422 非法筛选 |
| GET | `/library/home` | 最近资源/合集预览/保存时间线/统计/工作/消费 | — |
| GET | `/library/collections` | `previewThumbnails[≤3]` + `memberCount` | — |

DTO 关键变化：

- `Resource.category` → `Resource.categories: Category[]`。
- `ResourcePatch.categoryName` → `categoryIds: number[]`；空数组清空。
- `Category` → `CategoryNode`（含 `type/parentId/count/children`）。
- `Collection`/`CollectionCardData` 增加 `previewThumbnails`。

## 4. 数据流

### 4.1 资源库查询

```text
URL /library/image?view=grid&categoryIds=12
  → LibraryContext（type/view/categoryIds/tags/q/sort）
  → ResourceBrowser / PhotoTimeline
  → GET /library/resources?type=image&categoryIds=12
  → CategoryRepository 递归后代
  → SQLite keyset 分页
  → 列表 + total + category counts
```

### 4.2 分类树与赋值

```text
打开图片库 → GET categories?type=image → CategoryTree
点击节点 → context.categoryIds=[id] → 列表刷新
信息栏多选分类 → PATCH categoryIds → 校验 type → replace resource_categories → 返回 categories
新建/移动/删除 → 分类 API → 刷新树与计数
```

### 4.3 保存时间线

```text
时间线筛选 → 保存 → POST saved-views(filters)
选择时间线 → 读取 filters → 合并到 LibraryContext → 查询
分类删除 → 更新 saved_views.filters（清 ID）
```

### 4.4 首页

```text
GET /library/home
  → recent[12] / collections[previewThumbnails] / savedTimelines / stats / tasks
  → 点击最近缩略图 → 当前一张 viewer/player（不路由）
  → 点击合集卡 → /collections/:id
  → 点击时间线 → /library/:type?view=timeline&savedViewId=
```
