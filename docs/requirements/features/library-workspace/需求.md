# 资源库工作区（分类树 / 视图 / 首页） · 需求

> 状态：**L1/L2 已定稿 · 已落地（2026-10-19）**
> Feature ID：`library-workspace`
> 日期：2026-10-18
> 来源：2026-10-18 图片组织、菜单/工具栏/信息栏讨论
> 关联：`photo-timeline-map`、`library-collections`、`photo-management-next`、`tag-category-hygiene`

## 0. 已确认决策

1. **资源是底层内容实体**：图片/视频等资源只有一份；时间线、地图是资源视图；合集是手动成员关系；角色/人物后续独立建模。
2. **每个资源类型一棵独立分类树**；资源可多分类；分类树 3–4 层；MVP 筛选一次选一个节点，结果包含该节点及所有后代。
3. **导航采用“资源库 + 类型 tabs + 分类树 + 视图切换”**；时间线、地图收进视图，不单独占侧栏。
4. **多时间线 = 保存的筛选器**，无成员表；时间线按类型拆分（图片/视频各自一条）；**一个时间线可包含多个分类（并集）**；分类删除时从保存筛选中清空对应 ID。
5. **合集保持跨类型**；合集详情按类型 tabs 筛选，选中某类型时显示该类型分类树。
6. 老分类按资源实际使用类型迁移；多类型共用的分类自动复制；无资源使用的分类先归入图片树「待整理分类」。
7. 批量快捷键：`Ctrl + 左键` 切换、`Shift + 左键` 连续范围（替换当前选择）、`Esc` 退出批量；不新增 `Ctrl+A`。
8. 合集卡采用 **D：封面 + 悬停/focus 扇形展开**；首页改为资源工作台。
9. 地图首版只做入口/空态；分类树常驻可折叠；时间线默认**不包含**未知时间资源；类型切换重置全部筛选；首页最近添加的缩略图点击**直接打开查看器/播放器**，不跳转。

## 1. 背景

类型页、时间线、合集、分类、标签、角色、人脸等能力持续增加后，当前结构出现三个问题：

- 左侧菜单按类型罗列，时间线/地图/合集各自成为入口，资源被“入口”而不是“关系”组织。
- 分类仍是扁平单值，无法表达「二次元 / 真人 coser / 风景」及其细分。
- 工具栏、批量条、信息栏各自堆动作，缺少统一的操作层级。

本能力把“资源”放回底层，把分类、合集、时间线、地图分别变成关系或视图，并重做资源库的导航与首页。

## 2. 目标

- 同一份资源可以在网格、时间线、地图、分类、合集、角色等不同视角出现，不复制数据。
- 用每类型分类树表达主题结构，支持多分类、3–4 层、批量归类。
- 菜单稳定：新增能力主要进入视图/筛选/关系，不再无限增加顶级入口。
- 首页展示“最近在整理什么”，而不是只有统计和工作列表。
- 工具栏、批量条、信息栏有明确的操作分层，低频动作不抢占主路径。

## 3. 非目标

- 不做物理文件夹镜像分类；库内文件仍按 `{type}/{id}` 存放。
- 不实现角色/人脸识别；`角色` 入口在 R3 落地前不出现。
- 不做分类多节点筛选（两个节点取并集）；MVP 单节点筛选。
- 不改变合集成员关系、导入流程、下载/刮削流程。
- 本轮不做完整像素级视觉重构；L2 先定导航/操作层级，视觉方向另走 `project-spec-design`。
- 地图引擎选型与完整交互可后置；本能力先定义地图作为视图的位置与筛选上下文。

## 4. 用户故事与验收

### W1 资源库导航

- **US-W1.1** 侧栏只有：首页、资源库、合集、回收站、设置；角色在 R3 后出现。
- **US-W1.2** 进入资源库后，顶部类型 tabs 切换图片/视频/番剧等；隐藏分区不出现。
- **US-W1.3** 资源库内可切换网格/时间线/地图；切换视图保留当前类型、分类、标签、搜索、排序。
- **US-W1.4** 当前 URL 能表达 `type / view / categoryId / tagIds / q`，刷新/后退不丢上下文。
- **US-W1.5** 切换类型时重置全部筛选（分类、标签、搜索、保存时间线、排序）；视图模式保留，类型不支持则回网格。

**验收**：从图片 tab 选中「二次元」→ 切到时间线 → 再切回网格，分类与标签筛选仍在；切到视频 tab 后筛选清空。

### W2 每类型分类树

- **US-W2.1** 图片树可建「二次元 / 真人 coser / 风景」等根节点及 3–4 层子节点；视频树独立。
- **US-W2.2** 资源可同时挂多个分类；信息栏用 chips 展示，可增删。
- **US-W2.3** 选择父节点筛选时，结果包含挂在父节点及所有后代节点的资源；计数去重。
- **US-W2.4** 分类管理支持新建、重命名、移动、删除；禁止循环，深度上限 4。
- **US-W2.5** 删除有子分类或资源的分类时阻止，并提示先迁移；删除空分类时，从引用它的保存时间线中清空该分类 ID。
- **US-W2.6** 老分类迁移后资源不丢；无资源分类进入图片树「待整理分类」。
- **US-W2.7** 分类树常驻可折叠，默认展开到第一层；「未分类」为资源虚拟筛选，不是真实分类节点。

**验收**：一张图同时挂「二次元/角色」与「真人 coser/漫展」；点「二次元」能在结果中看到它；点「真人 coser」也能看到；父节点计数不重复计同一资源。

### W3 时间线与地图视图

- **US-W3.1** 图片 tab 的时间线只展示图片；视频 tab 的时间线只展示视频。
- **US-W3.2** 时间线保存为命名筛选器（如「2026 漫展」），成员由筛选规则计算，无成员表；一个时间线可包含多个分类（并集）。
- **US-W3.3** 地图视图首版只提供入口与空态，展示当前类型/分类/标签筛选；完整地图交互后置。
- **US-W3.4** 切换保存的时间线只改变筛选与视图，不复制资源。
- **US-W3.5** 旧 `/photos` 入口迁移到图片时间线视图，不保留混合 image+video 的默认页。
- **US-W3.6** 时间线默认不包含「未知时间」资源；可在保存筛选器中显式开启。

**验收**：保存「2026 漫展」= 图片类型 + 日期范围 + 分类「漫展」+「C104」；新增符合任一分类规则的资源自动出现；删除其中某分类后，该时间线只保留剩余分类条件。

### W4 首页工作台

- **US-W4.1** 首页顶部有导入、全局搜索、新建合集等主操作。
- **US-W4.2** 展示最近添加的资源缩略图带；点击缩略图**只打开当前一张**（查看器/播放器），不建立播放序列、不跳转页面；「查看全部」另行进入资源库。
- **US-W4.3** 展示合集（D 叠图卡）与保存的时间线入口。
- **US-W4.4** 保留进行中的工作、最近消费；统计压缩为一行/小卡。
- **US-W4.5** 空数据时展示引导，不显示空壳卡片。

### W5 合集卡 D

- **US-W5.1** 合集卡显示最多 3 张成员缩略图，形成叠层；hover/focus 时轻微扇形展开。
- **US-W5.2** 0 成员为占位、1 成员单封面、2+ 成员叠层；成员数和标题清晰。
- **US-W5.3** 卡片可键盘聚焦/打开；`prefers-reduced-motion` 下保留静态叠层。
- **US-W5.4** 合集页与首页使用同一卡片组件和数据契约。

### W6 批量快捷键

- **US-W6.1** 批量模式下 `Ctrl + 左键` 切换当前项。
- **US-W6.2** `Shift + 左键` 从锚点选连续范围，替换当前选择。
- **US-W6.3** `Esc` 退出批量；若图片查看器/弹窗打开，先关闭上层。
- **US-W6.4** 输入框、弹窗、查看器内不响应网格快捷键；不新增 `Ctrl+A`。

### W7 操作区层级

- **US-W7.1** 全局栏只放导入、搜索、设置、主题、更新。
- **US-W7.2** 上下文栏放类型 tabs、视图切换、分类树、标签、排序、批量选择。
- **US-W7.3** 批量栏只放选中数、加入合集、打标、移入回收站、更多；显示快捷键提示。
- **US-W7.4** 信息栏按「信息 / 元数据 / 关系」组织；分类、标签、合集、时间线、角色关系不混在长列表里。

## 5. IN / OUT

| IN | OUT |
|----|-----|
| 资源库导航与视图上下文 | 角色/人物实体、人脸识别 |
| 每类型分类树、多分类赋值、单节点子树筛选 | 分类多节点筛选、分类权限/多人 |
| 分类管理 CRUD、迁移 | 物理目录/磁盘文件夹镜像 |
| 保存的时间线筛选器 | 时间线成员表、手动排序 |
| 合集详情类型 tabs、D 卡片 | 合集成员规则/自动合集 |
| 首页资源工作台 | 完整视觉稿/像素级重构（另走 design） |
| 批量 Ctrl/Shift/Esc | Ctrl+A、Delete 等破坏性快捷键 |
| 工具栏/信息栏操作层级 | 导入、下载、刮削流程改造 |

## 6. 已定细节

1. 「待整理分类」作为图片树系统根：只收纳迁移后无资源的旧分类；非空才显示，不可删除，子节点可移出。它不是资源筛选「未分类」。
2. 多分类时间线：保存筛选器时勾选多个分类，按并集去重；父子节点允许同时选。
3. 首页最近添加：点击缩略图只打开当前一张，不建立播放序列。
4. 分类树默认展开到第一层。
