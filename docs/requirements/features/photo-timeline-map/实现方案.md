## 数据流

1. 导入：`probe_image` 读 EXIF → `add_file` 写 `exif_taken_at/exif_lat/exif_lng`
2. 可见性：`timeline_visible` 三态；NULL 时按 primary `exif_taken_at` 是否非空判定
3. 时间线：`GET /library/photos/timeline` → repository 按 `substr(exif_taken_at,1,10)` 聚合（days + unknown + total），封面缩略图批量取 URL
4. 某天：`GET /library/resources?takenDate=…&timelineVisible=true&includeCollected=true` → 复用网格
5. 单图开关：`PATCH /library/resources/{id} {timelineVisible}` → 写 `resources.timeline_visible`
6. 回填：`POST /library/photos/backfill` → `asyncio.to_thread` 读旧图 EXIF → 写 `files`（不清空已有值、不改 `timeline_visible`）
