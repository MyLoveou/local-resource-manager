# 照片时间线与地图 · 需求

> 状态：**评审中**（L1 · 2026-10-18，四项方向已确认，剩来源区分模型待定）
> Feature ID：`photo-timeline-map`
> 上游：`image-library-depth` 的 N2（按拍摄日分组）、N6（EXIF 详情/GPS）、N7（地图浏览）
> 复杂度判定：**命中 L2**（新 GPS/来源字段与迁移、EXIF 解析与回填、新照片页与时间线 API，跨前后端）→ 需求确认后写 `设计.md` 并 STOP

## 0. 已确认方向（2026-10-18）

1. **v1 先做时间线**；地图下一刀（底图已定为 MapLibre + OSM 在线瓦片，WGS84）
2. **入口**：新增独立「照片」页，页内切换「网格 / 时间线」（地图后续加入同一页）
3. **来源区分**：每张图一个「计入时间线」开关；默认按 EXIF 自动（有拍摄时间/相机信息→开），信息栏可改；时间线提供「显示全部照片」切换
4. **无拍摄时间**：单独「未知时间」分组，不伪造时间
5. **范围**：时间线是独立视图，包含已加入合集的照片（不受主列表隐藏开关影响）
6. **回填**：旧图一次性回填（见 §5 说明）；建议同时解析 GPS，为地图刀少扫一次
7. 地图暂不进入 v1 验收；`MapLibre+OSM` 与坐标转换留到地图刀

## 1. 背景

用户现在有**旅游**与**漫展拍摄**两类照片。现有能力：图片库网格、分类/标签/合集、EXIF 拍摄时间（新导入才有）、按拍摄时间排序。缺口：

- 没有按时间线（日/月/年）组织的浏览方式
- 没有读取 EXIF GPS，无法在地图上按拍摄地点看照片
- 无法把「一次旅行 / 一场漫展」按时间+地点串起来

目标是让照片除了「文件列表」之外，还能按**时间**和**地点**两条自然线索组织。

## 2. IN / OUT（草案）

| 做（v1 时间线） | 不做（v1） |
|----|--------------|
| 独立「照片」页：网格 / 时间线视图切换 | 地图视图（下一刀；MapLibre+OSM 已定） |
| 时间线按拍摄日分组，月/年跳转，正序/倒序 | 自动识别「旅行/漫展」并命名（用合集/日期段过渡） |
| 每张照片可标记「是否计入时间线」（模型待定） | 云上传、分享、在线相册 |
| 无拍摄时间照片：单独「未知时间」分组（待确认） | 反向地理编码（城市/地点名） |
| 旧图片拍摄时间（及后续 GPS）一键回填，不复制/不改原图 | 视频与 GPS 轨迹 |
| 复用现有分类/标签筛选（待确认） | 用文件夹/创建时间伪造拍摄时间 |

## 3. 用户故事与验收（v1 时间线）

- **US-T.1** 打开「照片」页 → 切换「时间线」：按拍摄日分组，显示每天张数；点某天进入该天网格
- **US-T.2** 时间线可切月/年跳转，正序/倒序；无拍摄时间的照片进入「未知时间」分组
- **US-T.3** 每张图可标记「计入时间线」（默认按 EXIF 自动）；时间线提供「显示全部照片」切换
- **US-T.4** 旧库点「回填拍摄时间」：只读原文件、更新库内元数据，不复制/不改原图
- **US-T.5** 时间线与现有分类/标签筛选兼容（范围待确认）
- **US-T.6** 地图视图为下一刀：有 GPS 的照片打点/聚合；无 GPS 不入图并提示

## 4. 已确认（2026-10-18）

1. 每图「计入时间线」开关；默认有 EXIF 拍摄时间/相机信息则开，信息栏可改；时间线可「显示全部」
2. 无拍摄时间 → 单独「未知时间」分组；不伪造时间
3. 时间线包含合集成员（独立视图，不受主列表隐藏开关影响）
4. 回填：一次性扫描旧图补 EXIF 拍摄时间；**建议同时解析 GPS**，为地图刀少扫一次（待你确认）

## 5. 剩余待确认

1. **回填范围**：只拍摄时间，还是同时 GPS（推荐）
2. **旅行/漫展分组**：v1 用「合集 + 日期段筛选」是否够？需要自动切分行程吗？
3. **分类/标签筛选**：时间线是否复用现有筛选（顶部展示）
4. **旧图回填的解释**：旧图指导入时未解析 EXIF 拍摄时间/位置的图片；回填 = 重新读原图 EXIF 并写库（不复制、不改原图），用于让老照片进入时间线与地图

## 5. 约束与风险（记录）

- 现有 `files.exif_taken_at` 已有，但**没有 GPS 字段**；需要 DB 迁移与 ProbeFields 扩展
- 地图瓦片在线访问会暴露视口范围（非照片精确坐标若做本地聚合）；默认不上传照片
- 中国地图坐标系（GCJ-02）与 EXIF WGS84 存在偏移，选国内底图必须转换
- 旧库回填需遍历 225+ 张原图，需后台任务/进度，不能阻塞 UI
- 与 `section-visibility`/`library-collections` 的隐藏规则需要一致的产品口径

## 6. v2 · Justified 照片流（2026-10-18 已确认）

- 替换「按天小行列表」为连续照片流：粘性年/月标题 + 日段 + 逐行 Justified（同行等高、按比例分宽）
- 时间线接口直接返回每日照片瓦片（id/宽高/缩略图/拍摄时间）；前端用 `justified-layout` 计算行
- 保留现有筛选/「显示全部照片」/回填/未知时间；点击照片仍走选中与查看器
- 不做：Apple 年/月三层、地图、自动行程
- 验收：滚动为连续照片流；行高随窗口变化；照片按比例、行内无空洞；切筛选/开关后布局重算

## 7. 时间线包含录制的视频（2026-10-18 已确认）

- 时间线不只照片：本机**录制/拍摄的视频**也要进入同一条时间线（按拍摄时间排序）
- 范围：`video` 类型；不含番剧/AV（系列作品）、音频、下载的电影（下载视频默认无拍摄时间，可在信息栏手动计入）
- 视频拍摄时间：优先 ffprobe `format.tags.creation_time`（转换为本地时间）；没有则进「未知时间」，不用文件修改时间伪造
- 视频瓦片：同一套 Justified 流；显示时长角标；双击播放（图片双击看图）
- 日网格：同一天的照片与视频混排；入口改名「时间线」
- 回填：扫描范围扩到图片 + 视频；视频只补拍摄时间（GPS 不做）
- 每图「计入时间线」开关对视频同样生效
- 已确认：
  1. 入口改名「时间线」
  2. 视频仅本机拍摄（有 creation_time）；下载视频默认不进，可手动计入
  3. **内嵌 ffprobe**（随包分发，GPL-3.0 许可文件随包）
