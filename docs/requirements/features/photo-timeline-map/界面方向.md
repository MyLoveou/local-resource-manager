# 界面方向 · 照片时间线

> 状态：**已确认**（2026-10-18：选 Justified 照片流；`justified-layout` + 现有虚拟化；接口直接返回瓦片）

## 对象

- 页面/用户：照片 → 时间线；单人本地整理旅游/漫展照片
- 要解决的观感或结构问题：当前是「按天的小行列表」（54px 封面 + 日期/张数），照片不成为主角，天与天之间没有层级，看起来像文件列表，而不是照片时间线
- 约束：Vue 3 + naive-ui + 现有 `--sm-*` 主题令牌；已有 `@tanstack/vue-virtual`、`VirtualGrid`、查看器与信息栏；不引入第二套视觉语言

## 主方案：Google Photos / Immich 式「粘性日期 + 逐行 Justified 照片流」

- 信息层级（先看到什么）：照片本身 > 月/年 > 日；日期是骨架，不是行卡
- 布局骨架：
  - 顶部保留现有筛选（年/月、分类/标签、显示全部、回填）
  - 滚动区：**粘性年/月标题**（16–18px）→ **日段**（12–13px 日期+张数）→ **逐行 Justified 照片**（同一行等高，宽度按比例分配，行高随窗口 180–240px）
  - 照片铺满宽度，行间 4–6px，圆角 4–6px；hover 显示时间/张数浮层；点击进入现有查看器；选中沿用描边
  - 「未知时间」作为最后一个日段（不伪造日期）
  - 可选：右侧月份刻度/快速跳转（v1 可先不做）
- 色与字：沿用 `--sm-color-bg-page/surface`、`--sm-color-text/muted`、`--sm-color-border`、`--sm-radius-control`；不新增品牌色
- 间距与密度：页面 padding 16；月标题上下 12–16；日段间距 10–12；照片行 gap 4–6；默认舒适密度，紧凑密度后续再加
- 状态：
  - 加载：骨架行（灰块）而非「加载中」文字
  - 空：现有 EmptyGuide + 导入引导
  - 错误：行内重试
  - 禁用：回填中按钮 loading
- 组件拆分（文件级）：
  - `components/PhotoTimeline/index.vue`：滚动容器 + 粘性头 + 分段虚拟列表
  - `components/PhotoTimeline/PhotoRow.vue`：接收照片尺寸，算 Justified 行
  - `components/PhotoTimeline/PhotoTile.vue`：单张缩略图/选择/hover
  - `views/PhotoDay` 保持不变（点日进入现有网格）

### 数据要求

要铺出 Justified 照片流，时间线需要「每张照片的宽高 + 缩略图 URL」，而不只是每天封面：

- v1（当前 225 张规模）：时间线接口按日分组时一并返回该日照片的 `id/width/height/thumbnailPath/takenAt`
- 规模再大：改为按「月」懒加载照片瓦片，保留日计数聚合

## 备选：Apple Photos 式 Years/Months/Days 三层

- 方案：年页大拼贴（hero collage）→ 月页 → 日页，滚动转场
- 不采用因为：工作量明显更大（拼贴、转场、层级导航），对 225 张的日常浏览收益不如一条连续的 Justified 流

## 现成库与方案对比

| 方案 | 许可/版本 | 能提供 | 代价 | 结论 |
|------|-----------|--------|------|------|
| `justified-layout`（Flickr） | ISC · 4.1.0 | 纯函数算 Justified 行位置/尺寸 | 需要自己做粘性头/虚拟化；尺寸需后端提供 | **推荐**：与现有 TanStack 虚拟化、选中/信息栏最贴合，体积小 |
| `@egjs/vue3-infinitegrid` | MIT · 4.13.0 | Vue 3 JustifiedGrid/Masonry、groupBy、无限滚动、虚拟化 | 自带滚动/布局抽象，需改造选中/查看器/信息栏接入；学习成本 | 备选：想最快出货可用 |
| `@yeger/vue-masonry-wall` | MIT · 6.1.4 | 简单瀑布流 | 无 Justified、无虚拟化；不是时间线结构 | 不选 |
| `vue-virtual-scroller` | MIT · 3.0.5 | 虚拟列表 | 仍要自己算行；已有 TanStack | 不选 |
| `photoswipe` | MIT · 5.4.4 | 灯箱 | 已有 Viewer.js | 不选 |
| `vue-waterfall-plugin-next` | UNLICENSED · 3.0.1 | 瀑布流 | 许可不明 | 不选 |

参考产品：Google Photos（粘性日期 + Justified 流）、Immich（开源，同类结构）、Apple Photos（三层，偏重）。
