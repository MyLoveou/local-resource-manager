## 数据流

1. 配置：`HIDDEN_SECTIONS`（默认 `/av /anime /novel /comic /game /model`）
2. 谓词：`isSectionHidden(path)` → `path === key` 或 `path.startsWith(key + '/')`；`/` 恒 false
3. 菜单：App.vue → `menuFromRoutes(routes, isSectionHidden)` → MenuBar options
4. 导航：`router.beforeEach` → 命中即 `return { path: '/' }`（不记导航日志）
5. 导入：`ENABLED_IMPORT_TYPES` = TYPE_PROFILES 排除 `work_directory` 与隐藏路由
6. 首页：`visibleStats` 用 `profileFor(type).routePath` 过滤；`hasOverviewData` 只看可见卡 + 工作 + 最近消费

## 纵向步骤
