# 设计 · section-visibility（L2）

> 状态：**评审中**（2026-10-07）
> 需求：`需求.md`（已定稿）

## 1. 设计原则

- **单一真源**：隐藏清单只在一处（`domain/visibility.ts`）维护，所有入口消费同一个纯谓词
- **只动展示与导航**：不删路由、不删页面、不改 `TYPE_PROFILES`、不改后端/DB；取消配置即恢复
- **代码配置**：TS 常量，随代码提交，重启生效；不做设置页、环境变量、权限模型
- **空配置 = 现状**；未知 key 忽略；`/` 不可隐藏（避免重定向死循环）
- **v1 边界**：搜索与合集混排**不**过滤隐藏类型（避免前端分页过滤失真或新增后端过滤契约）

## 2. 模型（无新表 / 无新 API）

`domain/visibility.ts`（新）：

```ts
export const HIDDEN_SECTIONS: readonly string[] = [
  '/av', '/anime', '/novel', '/comic', '/game', '/model',
]

export function isSectionHidden(path: string): boolean
// 规则：path === key 或 path.startsWith(key + '/')；忽略 '/'；未知 path → false
```

- key 即路由 path（`TYPE_PROFILES.routePath` / 固定路由 path）
- 前缀规则只服务子路由（隐藏 `/collections` 时 `/collections/:id` 一并拦截）
- 不变量：资源、合集、类型定义、API 契约均不变；隐藏只影响入口可见性

## 3. 交互

### 主路径
1. 修改 `HIDDEN_SECTIONS` → 重启应用
2. 左侧菜单不渲染命中项
3. 地址栏直达 `#/av`（或子路径）→ 守卫重定向 `/`
4. 导入向导类型选项不出现命中类型
5. 首页概览统计卡不出现命中类型

### 边界与失败
- 隐藏 `/collections`：合集卡（全库混排）仍可点 → 路由守卫重定向首页（可接受，v1）
- 「最近消费」点隐藏类型 → 同样由守卫回首页
- 隐藏全部类型：菜单只剩首页/合集/回收站（未隐藏项）；首页概览卡为空
- 配置项不是字符串或不存在：忽略，不报错

## 4. 模块划分（沿用现有前端四层）

| 层 | 文件 | 职责 | 不进入 |
|----|------|------|--------|
| domain（算法/配置切片） | `domain/visibility.ts`（新） | 隐藏清单 + 纯谓词 | 路由、Vue、HTTP |
| domain | `domain/menu.ts` | `menuFromRoutes` 增加可选谓词参数（默认不过滤） | 读配置常量（由调用方注入） |
| domain | `domain/mediaTypes.ts` | `ENABLED_IMPORT_TYPES` 过滤隐藏类型 | 路由守卫 |
| ui | `App.vue` | 组合根：把 `isSectionHidden` 注入菜单生成 | 规则细节 |
| ui/views | `views/Home/index.vue` | 概览卡按 `profileFor(type).routePath` 过滤 | 配置清单 |
| infrastructure | `router/index.ts` | `beforeEach` 拦截隐藏 path → `/` | 菜单展示 |
| 后端 | — | 不进入 | — |

依赖方向：`ui → domain`；`infrastructure/router → domain`；domain 不依赖 UI/HTTP。

## 5. 功能拆分（组合式）

| 切片 | 提供 | 契约 |
|------|------|------|
| 算法 | 可见性判定 | `isSectionHidden(path: string): boolean`；纯函数，未知输入 false |
| 功能 | 导航拦截 | `beforeEach`：命中隐藏 → `return { path: '/' }` |
| UI | 菜单过滤 | `menuFromRoutes(routes, isHidden?)`；未传谓词行为与现状一致 |
| UI | 导入选项过滤 | `ENABLED_IMPORT_TYPES` 保持导出形状 `{value,label}[]` |
| UI | 首页卡过滤 | 按 `profileFor(type)?.routePath` 判定；未知类型保留 |

组合根：`App.vue`（菜单）+ `router/index.ts`（守卫）+ `Home`/`ImportWizard` 各自消费同一谓词。无新增门面。

## 6. 抽象

- **抽**：配置清单 + 纯谓词 + 菜单过滤谓词注入（可单测、单源、无框架）
- **不抽**：通用 feature-flag 引擎、通配符/正则、后端开关、运行时切换、单功能级开关

## 7. 测试与验收

- 前端无自动化测试脚本（`package.json` 无 test）→ 以 `typecheck` / `lint` / `build` + Electron 手验为准
- 手验场景：
  1. 默认清单：菜单无 AV/番剧/小说/漫画/游戏/模型；`#/av` → 首页；导入向导无这 6 类；首页概览无这 6 类卡
  2. 清空清单：13 项菜单与现状一致
  3. 配 `'/collections'`：菜单无合集；`#/collections/1` → 首页
  4. 配未知 key：无报错、无变化
- 后端回归不涉及（不改后端），仍跑全量 pytest 防误伤
