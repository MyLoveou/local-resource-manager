# 设计 · audio-embedded-cover（L2）

> 状态：**已落地**  
> 需求：`需求.md`。施工图：`实现方案.md`。

## 0. 复杂度

接在已有 `covers/` 上：多一个 origin、一条 ingest 分支、一次 ffmpeg 抽附加图。不新开服务。不可跳过 L2（origin 字面量与工具选型要锁死）。

## 1. 设计原则

| 原则 | 含义 | 不做 |
|------|------|------|
| 复用封面管道 | 抽出静态图后只走 `attach_cover_image` | 音频播放器里现解封面 |
| 与抽帧同一工具 | PATH 上 `ffmpeg` | mutagen、渲染进程解析 ID3 |
| 失败可见 | 无二进制 / 非 0 退出打 warning | 再静默 `.tmp` 失败 |
| 新导入 | 只在 audio file ingest 成功后 | 回填任务 |
| 用户锁定 | origin=user 则跳过 | 重导钩子盖海报 |

## 2. 模型

`coverOrigin` 增加：`embedded`。

优先级（音频）：已是 user → 停；否则内嵌图；否则无。  
音频 file ingest **没有** `source_root`，本刀不做目录 `poster.jpg`（那是多文件一张卡，和当前一曲一资源冲突）。

不变量：primary 仍是音频；cover 是包内小图；列表吃 thumbnail。

## 3. 交互

用户无感知步骤。无图：网格「无封面」。手换入口已有，本刀不改 InfoPanel。

## 4. 模块划分

| 模块 | 边界 | 不进入 |
|------|------|--------|
| `covers/embedded.py`（或扩 `frame.py` 旁） | `extract_audio_cover(src, dest_jpg) -> bool` | 播放 Howler |
| `ingest.apply_ingest_cover` | `AUDIO` + `audio_path` → 抽内嵌 | 改视频抽帧语义 |
| `ImportService._ingest_one` | type=audio 时传入 primary 路径 | 新 HTTP |

依赖方向：导入 → ffmpeg 附加图 → put_cover。禁止为音频复制一套封面 API。

**抽法（锁定语义，L3 可调参数）**：

```text
ffmpeg -y -i <audio> -an -frames:v 1 -q:v 2 <stem>.part.jpg
```

无视频/附加图流则非 0 退出 → False。输出必须是 `.jpg` 扩展名。超时同 `FFMPEG_TIMEOUT_SEC`。

不先 `ffprobe` 判流也可：失败即无封面。若 L3 要用 probe 减一次失败日志，可以，但不得因此加依赖。

## 5. 功能拆分（一刀）

| 切片 | 可感知结果 |
|------|------------|
| A | ffmpeg 抽出图 + attach + origin=embedded |
| B | 无图/无 ffmpeg 不挡导入 + 有日志 |
| C | user 锁定单测 |

## 6. 抽象

**抽**：与 `extract_video_frame` 并列的纯函数，ingest 里 AUDIO 分支调用。  
**不抽**：按扩展名分 mp3/flac 解析器。
