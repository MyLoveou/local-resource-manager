# 音频内嵌封面 · 需求

> 状态：**已落地**  
> Feature ID：`audio-embedded-cover`  
> 上游：`library-covers`（D-20260919-03 将本能力 OUT）；抽帧已验过 ffmpeg  
> 对齐：开发库清库重导；**不回填**

## 1. 问题

音频能导入、能播、能手换封面，但导入不读文件里的专辑图。带 ID3/FLAC/`covr` 的曲子网格仍是「无封面」。视频抽帧已通，音频是同类缺口。

不是每首都有内嵌图；没有则保持空封面，可手选。

## 2. 已按口令收口

1. 只做 **音频 type** 新导入抽内嵌图。  
2. 不回填旧库。  
3. **EPUB / 小说** 仍 OUT。  
4. 失败不挡导入；`coverOrigin=user` 后不覆盖。  
5. 不写回音频文件。

## 3. 范围

### IN

- `ingestKind=file` 的 `audio`：复制进库后，用本机 **ffmpeg** 抽出第一条视频/附加图流，写入包内 cover + `thumbs/grid.webp`。  
- `extra.coverOrigin=embedded`。  
- 无内嵌图 / 无 ffmpeg / 抽失败：导入成功，无自动封面。  
- 日志：找不到 ffmpeg、抽失败（与修过的抽帧一致，禁止静默）。  
- 临时文件用图片扩展名（避免再出现 `.tmp` muxer 问题）。  
- 单测：有附加图的夹具（或 mock ffmpeg）写入 origin=embedded；无图文件导入成功且无 cover 角色。

### OUT

- 旧库扫描。  
- mutagen / 新 Python 依赖。  
- 把 ffmpeg 打进安装包。  
- 多图挑选 UI、写入 ID3、歌词。  
- 目录专辑海报（音频仍是一文件一资源；文件夹导入=多卡）。  
- 小说 EPUB 封面。

## 4. 用户故事

- **US-A.1** 导入带内嵌封面的 mp3/flac/m4a（本机有 ffmpeg）→ 网格有缩略图。  
- **US-A.2** 导入无内嵌图的 wav → 导入成功，「无封面」，可手换。  
- **US-A.3** 无 ffmpeg → 导入成功，无自动封面。  
- **US-A.4** 手换封面后再走自动抽 → 文件与 origin 仍为 user。

## 5. 验收

- [ ] 有内嵌图：cover 文件 + thumbnailPath + origin=embedded。  
- [ ] 无内嵌图 / 无 ffmpeg：导入成功，不假装有封面。  
- [ ] 手指定锁定仍有效。  
- [ ] 不改源音频与库内 primary 字节（只多 cover/缩略图）。  
- [ ] 列表仍只展示 thumbnailPath。

## 6. 契约草案

- 不新增路由。沿用 `files.role=cover`、`POST /cover`。  
- `coverOrigin` 增加字面量 `embedded`。  
- 不迁表。

禁止：渲染进程读音频容器；GET 任意磁盘路径。

## 7. 开放问题

无。工具锁 ffmpeg（与视频抽帧同一 PATH）；多图取**第一条**附加图流。
