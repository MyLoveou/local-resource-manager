# 音频内嵌封面 · 实现方案（L3）

> 状态：**已落地**  
> 拍板沿用 D-20260919-03 的锁定规则；本刀补上当时 OUT 的音频内嵌。L2：`设计.md`。

沿用 `covers/` 与 `attach_cover_image`。不新建表、不加 mutagen、不打进 ffmpeg。

## 1. 对齐

- 仅 `ResourceType.AUDIO` 的 file ingest。  
- 渲染进程不解析容器。  
- 失败不挡导入；无 ffmpeg 与抽帧同等降级。  
- 临时输出必须是 `.jpg`（禁止 `.jpg.tmp`）。  
- 旧库不回填；不写回音频；EPUB 仍 OUT。

## 2. 锁定

| 项 | 锁定 |
|----|------|
| origin | `embedded` |
| 工具 | PATH `ffmpeg`；超时 `FFMPEG_TIMEOUT_SEC` |
| 命令 | `-y -i <audio> -an -frames:v 1 -q:v 2 <stem>.part.jpg` |
| 多图 | 默认第一条视频/附加图流（ffmpeg 默认 map） |
| 锁定 | `coverOrigin=user` 则跳过 |

## 3. 数据流

1. `_ingest_one` commit 后 `apply_ingest_cover(..., audio_path=primary)`（仅 audio）。  
2. `extract_audio_cover` → 临时 jpg → `attach_cover_image(..., embedded)` → thumbnail。  
3. 无流 / 非 0 / 超时：warning，无 cover。

## 4. 文件清单

| 路径 | 动作 |
|------|------|
| `covers/origin.py` | `COVER_ORIGIN_EMBEDDED` |
| `covers/embedded.py` | **新** `extract_audio_cover` |
| `covers/ingest.py` | AUDIO 分支 |
| `covers/__init__.py` | 导出 |
| `import_service.py` | 传入 `audio_path` |
| `tests/test_library_covers.py` | mock + 后缀；有 ffmpeg 则夹具 mp3 |

不改 InfoPanel、不改 API。

## 5. 测试

- 导入无图 mp3：成功，无 cover 角色（现 fake ID3 即可）。  
- mock 抽出图：origin=embedded，cover_path 含 `/files/`。  
- user 锁定仍跳过（已有用例）。  
- argv 末尾后缀 `.jpg`。
