# 界面方向 · 确认元数据面板

> 本轮默认不写业务代码。确认后再走施工（含字段级覆盖的契约，见文末）。  
> 对象：`ScrapeConfirmQueue`（信息栏 / 批量「获取元数据」共用）。  
> 库类型：视频、番剧。令牌沿用 `--sm-*` 与 naive-ui `size="small"`。

## 对象

- **页面/用户**：本机库操作者；对照候选后决定写进当前资源的哪些字段。  
- **要解决的问题**：  
  1. **不能勾选部分字段覆盖**——确认后一律写标题、简介、`catalog`、追加标签；只有封面有开关。想只换封面或只改简介做不到。  
  2. 弹层 560px 单列：候选、BV 框、长简介、封面挤在一起；选中态用死色 `#2563eb`，和主题主色 `--sm-color-primary` 不一致。  
- **约束**：不换皮成另一款产品；不新开路由；不改信息栏分区骨架；`description`（我的评价）与用户评分仍永不被刮削改。

## 主方案：左右分栏 + 字段勾选对照

### 信息层级（先看到什么）

1. 进度（第 n / m）与搜索状态。  
2. **左：候选是谁**（来源 + 标题 + 小图）。  
3. **右：写哪些字段**——每块一行勾选，勾上才覆盖；旁注当前库内值（灰）与将写入值（正文）。  
4. 封面单独一块：勾选「写入封面」后才点选海报。  
5. 底栏：跳过 / 全部跳过 / 确认（至少勾一项才可点）。

### 布局骨架

弹层加宽到约 **840px**（不超过主区舒适宽度），高约 **72vh** 内滚动。

```
[ 第 1/3 · 搜索中|无候选|失败原因 ]
[ BV 输入 | 按此重新搜索 ]          ← 仅视频
┌─────────────┬──────────────────────┐
│ 候选列表    │ 写入字段             │
│ 竖向滚动    │ 标题 ☑ 现有→新       │
│             │ 简介 ☑ …             │
│             │ 作者 ☑（空才默认勾） │
│             │ 标签 ☑ 只追加        │
│             │ 作品档案 ☑ catalog   │
│             │ 封面 ☑ 缩略图横滑    │
│             │ ☑ 覆盖手动封面       │
└─────────────┴──────────────────────┘
[ 全部跳过 ] [ 跳过 ]        [ 确认 ]
```

左栏固定约 **240px**。右栏字段块用信息栏同款分区：小标题 12px muted，控件 `small`。

### 色与字（跟现有页面对齐）

| 用途 | 令牌 |
|------|------|
| 面、字、边框 | `--sm-color-bg-surface` / `--sm-color-text` / `--sm-color-border` |
| 次要说明、现有值 | `--sm-color-text-muted` |
| 选中候选 / 选中封面 | `outline: 2px solid var(--sm-color-primary)`，**去掉 `#2563eb`** |
| 标题 | 13px，与卡片标题一致 |
| 字段标签 | 12px |

不新增色板、不引入第二套圆角。间距 `--sm-space-2` / `--sm-space-3`。

### 间距与密度

- 候选行：左 48×72 竖图（与现网缩略图比例一致），内边距 6–8px。  
- 字段行：勾选 + 标签一行；其下现有值单行省略，新值最多 4 行滚动。  
- 封面图 72×108，横滑不换行撑高。  
- 底栏按钮仍 naive small，主按钮「确认」。

### 字段默认勾选（交互，不是纯 CSS）

| 字段 | 默认 | 说明 |
|------|------|------|
| 标题 | 开 | 可关，保留文件名 |
| 简介 `synopsis` | 有新简介则开 | 空简介默认关 |
| 作者 | **仅当库内 author 为空** 且站点有 UP | 已有作者默认关，避免覆盖 |
| 标签 | 有新标签则开 | 仍只追加不删 |
| 作品档案 catalog | 开 | 关则保留原 catalog |
| 封面 | 有图则开 | 与现网一致；user 锁另勾「覆盖我手动指定的封面」 |

全不勾时「确认」禁用，文案：至少选择一项写入。

### 状态

| 状态 | 表现 |
|------|------|
| 默认 | 左有候选，右对照 |
| 加载 | 左骨架或「搜索中」，右空，确认禁用 |
| 空 | 「无候选」；BV 框仍可用 |
| 错误 | 状态行 muted 展示失败原因，不弹第二层 |
| 禁用 | 搜索中底栏跳过仍可用；确认 loading |

### 组件拆分（Vue SFC，不混栈）

仍一个弹层，**不新开页面**。建议在 `ScrapeConfirmQueue` 内拆两个小组件（同目录）：

- `ScrapeCandidateList.vue` — 左栏 listbox  
- `ScrapeApplyFields.vue` — 右栏勾选对照 + 封面  

令牌与选中态只写在这些 SFC 的 scoped less。不改 ToolBar、不改后端本轮（方向确认后才改契约）。

## 备选

- **方案**：保持 560px 单列，只在封面下追加「标题/简介/标签」勾选。  
- **不采用因为**：看不到库内现值，勾选像开关说明书；用户问题是「选部分覆盖」，对照比再挤一列 checkbox 更有效。宽屏桌面端加一栏成本低。

## 落地

- **下一步：全量 `project-spec`（L2+L3）**，不是纯 `project-spec-style`。原因：`POST .../select` 与 `apply_scrape_detail` 必须按字段开关写库；预览需带上当前资源快照（标题/简介/作者/是否已有封面）。  
- 视觉本方向作为 L2 交互输入。  
- **明确不做**：新路由、对比原图查看器、改 `description`/评分、批量为每一条弹出不同布局、换主题品牌色。
