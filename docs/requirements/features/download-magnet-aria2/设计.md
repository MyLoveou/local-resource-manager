# 设计 · download-magnet-aria2

> 状态：**已定稿**（已编码）

HTTP 仍是 `engine=httpx`。磁力是 `protocol=magnet`、`engine=aria2`。不新表。`save_path` 在进行中是任务目录 `data/downloads/<id>/`，完成后改为入库前的视频路径（随后删除暂存）。

## 数据流

```
POST /download/tasks { url: magnet:?xt=urn:btih:... }
  → validate_magnet（重建 xt/dn/tr）
  → 无 aria2c 则 400
  → insert queued
  → worker pull_magnet
       aria2.addUri → 轮询 tellStatus
       暂停 forcePause；取消 forceRemove
       complete → 最大视频文件 → ImportService
```

进程退出时 `aria2.shutdown`。重启后内存里的 gid 丢失，未完成任务会重新 `addUri`。

## 安全

- RPC：`rpc-listen-all=false`，随机端口，`rpc-secret`。  
- 不把 `ws`/`as`/`xs` 交给 aria2。种子元数据里自带的 web seed 仍可能被 aria2 去拉，这一刀不额外封。  
- 不扫描 `downloads/` 根。
