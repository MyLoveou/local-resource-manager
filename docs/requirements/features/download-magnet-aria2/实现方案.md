# 实现方案 · download-magnet-aria2

## 文件

| 路径 | 职责 |
|------|------|
| `app/download/application/magnet.py` | 校验、选视频文件 |
| `app/download/application/aria2.py` | 找二进制、JSON-RPC、轮询 |
| `app/download/application/service.py` | 创建任务分流；完成后入库 |
| `app/download/application/queue.py` | 停 worker 时关掉 aria2 |
| `components/DownloadDrawer/index.vue` | 占位文案含磁力 |
| `tests/test_download_magnet.py` | 校验、缺 aria2、假完成入库 |

## 契约

`POST /download/tasks` 请求体不变：`{ "url": "..." }`。磁力成功时 `protocol=magnet`、`engine=aria2`。错误文案：`磁力链接无效`、`磁力链接不能带直链参数`、`未找到 aria2，无法下载磁力`、`没有可入库的视频`。

环境变量 `ARIA2C_PATH` 指向 `aria2c` 可执行文件；否则用 PATH。
