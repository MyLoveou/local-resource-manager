# 磁力下载 · 本机 aria2 · 需求

> 状态：**已落地**（待 Electron 手验；拍板 D-20260923-06）  
> Feature ID：`download-magnet-aria2`  
> 上游：MS7 原文「贴一条 HTTP 和一条磁力，能下完并在资源库看到」  
> 沿用：[download-http-ingest](../download-http-ingest/需求.md) 的入库方式

## 1. 问题

HTTP 直链第一刀已能进视频库。原文还要磁力。技术栈把磁力交给 aria2 或 rqbit；这一刀只接本机已安装的 aria2c，不把 HTTP 从 httpx 换掉。

## 2. 收口

1. 顶栏同一抽屉可贴 `magnet:?xt=urn:btih:`。  
2. 执行器是本机 `aria2c` 子进程，JSON-RPC 只听 `127.0.0.1`，带密钥。  
3. 找不到可执行文件（PATH 或 `ARIA2C_PATH`）时 400，不建任务。不随应用下载 aria2。  
4. 拒绝 `ws` / `as` / `xs`，拒绝其它未知参数；tracker 必须是公网 `http(s)` 或 `udp`。  
5. 完成后在暂存目录里选最大的视频文件，走现有 `ImportService` 进视频库，再删该任务暂存。  
6. 没有视频文件则任务失败。暂停 / 取消沿用现有按钮。  
7. HTTP 直链行为不变。

## 3. 不做

rqbit、yt-dlp、FTP、把 HTTP 改走 aria2、把 aria2 打进安装包、磁力搜索、蜜柑写种子、设置页限速。

## 4. 验收

- [x] 非法磁力、内网 tracker、直链参数不建任务（单测）。  
- [x] 假 aria2 报完成后，库内有视频（单测）。  
- [ ] 本机装有 aria2c 时，贴一条真实磁力，完成后视频库能播。  
- [ ] 未安装 aria2 时，抽屉看到「未找到 aria2」。
