## Purpose

扩展资源列表查询：关键词与排序键；服务端过滤；分页与排序一致。

## ADDED Requirements

### Requirement: 列表可搜索

系统 SHALL 允许用户用关键词缩小当前浏览范围内的资源列表。无匹配时 MUST 显示无匹配空态，不得伪装成从未导入。

#### Scenario: 标题命中

- **WHEN** 用户在某类型页输入与某条标题匹配的关键词
- **THEN** 网格只包含命中的作品卡

### Requirement: 列表可排序

系统 SHALL 支持至少一套共用排序键及升/降序。换排序后后续分页 MUST 与该序一致。

#### Scenario: 按标题排序

- **WHEN** 用户选择按标题排序
- **THEN** 列表顺序改变且继续加载不重复条目
