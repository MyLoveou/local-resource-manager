## Purpose

批量操作离开网格首行；信息栏分区且操作固定底部。不改变软删/恢复/保存的业务语义。

## ADDED Requirements

### Requirement: 批量入口位置

系统 SHALL 把批量删除（及回收站批量恢复/彻底删除）放在顶栏 ToolBar 右侧，MUST NOT 占用网格第一行作为按钮条。

#### Scenario: 进入批量

- **WHEN** 用户进入批量模式
- **THEN** 操作按钮出现在约定壳层位置，网格卡片从主区顶部排起

### Requirement: 信息栏分区

系统 SHALL 将资源信息栏分为身份、只读技术信息、可编辑字段、底部操作。底部操作在内容滚动时 MUST 仍可见。信息栏默认不折叠。

#### Scenario: 长内容

- **WHEN** 选中含长描述与待办的资源并滚动面板中部
- **THEN** 保存/回收站仍留在信息栏底部
